# Завдання для локальної сесії Claude з браузером: пошта (Resend) і CAPTCHA (Cloudflare Turnstile) для Willowsum

**Створено:** 2026-11-12 · **Оновлено:** 2026-11-12

## Для кого цей текст

Ти — локальна сесія Claude, яка керує браузером власника продукту Willowsum. Цей документ дав
тобі власник. Виконуй кроки по черзі сам. Зупиняйся і проси власника лише там, де написано
«ЗУПИНКА». Говори з власником українською, коротко.

## Що вже є (з попереднього проєкту власника, wealth-platform)

- Домен **mina.yachts**, DNS керується у **Spaceship**.
- **Resend**: обліковий запис власника, домен `mina.yachts` уже **Verified** у регіоні
  **Ireland (eu-west-1)** (стан на 2026-10-19). Записи DNS для Resend уже додано в Spaceship.
- **Cloudflare Turnstile**: обліковий запис власника, є віджет «Wealth staging» (для
  `app.staging.mina.yachts` / `admin.staging.mina.yachts`).

Нові облікові записи не потрібні. Потрібно лише окремий ключ і окремий віджет для Willowsum.
Обидва сервіси вже записані у вимогах (NFR-17@PoC, ACC-01) і в переліку інтеграцій
[`docs/ops/integrations.md`](../integrations.md).

## Жорсткі правила

- **Ніколи** не вставляй ключі, токени чи паролі в чат, у звіт, у файли, у GitHub чи кудись ще.
  Секрети живуть лише в панелі сервісу і в менеджері паролів власника.
- **Не плати** і не змінюй тариф. Лише безкоштовні тарифи. Якщо щось вимагає оплати — ЗУПИНКА.
- **Не приймай юридичні угоди** замість власника — ЗУПИНКА, хай натисне сам.
- **Не змінюй і не видаляй** нічого, що належить wealth-platform: віджет «Wealth staging», старі
  ключі Resend, наявні DNS-записи.
- Якщо інтерфейс не такий, як описано, — розберись сам; якщо не виходить за 2 спроби — ЗУПИНКА.

## Крок 0. Адреса Willowsum

Адреса застосунку: `<ХОСТ>` = **`willowsum.mina.yachts`** (рішення власника 2026-11-12). Інший хост —
лише якщо власник прямо вказав його в повідомленні, яким передав тобі цей файл. Адреса відправника
листів: `Willowsum <no-reply@mina.yachts>`.

## Крок 1. Resend: перевірити домен і створити ключ

1. Відкрий https://resend.com/domains . Якщо власник не увійшов — ЗУПИНКА: хай увійде.
2. Перевір, що `mina.yachts` має статус **Verified** і регіон **eu-west-1 (Ireland)**.
   - Якщо статус не Verified — натисни **Verify DNS Records**; перевіряй раз на 10 хв, до 6 разів.
     Якщо так і не підтвердилось — ЗУПИНКА з описом.
3. **API Keys → Create API Key**:
   - Name: `willowsum-production`
   - Permission: **Sending access** (не Full access)
   - Domain: лише `mina.yachts`
4. Resend покаже ключ один раз. ЗУПИНКА: попроси власника зберегти його в менеджер паролів у запис
   «Willowsum — Resend API key (production)». Сам ключ нікуди не копіюй.

## Крок 2. Cloudflare Turnstile: окремий віджет

1. Відкрий https://dash.cloudflare.com/ → **Turnstile**. Якщо власник не увійшов — ЗУПИНКА.
2. **Add widget**:
   - Widget name: `Willowsum`
   - Hostnames: `<ХОСТ>` (і `localhost`, якщо інтерфейс дозволяє)
   - Widget mode: **Managed**
   - Pre-clearance: вимкнено
3. Збережи. З'являться **Site Key** і **Secret Key**. ЗУПИНКА: попроси власника зберегти обидва в
   менеджер паролів у запис «Willowsum — Cloudflare Turnstile».
4. Віджет «Wealth staging» не чіпай.

## Крок 3. DNS для застосунку — НЕ зараз

Запис DNS для `<ХОСТ>` (вказівник на сервер Willowsum в Oracle Cloud) додається пізніше, коли буде
сервер. Зараз нічого в Spaceship не змінюй.

## Крок 4. Звіт власнику (без секретів)

Напиши власнику одним повідомленням, щоб він передав його в хмарну сесію Willowsum:

```
Пошта і CAPTCHA для Willowsum:
- Хост застосунку: <ХОСТ>; відправник: Willowsum <no-reply@mina.yachts>
- Resend: домен mina.yachts — <Verified / проблема>, регіон eu-west-1;
  ключ «willowsum-production» (Sending access, лише mina.yachts) збережено в менеджері паролів.
- Cloudflare Turnstile: віджет «Willowsum» для <ХОСТ> (Managed) створено; ключі в менеджері паролів.
- Що лишилося: <якщо щось не вдалося>
```

Секретів у звіті бути не повинно. Ключі хмарна сесія попросить окремо через захищену форму, коли
дійде до розгортання.
