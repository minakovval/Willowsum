# Завдання для локальної сесії Claude з браузером: пошта (Resend) і CAPTCHA (Cloudflare Turnstile) для Willowsum

**Створено:** 2026-11-12 · **Оновлено:** 2026-11-12

## Для кого цей текст

Ти — локальна сесія Claude, яка керує браузером власника продукту Willowsum. Цей документ
дав тобі власник. Виконуй кроки по черзі, сам, без зайвих запитань. Зупиняйся і проси власника
лише там, де написано «ЗУПИНКА». Говори з власником українською, коротко.

## Мета

Підготувати два зовнішні сервіси, які вже записані у вимогах Willowsum (NFR-17@PoC, ACC-01; перелік —
[`docs/ops/integrations.md`](../integrations.md)):

1. **Cloudflare Turnstile** — CAPTCHA на сторінках реєстрації і входу. Безкоштовно.
2. **Resend** — надсилання листів (підтвердження email, сповіщення власнику). Регіон EU.

Результат — два налаштовані сервіси і короткий звіт власнику **без жодних секретів**.

## Жорсткі правила

- **Ніколи** не вставляй ключі, токени чи паролі в чат, у звіт, у файли, у GitHub чи кудись ще.
  Секрети живуть лише в панелі сервісу і в менеджері паролів власника.
- **Не плати** і не обирай платний тариф. Лише безкоштовні (Free) тарифи. Якщо безкоштовного
  немає — ЗУПИНКА.
- **Не приймай юридичні угоди** (умови використання, DPA) замість власника: покажи, що
  приймається, і попроси власника натиснути самому — ЗУПИНКА.
- **Не купуй домен.** Якщо домену ще немає — ЗУПИНКА, спитай власника.
- Не змінюй інших налаштувань облікових записів, крім описаних тут.
- Якщо щось виглядає не так, як описано (інший інтерфейс, помилка) — розберись сам; якщо не
  виходить за 2 спроби — ЗУПИНКА з коротким описом.

## Крок 0. Домен

Спитай власника (ЗУПИНКА): «На якому домені буде Willowsum і з якої адреси надсилати листи?»
- Якщо домен є — запиши його як `<ДОМЕН>`; адреса відправника за замовчуванням
  `no-reply@<ДОМЕН>`, але погодь із власником.
- Якщо домену немає — завершуй завдання і передай власнику: «Потрібен домен. Купівля — ваше
  рішення; повідомте його, і я продовжу». Далі не йди.
- Дізнайся, де керується DNS домену (Cloudflare, реєстратор тощо): відкрий панель реєстратора
  або Cloudflare в браузері власника. Якщо потрібен вхід — ЗУПИНКА, хай власник увійде.

## Крок 1. Cloudflare Turnstile

1. Відкрий https://dash.cloudflare.com/ . Якщо власник не увійшов — ЗУПИНКА: попроси увійти
   або зареєструватися (реєстрація безкоштовна; умови приймає власник).
2. У меню зліва знайди **Turnstile** → **Add widget** (або «Add site»).
3. Заповни:
   - Widget name: `Willowsum`
   - Hostnames: `<ДОМЕН>` (і `localhost`, якщо інтерфейс дозволяє — для локальної перевірки)
   - Widget mode: **Managed**
   - Pre-clearance: вимкнено (якщо є такий пункт)
4. Збережи. Cloudflare покаже **Site Key** і **Secret Key**.
5. ЗУПИНКА: попроси власника зберегти обидва ключі в його менеджер паролів у запис
   «Willowsum — Cloudflare Turnstile». Сам їх не копіюй нікуди. Дочекайся «готово».

## Крок 2. Resend

1. Відкрий https://resend.com/ . Якщо власник не увійшов — ЗУПИНКА: реєстрація або вхід.
   Умови використання і, якщо запропоновано, DPA приймає власник сам (ЗУПИНКА — покажи, що саме
   приймається).
2. Тариф: переконайся, що активний **Free**. Якщо сервіс просить картку чи платний тариф —
   ЗУПИНКА.
3. **Domains** → **Add Domain**:
   - Domain: `<ДОМЕН>` (або піддомен для пошти, якщо власник так вирішив, напр. `mail.<ДОМЕН>`)
   - Region: **EU (eu-west-1, Ireland)** — обов'язково EU.
4. Resend покаже DNS-записи (SPF/TXT, DKIM, можливо MX для відповідей і DMARC).
   - Якщо DNS у Cloudflare і власник увійшов — додай ці записи в Cloudflare → DNS для `<ДОМЕН>`
     точно як показано (тип, ім'я, значення; для записів Resend проксі Cloudflare — **вимкнено**,
     «DNS only»).
   - Якщо DNS в іншого реєстратора — додай там так само; якщо потрібен вхід — ЗУПИНКА.
   - Не видаляй і не змінюй інших DNS-записів.
5. Повернися в Resend і натисни **Verify**. DNS може оновлюватися до години: перевіряй раз на
   10 хвилин, не більше 6 разів. Якщо не підтвердилось — переходь до кроку 3 зі статусом
   «очікує підтвердження DNS».
6. **API Keys** → **Create API Key**:
   - Name: `willowsum-production`
   - Permission: **Sending access** (не Full access)
   - Domain: лише `<ДОМЕН>`
   Resend покаже ключ один раз. ЗУПИНКА: попроси власника зберегти його в менеджер паролів у запис
   «Willowsum — Resend API key (production)». Сам ключ нікуди не копіюй.

## Крок 3. Звіт власнику (без секретів)

Напиши власнику одним повідомленням, щоб він передав його в хмарну сесію Willowsum:

```
Пошта і CAPTCHA для Willowsum:
- Домен: <ДОМЕН>; адреса відправника: <АДРЕСА>
- DNS керується в: <Cloudflare / реєстратор>
- Cloudflare Turnstile: віджет «Willowsum» створено, режим Managed, hostnames: <список>.
  Ключі збережено в менеджері паролів власника.
- Resend: тариф Free, регіон EU, домен <підтверджено / очікує DNS>,
  API-ключ «willowsum-production» (Sending access, лише цей домен) збережено в менеджері паролів.
- Що лишилося: <якщо щось не вдалося — що саме>
```

Секретів у звіті бути не повинно. Ключі хмарна сесія попросить окремо через захищену форму,
коли дійде до розгортання.
