# Зовнішні сервіси та інтеграції

**Створено:** 2026-11-12 · **Оновлено:** 2026-11-12

Єдиний перелік усіх сторонніх сервісів, з якими Willowsum взаємодіє: для чого, через який
обліковий запис, яким способом, де лежать облікові дані, які дані йдуть назовні і в якому стані
налаштування. Джерело правди для обробників персональних даних — [NFR-17@PoC](../requirements/nfr/NFR-17.poc.md);
цей документ не змінює вимог, а показує, як вони реалізовані.

Правила:
- Облікові записи сервісів належать власнику продукту. Агенти ніколи не тримають паролів і не
  входять в облікові записи; дії в браузері виконує власник або його локальна сесія Claude за
  інструкцією (див. «Інструкції для браузера»).
- Секрети ніколи не потрапляють у чат, issue, PR чи репозиторій. Секрети production — лише в
  сховищі секретів OCI (OCI Vault); на сервері production немає токена GitHub (CICD-12).
- Новий сервіс, який отримує персональні дані, додається до NFR-17 і сюди **до** першої передачі
  даних; новий сервіс без персональних даних — сюди, у тому ж PR, що його підключає.
- Кожен рядок змінюється в тому ж PR, що змінює інтеграцію. Стан «налаштовано» ставить лише
  власник (або зі звіту його локальної сесії).

Позначки: **Обробник** — отримує персональні дані (NFR-17); **Джерело** — дані, які підключає сам
користувач (NFR-17@PoC v2 п. 11); **Інструмент** — не отримує даних користувачів.

## Інструкції для браузера

Дії, які потребують облікового запису власника, описано як завдання для локальної сесії Claude з
браузером (рішення власника 2026-11-12): сесія виконує кроки сама і зупиняється лише для входу,
юридичної згоди, оплати і збереження секретів у менеджер паролів власника. Нове завдання пишеться
за skill `browser-task` (`.claude/skills/browser-task/SKILL.md`).

| Завдання | Що робить | Де |
| --- | --- | --- |
| browser-task-01 | Resend (ключ для вже підтвердженого домену, EU) і віджет Cloudflare Turnstile «Willowsum» для `willowsum.mina.yachts` | [`browser-tasks/01-mail-captcha.md`](browser-tasks/01-mail-captcha.md) |
| OCI account | Обліковий запис OCI, MFA, бюджет, другий регіон (інструкція для власника, створена до рішення 2026-11-12) | [`infra/start/owner-setup.md`](../../infra/start/owner-setup.md) |
