## Порядок PR

Ч — чутливий PR (автентифікація, права, шифрування, гроші, схема БД, конвеєр, інфраструктура;
`tools/pr-rules/lib/paths.mjs`); йому потрібна окрема рецензія безпеки. Кожен PR, що створює таблиці або змінює

D для файлів (рядок 38 дає сховище, яке копіює рядок 160).
