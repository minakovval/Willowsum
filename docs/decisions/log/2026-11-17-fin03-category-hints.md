# Рішення 2026-11-17: підказки категорії «Нової транзакції» — FIN-03@PoC FR 30, FR 31 (серверна частина, #438)

Малі рішення виконавця PR «FIN-03: category hints for «Нова транзакція» — FR 30, FR 31 server part»; власник їх не
схвалював.

- Рішення ведучого (2026-11-17; власник не схвалював; FIN-03 FR 30, FR 31): підказки — один маршрут лише для читання
  `GET /v1/category-suggestions` модуля `categorization` (там категорії транзакцій і правила; мерчанти й транзакції — через
  їхні публічні інтерфейси). Прапорець випуску і ключ функції — `categorization.suggestions`, потребує
  `categorization.rules`; ліміту плану немає (FIN-03 його не називає).
- Рішення ведучого (2026-11-17; власник не схвалював; FIN-03 FR 30, FR 15): порядок підказки — перше ввімкнене правило
  без «Потребує уваги», що підходить, як для нової транзакції (BUD-14 FR 8); потім остання категорія «вручну» цього
  мерчанта. Правило з умовою «Сума» чи «Рахунок» (або «Лише для рахунків») враховується, лише коли форма передала суму
  чи рахунок кроку 1. Якщо категорія правила не підходить (прихована, не того типу), підказкою стає «як раніше», а не
  наступне правило: перше правило, що підходить, вирішує, як і для нової транзакції.
- Рішення ведучого (2026-11-17; власник не схвалював; FIN-03 FR 31): «Часто для <мерчанта>» і «Нещодавні» — до 3
  категорій кожна (на дошці `PocMoneyNewTxCat` — 2). «Часто для» рахує категорії транзакцій мерчанта з будь-яким джерелом,
  більше — вище, нічия — новіша; «Нещодавні» — різні категорії найновіших транзакцій простору. Відомий мерчант без
  жодної категорії — «Нещодавні» замість порожньої групи.
- Рішення ведучого (2026-11-17; власник не схвалював; FIN-03 FR 30, FR 31): пропонується лише категорія в ужитку, не
  прихована (у списку форми прихованих немає) і, коли форма передала тип, того самого типу. Історія — найновіші
  20 000 показаних транзакцій простору (межа одного запиту, як у «Показати» правил BUD-14 FR 7), не сторони переказу, не
  розділені, не злиті; поле `truncated` каже, що є старіші.
- Рішення ведучого (2026-11-17; власник не схвалював; FIN-03 FR 30): категорія біля кожного відомого контрагента
  («23 транзакції · Продукти») — та сама підказка для назви мерчанта з тими самими сумою, рахунком і типом; мерчант без
  підказки в `merchants` не входить.
