# Рішення 2026-11-21: ліміт на місці, рядок «Додати категорію» і «N транзакцій» (BUD-02@PoC п. 7, п. 23, AC 19)

**Створено:** 2026-11-21

Дрібні деталі, які BUD-02@PoC і дошки PocPlanBudget, PocPlanBudgetAddCat не задають, вирішено в PR «BUD-02: limit
popover, add row and the transaction count of «Видалити категорію…»».

- Рішення ведучого (2026-11-21; власник не схвалював; BUD-02 п. 23): «N транзакцій» — наявні транзакції простору з
  цією категорією (приховані теж, відкочені — ні). Нерозділена транзакція рахується за власною категорією (модуль
  categorization), розділена — один раз, якщо хоч одна її частина має цю категорію (модуль transactions); власну
  категорію розділеної не рахуємо, щоб не рахувати транзакцію двічі. Кількість читає новий
  `GET /v1/categories/{categoryId}/usage` через порт `CategoryUsage.transactions` модулів, без SQL між модулями.
- Рішення ведучого (2026-11-21; власник не схвалював; BUD-02 п. 23, AC 19): у діалозі непорожньої категорії кількість
  стоїть першим реченням пояснення: «12 транзакцій. Цю категорію не можна видалити: …». Кількість 0 (системна
  категорія без транзакцій) і невдале читання кількості — пояснення без числа; «Приховати» і «Об'єднати з іншою…»
  лишаються. Форми «1 транзакція», «3 транзакції» — варіант від агента (у вимозі є лише «N транзакцій»).
- Рішення ведучого (2026-11-21; власник не схвалював; BUD-02 п. 7): поповер ліміту має поле «Ліміт» і кнопки
  «Скасувати» / «Зберегти» (тексти дошок PocPlanBudget і PocPlanBudgetTarget); його назва — «Змінити ліміт «…»»
  (aria-мітка олівця з дошки). Рядок «Поза планом» має кнопку «Задати ліміт» (дошка); назва її поповера
  «Задати ліміт «…»» — варіант від агента. Ліміт змінюється в поточному й майбутньому місяці, у минулому — ні (його
  план — знімок, п. 11).
- Рішення ведучого (2026-11-21; власник не схвалював; BUD-02 п. 7): рядок «Додати категорію» пропонує всі категорії
  витрат простору без ліміту, не приховані (не лише групи, з якої його відкрито): з лімітом категорія стає в рядок своєї
  групи. Розділ «Поза планом · є витрати» — категорії «Поза планом» з витратами цього місяця, рядок
  «<назва> · <сума> цього місяця» (дошка). Підказка «сер. N €» — середнє за 3 міс. із `GET /v1/budget/wizard`; без
  історії поля без підказки. «✓» спершу зберігає ліміт, потім, якщо перемикач змінено, атрибут «обов'язкова» категорії.
  Назва розділу «Без ліміту» з дошки; «Додати» / «Скасувати» — підписи «✓» / «✕» (дошка).
