# Рішення ведучого 2026-11-18: тести GRID-00 (частина 2), назви в два рядки

**Створено:** 2026-11-18

- Рішення ведучого (2026-11-18; власник не схвалював): GRID-00 пункт 18 / AC 5 / EC 2 — `TruncatedText` отримав
  властивість `maxLines={2}` (за замовчуванням 1, поведінка не змінена). Драбина назви з DS-05 і `design-system-doc.md`:
  один рядок, один рядок 85 %, два рядки 85 % (довге слово без пробілів ламається за символами,
  `overflow-wrap: anywhere`), далі трикрапка. Крок задає атрибут `data-fit` (`one`, `smaller`, `two`); правила —
  `.ws-truncate--name` у `components.css`, `-webkit-line-clamp: 2`. Підказка і фокус з'являються лише тоді, коли
  назва не вміщується і в два рядки. Застосунок цю властивість поки не викликає: сторінок з картками, цілями й
  рахунками, що виводять назви, у PoC ще немає в потрібному вигляді (див. Follow-ups PR).
