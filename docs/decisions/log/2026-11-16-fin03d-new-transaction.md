# Рішення 2026-11-16: «Нова транзакція» S-048 і «+ Додати → Транзакція» S-025 (FIN-03 d), рядок 116)

Малі рішення виконавця PR «FIN-03 d): «Нова транзакція» S-048 and «+ Додати → Транзакція» S-025 (row 116, part 1)»;
власник їх не схвалював.

- Рішення ведучого (2026-11-16; власник не схвалював): рядок 116 розбито на два PR. Цей — S-048 разом із входами в
  нього (S-025 «+ Додати → Транзакція», кнопка «Нова транзакція» в шапці «Транзакцій», маршрут
  `/money/transactions/new`); S-047 «Деталь транзакції» — наступним PR. Причина: S-047 і S-048 разом більші за
  ≈ 1 500 рядків без тестів, а S-047 відкривається з таблиці S-046 (рядок 115), якої ще нема; меню S-025 без форми не
  має що відкрити, тож воно йде з S-048.
- Рішення ведучого (2026-11-16; власник не схвалював): тип «Переказ між рахунками» (FIN-03 FR 1, FR 28) у формі поки
  не показано: API не створює переказ однією дією (обидві ноги й отриману суму в іншій валюті). Це серверна частина,
  її не будували в цьому PR; до неї перемикач типу має два варіанти.
- Рішення ведучого (2026-11-16; власник не схвалював): категорію і теги API приймає лише окремими запитами після
  створення. Форма створює транзакцію одним запитом із ключем ідемпотентності (повторне натискання не створює
  дубль), потім ставить категорію і теги; якщо ці запити не вдалися, форма каже, що транзакцію додано без них, і
  пропонує змінити їх у деталі.
- Рішення ведучого (2026-11-16; власник не схвалював): «сьогодні» для поля «Дата» (FR 29) рахується в часовому поясі
  Europe/Kyiv, доки API не віддає «сьогодні» простору (рядки 176–178 хвилі 2).
- Рішення ведучого (2026-11-16; власник не схвалював): категорія в списку має колір групи (`chart-cat-N` за порядком
  групи витрат, `chart-group-income-N` для доходів) і загальну іконку: іконки й відтінки категорій з API — не
  токени дизайн-системи.
- Рішення ведучого (2026-11-16; власник не схвалював): пояснення без рахунків — текст дошки `PocMoneyNewTxNoAcc`
  («Рахунків ще немає. …»), а не текст FIN-03 FR 32 («Щоб записати транзакцію, потрібен рахунок»): за правилом
  `docs/design/ARTIFACTS.md` перемагає канва.
- Рішення ведучого (2026-11-16; власник не схвалював): «Імпортувати виписку» — посилання у формі (UX-09 FR 14, AC8),
  а не пункт меню «+ Додати», як на дошці `PocAdd`: UX-09 AC10 дозволяє в меню лише три пункти.
