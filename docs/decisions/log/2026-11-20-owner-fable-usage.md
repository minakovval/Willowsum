# Рішення 2026-11-20: Fable лише для доступу, входу, шифрування і схеми бази

## Питання (дослівно)

«Як скоротити Fable? а) (рекомендую) Fable лише для доступу, входу, шифрування і схеми бази. Сюди потрапляють PR з мітками permissions, auth, encryption або schema. PR лише про гроші й усі повторні перевірки йдуть на Opus із тим самим чек-листом безпеки та мутаційними тестами. Fable стане приблизно на 60–70 % менше. Ризики й мінуси: Opus може пропустити тонку помилку в грошовій логіці. Сьогодні Fable знайшов таку в #643: виписка кредитної картки тихо перевертала знаки. Як пом'якшити: для грошових PR мутаційні тести стануть обов'язковими. Раз на день один агент Fable читає лише вже злиті грошові PR, і це дешевше, ніж перевіряти кожен окремо. б) Лише повторні перевірки переходять на Opus, перша перевірка безпеки грошових PR лишається на Fable (≈ 30 % менше). в) Без змін, але не більше одного Fable одночасно.»

## Варіанти

- а) (рекомендація) Fable лише для PR з мітками `permissions`, `auth`, `encryption`, `schema`; PR лише про гроші і всі повторні перевірки — Opus; мутаційні тести грошової логіки обов'язкові; раз на день один агент Fable читає злиті грошові PR (≈ 60–70 % менше Fable).
- б) Лише повторні перевірки на Opus, перша перевірка безпеки грошових PR лишається на Fable (≈ 30 % менше).
- в) Без змін, але не більше одного Fable одночасно.

Рішення власника (2026-11-20): а).
