# Рішення 2026-11-16: зірочка «Обране» на рахунку (FIN-01@PoC п. 20)

Рішення власника, яке виконує PR «FIN-01: «Обране» on an account»: 2026-11-16, п. 2а — «додати поле в PoC окремим
невеликим PR» (запис — `docs/decisions/log/2026-11-16-owner-answers-413-417.md`). Малі рішення виконавця нижче власник не
схвалював.

- Рішення ведучого (2026-11-16; власник не схвалював): «Обране» зберігається як колонка `accounts.accounts.favourite`
  (`boolean NOT NULL DEFAULT false`, міграція `0007_favourite.sql`, крок expand: попередній код її не називає, його нові
  рахунки — не в обраному).
- Рішення ведучого (2026-11-16; власник не схвалював): маршрут — `PATCH /v1/accounts/{accountId}/display`
  `{ favourite: boolean }` (розділ «Показ» налаштувань рахунку, FIN-12 п. 4); той самий маршрут прийме пізніше
  «Враховувати в net worth». Те саме значення ще раз нічого не пише.
- Рішення ведучого (2026-11-16; власник не схвалював): «Обране» — прапорець показу, тож закритий рахунок теж його
  змінює (FIN-12 п. 8: «доступний лише для читання, крім прапорців показу»).
- Рішення ведучого (2026-11-16; власник не схвалював): кожна зміна пише запис аудиту `accounts.account`/`update` з полем
  `favourite` до й після (жорстке правило «кожна зміна даних — запис аудиту»).
- Рішення ведучого (2026-11-16; власник не схвалював): список `GET /v1/accounts` лишається в порядку додавання (курсор
  сторінок); «Обране» вгорі групи ставить сторінка, решта рядків — у тому порядку, що й раніше (сортування заголовками
  колонок прийде з FIN-12).
- Рішення ведучого (2026-11-16; власник не схвалював): зірочка стоїть у клітинці назви перед логотипом, як на дошці
  PocMoneyAccounts. Дошка малює обрану зірочку кольором акценту, але застосунок акцентом не фарбує (DS-06 AC4), тому
  обрана зірочка залита кольором `brand` (3:1 на картці), необрана — контур `ink-muted`; стан видно і за формою.
- Рішення ведучого (2026-11-16; власник не схвалював): зірочка змінюється одразу, а якщо сервер відмовив — повертається
  разом із порядком, і над групами з'являється «Не вдалося змінити «Обране». Спробуйте ще раз.» (англ. «Couldn't change
  favourites. Please try again.»); цього тексту немає на дошці «Тексти» S-050.
