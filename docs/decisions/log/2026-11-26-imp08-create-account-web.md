# Рішення 2026-11-26: «Створити рахунок» у кроці «Рахунок і файли» (IMP-08, рядок 230a, web)

**Створено:** 2026-11-26

Дрібні деталі web-частини IMP-08@PoC п. 2 і критерію 16 («Створити рахунок», рішення власника 2026-11-26, Q7 п. 1,
[журнал](2026-11-26-owner-corrections.md); сервер — [рядок 230](2026-11-26-imp08-detected-account.md)).

- Рішення ведучого (2026-11-26; власник не схвалював; row 230): «коротка форма нового рахунку» — це наявна форма
  «Новий рахунок» (S-052, FIN-01 FR 3, три кроки), що відкривається поверх кроку з даними файлу: тип «Поточний», назва
  — назва банку з файлу, банк (за назвою довідника), валюта, останні 4 символи картки чи IBAN. Другої форми немає: одна
  форма — одні перевірки (дублікат, довжини, повний номер картки не приймається) і один запит `POST /v1/accounts`.
  Залишок на дату людина вводить сама: файл його не каже, а поле обов'язкове.
- Рішення ведучого (2026-11-26; власник не схвалював; row 230): пропозиція «Створити рахунок» з'являється під файлом,
  що чекає на рахунок («Оберіть рахунок»), коли файл називає банк або маску картки чи IBAN і жоден активний рахунок
  простору не закінчується на ці 4 символи. Однієї валюти замало; файл, розібраний для наявного рахунку («визначено
  автоматично»), пропозиції не має (там є «Змінити рахунок»).
- Рішення ведучого (2026-11-26; власник не схвалював; row 230): у форму потрапляє лише маска виду «…» і 4 символи
  (`maskTail`); будь-який довший текст у `mask` форма не бере, номер лишається порожнім. Повного номера картки чи IBAN
  web не бачить, не показує і не зберігає.
- Рішення ведучого (2026-11-26; власник не схвалював; row 230): після збереження список рахунків читається знову без
  скелета (форма й крок лишаються на місці), файл розбирається для нового рахунку тим самим запитом, що й будь-який
  вибір (`POST …/parse` з `accountId`), а під файлом стоїть «Рахунок «{назва ··4 символи}» створено і вибрано для
  файлу». Скасування форми нічого не створює; помилка збереження лишає форму з її текстом помилки.
- Тексти «Такого рахунку ще немає», «Створити рахунок» і «Рахунок «{account}» створено і вибрано для файлу» — з канви
  (блок «Тексти» S-170, «Корекції власника 2026-11-26»), позначені там «варіант від агента, потребує погодження».
  Кнопка «Створити рахунок» не має окремої доступної назви з іменем файлу (як і «Змінити рахунок»); дві кнопки в двох
  рядках розрізняє контекст рядка.

Відкрите питання власнику (з рядка 230, не вирішене): довідник банків — банки НБУ, тож Revolut із критерію 16 у ньому
немає, сервер банк не визначає, і форма відкривається з порожнім банком (людина обирає «Інша установа»). Тест
критерію 16 дає довіднику Revolut, щоб перевірити саме підстановку; чи визначати банк і поза довідником, вирішує
власник.
