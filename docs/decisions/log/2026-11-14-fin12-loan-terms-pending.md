# Рішення 2026-11-14: FIN-12@PoC b) — кредит без умов після зміни типу лише з позначкою

**Створено:** 2026-11-14 · **Оновлено:** 2026-11-14

Раунд виправлень PR #233 «FIN-12: rename and change of kind within the group — server part b». Замінює пункт про
`liabilities` `0002` у [2026-11-14-fin12-rename-kind.md](2026-11-14-fin12-rename-kind.md).

- Рішення виконавця (2026-11-14; власник не схвалював; FIN-12, ARC-03 п. 4): міграція `0002` не знімає правило бази
  «кредит має ставку і платіж і не має пільгового періоду», а розширює його: нова колонка `terms_pending boolean NOT NULL
  DEFAULT false` (лише для кредиту) позначає кредит після зміни «Кредитна картка» → «Кредит», і тільки для нього база
  пропускає відсутні ставку й платіж (AC12); пільговий період кредиту база й далі не пропускає. Позначку ставить лише
  `changeKind` (`termsMissing`). Причина: крок CI «старий код + нова схема» (ARC-03 п. 4) — тест базової версії
  `fin01-liabilities.it.test.ts` перевіряє, що база відмовляє кредиту без умов; попередній код позначки не ставить, тож
  кожен його рядок підлягає тому самому правилу, що й раніше. Нове обмеження позначене `-- ws:contract 0001_liabilities.sql`
  з причиною, як розширення перевірок у `identity` `0003`.
