# Рішення 2026-11-18: «До розбору» — група «Без мерчанта», відміна групи; тексти S-053

**Створено:** 2026-11-18

Джерело: відповіді власника ведучому в чаті 2026-11-18 (≈ 08:00 UTC) на три питання. На кожне власник відповів
дослівно «як радиш» — це рекомендований варіант питання.

1. Питання: «Чи можна на екрані «До розбору» підтверджувати всю групу «Без мерчанта» одним натисканням?»
   Варіанти: а) так, як будь-яку групу, лише без «Запам'ятати», бо мерчанта немає (рекомендовано); б) ні, лише по одній;
   в) так, з попередженням. Рішення власника (2026-11-18): «як радиш» = а). Записано в BUD-12@PoC п. 14 (режим
   «Мерчанти») і в новому критерії приймання. Поведінка екрана вже збігається з рішенням. Власник скасував це
   2026-11-26: групи «Без мерчанта» немає, такі транзакції розбирають по одній ([журнал](2026-11-26-owner-corrections.md), Q4).
2. Питання: «Чи потрібна відміна підтвердження цілої групи?» Варіанти: а) ні; б) так, кнопкою «Відмінити» у спливному
   повідомленні (рекомендовано; сервер це вже вміє, треба дописати вимогу); в) через звіт масової дії. Рішення власника
   (2026-11-18): «як радиш» = б). Записано в BUD-12@PoC п. 6 і в новому критерії приймання; строк — той, що повертає API
   масової дії (`undo.available`, `undo.until`: 24 години після завершення дії; модуль `bulk-actions`, DAT-03@PoC).
   Текст сповіщення — на дошці `PocMoneyReviewTexts` («Дія сповіщення після групи» — «Відмінити», той самий текст, що
   вже стоїть у «Дія сповіщення»); позначки «потребує погодження» немає, бо варіант обрав власник. Екран цього ще не
   вміє: UI — окремий PR (див. тіло PR, «Follow-ups»).
3. Питання: «Тексти агента на дошці S-053 «Картка рахунку · Тексти»: а) схвалити всі (рекомендовано) / б) переглянути
   кожен». Рішення власника (2026-11-18): «як радиш» = а). На дошці `PocMoneyAccountTexts` знято позначки і речення
   вступу про погодження; самі тексти не змінено. Примітка: на дошці стояли позначки «погоджено власником 2026-11-17»
   (замість «варіант від агента…», рішення 2026-11-17, `2026-11-17-owner-answers-five.md`), хоча
   `2026-11-17-owner-batch.md` казав, що дошку S-053 не змінено; відповідь 2026-11-18 це знімає — позначок немає.
