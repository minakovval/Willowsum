# Рішення 2026-11-21: IMP-02@PoC — MCC, нульова комісія і «—» у виписці картки (#694)

**Створено:** 2026-11-21 · **Оновлено:** 2026-11-21

Дрібні деталі, які IMP-02@PoC п. 3, 4, 7, 12 не задають, вирішено в PR «IMP-02: an MCC code column is never an
amount, «—» is an empty number» (#694). Нових рішень власника тут немає.

- Рішення ведучого (2026-11-21; власник не схвалював; IMP-02): колонка кешбеку («Сума кешбеку (UAH)», «Кешбек»,
  «Cashback») має роль «ігнорувати» для суми, а не примітку. П. 4 не називає кешбек серед полів операції, а банк
  зараховує кешбек на рахунок окремою операцією; примітка з сумою кешбеку дублювала б цю операцію. Роль можна змінити в
  рецепті (IMP-06 п. 1).
- Рішення ведучого (2026-11-21; власник не схвалював; IMP-02 п. 4): колонка, усі заповнені клітинки якої — цілі
  0000–9999 (до чотирьох цифр, без знака й дробової частини), а заголовок містить слово «MCC» або «код», ніколи не
  отримує ролі суми, дебету, кредиту, залишку, комісії, початкової суми чи курсу; вона ігнорується з доказом «слово
  заголовка».
- Рішення ведучого (2026-11-21; власник не схвалював; IMP-02 п. 4): коли колонку суми вже визначено, числова колонка
  без слова «дебет» або «кредит» у заголовку не стає дебетом чи кредитом лише за вмістом: файл має або колонку суми, або
  пару «дебет / кредит». Інакше дві нульові колонки (комісія і кешбек `0.00`) перемикали знак на «дебет / кредит».
- Рішення ведучого (2026-11-21; власник не схвалював; IMP-02 п. 4, п. 12): «—» і «–» у клітинці — порожня клітинка для
  рішень рушія щодо колонок. «Курс» із «—» у рядках без конвертації — колонка курсу, курс таких рядків порожній, а
  перевірка курсу (п. 12) виконується для рядків із курсом.
- Рішення ведучого (2026-11-21; власник не схвалював; IMP-02 п. 4): заголовок «Сума в валюті картки» — окрема фраза
  колонки суми, тож вона переважає інші колонки «Сума …»; «Сума комісій» — фраза колонки комісії. Фрази додано окремим
  словником у `analysis.ts`, щоб не змінювати рядки основного словника, які змінює PR #696.
