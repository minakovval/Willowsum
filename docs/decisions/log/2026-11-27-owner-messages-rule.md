# Рішення власника 2026-11-27: мова і тиша перед кожним повідомленням власнику (PRC-02)

**Створено:** 2026-11-27

## Причина

Ведучий 34 надсилав власнику англійські проміжні статуси після нагадувань середовища («The user hasn't heard from you…»).
Причина: англомовні звіти агентів і нагадування; правило («Мовчання в чаті», `pr-pipeline` SKILL.md) було в стиснутому
підсумку контексту, але не перевірялося перед кожним повідомленням.

## Рішення

- Рішення власника (2026-11-27): рядок у `.claude/skills/pr-pipeline/references/restarts.md`, розділ «After compaction»
  (перший крок): перед кожним повідомленням власнику — лише українська; лише злиття / питання / проблема / підсумок;
  на нагадування «The user hasn't heard from you…» і сповіщення без справи для власника — лише «Нічого нового для вас.»
  Відповідь власника на пропозицію ведучого «а» (рядок у restarts.md і в #179 про мову і мовчання), дослівно: «так».
