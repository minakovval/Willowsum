# FLW-44: тексти кредитної картки у «Плані погашення» і «Стратегії»

**Створено:** 2026-11-27

Рішення власника (2026-11-27): схвалено три тексти, що в #737 були тимчасовими («варіант від агента»). Власник у чаті
відповів «як радиш», а на рекомендацію ведучого — «так».

- Поле суми картки: «Зменшувати на … / міс.» → «Гасити щомісяця: …» (en: «Pay off monthly: …»,
  `debts.plan.field.cardAmount`).
- Підказка «Вкажіть, скільки щомісяця гасите з картки» лишається без змін (en — як було, `debts.card.amountHint`).
- Рядок картки на «Стратегії»: «Зменшувати на … / міс.: {name}» → «{name}: гасити … / міс.» (en: «{name}: pay off … /
  mo.», `debts.strategy.cardAmountOf`).
- Вступ «Стратегії», коли бракує лише місячної суми картки (немає боргу без ставки чи платежу): замість «Вкажіть
  мінімальний платіж і ставку …» — підказка «Вкажіть, скільки щомісяця гасите з картки». Коли бракує й інших даних —
  вступ без змін (`debts.strategy.enter`).

Змінено: `packages/i18n`, `apps/web/src/debts`, дошка `PocPlanDebtsTexts` (рядки «Тексти» тепер «погоджено власником»,
додано рядок вступу), цитати в джерелах `BUD-19.md` і `FLW-44.md` (перегенеровано подання; відбитки оновлено лише для
12 + 10 пунктів, у яких була цитата), знімки `docs/validation/screenshots/flw44-card-*-1280.png`.
Не змінено: текст опису поля в API (`apps/api`, `openapi.json`) — це службовий опис, не екранний текст.

- Рішення ведучого (2026-11-27; власник не схвалював; FLW-44 тексти): вступ «Стратегії» показує підказку картки, коли
  кожен борг, якому бракує даних, — картка; у змішаному випадку лишається старий вступ.
