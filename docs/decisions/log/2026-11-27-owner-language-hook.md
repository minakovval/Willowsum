# Рішення власника 2026-11-27: хук `Stop` перевіряє мову повідомлень ведучого власнику (PRC-02)

**Створено:** 2026-11-27

## Причина

Правило власника — кожне повідомлення ведучого власнику українською (`pr-pipeline` SKILL.md «Мовчання в чаті»;
`.claude/skills/pr-pipeline/references/restarts.md`; #179; `2026-11-27-owner-messages-rule.md`) — знову порушено:
його ніщо не перевіряло механічно.

## Рішення

- Рішення власника (2026-11-27): схвалено хук `Stop` у сесії ведучого — `tools/lead-hooks/owner-language.mjs`,
  зареєстрований у `.claude/settings.json` (тайм-аут 10 с; хук `SessionStart` без змін). Ведучий запропонував хук;
  власник спитав про ціну («які ресурси витрачаються на хук?») і межі («це код який буде спрацьовувати всередині
  застосунку?» — відповідь ведучого: ні, лише в сесії Claude Code ведучого), потім відповів: «добре».
- Що робить: у сесії, де завантажено skill `pr-pipeline`, бере текст останнього повідомлення асистента, прибирає код,
  посилання, шляхи, SHA та ідентифікатори, @-згадки; якщо лишилося ≥ 40 літер і латинських більше, ніж кириличних, —
  блокує завершення ходу з причиною «Повідомлення власнику має бути українською: перепиши його українською (код,
  шляхи й назви лишай як є).» `stop_hook_active` → пропускає (без циклу); будь-яка помилка → пропускає.
- Ціна: локальний процес Node без мережі й залежностей, читає лише файл транскрипту, десятки мілісекунд на хід.
  Якщо хук заблокував хід — один додатковий хід моделі на переписування.

## Дрібні рішення ведучого

- Рішення ведучого (2026-11-27; власник не схвалював): сесію ведучого визначає лише виклик skill `pr-pipeline`
  (інструмент `Skill` або команда `/pr-pipeline`), а не нагадування хука `SessionStart` після стиснення: те
  нагадування бачить будь-яка сесія після стиснення (зокрема сесії рецензентів), а ведучий після нього однаково
  знову викликає `pr-pipeline`. Субагенти завершуються подією `SubagentStop`, тож хук їх не зачіпає.
- Ризики / мінуси / як пом'якшити: короткий англійський рядок (< 40 літер) не ловиться — правило в SKILL.md лишається;
  довга цитата англійського звіту агента в українському повідомленні може заблокувати хід — цитату варто брати в
  `код` або скорочувати; хибне блокування коштує один хід, а повторна зупинка (`stop_hook_active`) завжди проходить.
