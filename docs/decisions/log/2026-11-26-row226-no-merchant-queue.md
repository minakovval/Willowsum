# Рішення ведучого 2026-11-26: черга без групи «Без мерчанта» (рядки 226 і 226a)

**Створено:** 2026-11-26

Виконання рішення власника Q4 з [журналу 2026-11-26](2026-11-26-owner-corrections.md) (BUD-12 FR 14, FR 16, AC 11).

- Рішення ведучого (2026-11-26; власник не схвалював; row 226): рядки 226 і 226a зроблено одним PR і тільки в web.
  Причина: сервер лише віддає транзакції без мерчанта як набір `none` (список id і кількість); групою для користувача
  його робить лише `ReviewQueue.tsx`. Сервер не змінено, його тести про `none` лишаються; їхні назви уточнено.
- Рішення ведучого (2026-11-26; власник не схвалював; row 226): у режимі «Мерчанти» набір `none` не показується
  групою; його транзакції — розділом «Без мерчанта · по одній» під групами, картками по одній, найстаріша перша.
- Рішення ведучого (2026-11-26; власник не схвалював; row 226): запропонований мерчант — `merchant` з
  `GET /v1/category-suggestions?counterparty=<опис банку>`; API окремого «мерчант з тексту» не має. Картка без
  мерчанта і без тексту пропозиції не має.
- Рішення ведучого (2026-11-26; власник не схвалював; row 226): кнопки «Прийняти» немає — вона нічого не зберігала б і
  вводила б в оману. «Мерчант з опису банку: X» — лише підказка на картці; вибір категорії одразу використовує X
  («Часто для X»), без мерчанта чи без пропозиції — «Нещодавні» (FR 16). Збереження мерчанта на транзакції і аудит —
  рядок 228 (сервер).
- Рішення ведучого (2026-11-26; власник не схвалював; row 226): нові тексти S-058 (розділ, пояснення, «Мерчант з опису
  банку:») записано на полотні «Тексти» з позначкою «варіант від агента, потребує погодження».
