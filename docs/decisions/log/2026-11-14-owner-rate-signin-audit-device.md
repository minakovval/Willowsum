# Рішення власника 2026-11-14: курс НБУ для проводок між валютами, журнал входів, пристрій для листа «Новий вхід»

**Створено:** 2026-11-14 · **Оновлено:** 2026-11-14

Джерело: чат власника з ведучим, 2026-11-14 (≈ 10:00 UTC), відповідь на пронумеровані питання ведучого:
«1 — НБУ, 2 — журнал простору, 3 — браузер + ОС». Пакетний PR `PRC-02` (лише документи, без коду). Контекст:
#195 і доробки #201 (питання 1), тіло #198 «owner question» (питання 2), рецензія 5903335052 на #198 (питання 3).

- Рішення власника (2026-11-14): схвалено «1 — НБУ»: курс для операцій між валютами, які модулі-виклики
  (`transactions`, `accounts`) проводять у журнал (FIN-04, ARC-11), — офіційний курс НБУ з `fx-rates` на дату операції,
  а не фактичний курс банку. Тексти: ARC-11 («Запис проводок»), FIN-04 (граничний випадок). Для MVP джерело курсу
  лишається за VAL-04@MVP (ECB для основних валют, НБУ для гривні) — власник про нього не відповідав.
- Рішення власника (2026-11-14): схвалено «2 — журнал простору»: записи входів, невдалих входів і завершень сесій з
  IP-адресою і пристроєм (ACC-04 a3; NFR-15 п. 6, 7, 29; NFR-01 п. 10) зберігаються в журналі аудиту простору і
  видаляються разом із простором (NFR-12: «Журнал аудиту простору — поки існує простір»). Тексти: ACC-04 (бізнес-правило),
  NFR-15 п. 29; NFR-12 і NFR-01 уже узгоджені, не змінювалися.
- Рішення ведучого (2026-11-14; власник окремо не схвалював; ACC-04): разом із питанням 2 пішла рекомендація ведучого:
  невдалі входи для адреси без акаунта чи простору і для непідтвердженого акаунта не записуються зовсім (немає
  простору, в журнал якого писати, і немає причин зберігати чужу IP-адресу). Записано в ACC-04.
- Рішення власника (2026-11-14): схвалено «3 — браузер + ОС»: «новий пристрій» для листа «Новий вхід» (ACC-04 п. 4,
  AC6; NFR-15 п. 29) — браузер і операційна система без версії, а не весь `User-Agent`; оновлення версії браузера листа
  не дає. Це скасовує рішення ведучого з `2026-11-14-acc04-new-device-not-me.md` (там додано примітку, історію не
  видалено).

## Залежні зрізи і доробки (код цим PR не змінюється)

`--impact` для ACC-04, FIN-04, ARC-11, NFR-15, NFR-01: зрізи, що змінилися за змістом, — ACC-04@PoC/PoC v2/MVP/v1-mobile
(рядок бізнес-правила), ARC-11 і FIN-04 @PoC/PoC v2/MVP, NFR-15 @PoC/PoC v2/MVP/v2 (п. 29); решта залежних зрізів
(98 / 500 / 665) читає ці правила через «Зв'язки» і тексту не потребує. Доробки (issue відкриває ведучий):

- ACC-04 a3 (рядок 9a3 плану хвилі 2): журнал входів з IP і пристроєм у журналі аудиту простору, AC4, EC1; **тут же** код
  рішення 3 — ідентифікатор пристрою з браузера і ОС без версії (зараз у `identity` — весь `User-Agent`, `device.ts`,
  SHA-256 історії входів; потрібна міграція історії входів, щоб існуючі записи не дали зайвих листів), і тести
  `acc04-new-device`/`device.test.ts` за новим правилом.
- Доробка #201 (FIN-04): модулі `transactions` і `accounts`, що викликають події `fx-transaction`/`fx-transfer`, беруть
  курс НБУ з `fx-rates` на дату операції (не фактичний курс банку) і передають його ledger як явний `ExchangeRate`.
- Рішення власника для MVP про джерело курсу в проводках (VAL-04@MVP: ECB для основних валют) — не запитувалося.
