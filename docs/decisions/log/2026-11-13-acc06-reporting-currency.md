# Рішення 2026-11-13: ACC-06@PoC — валюта звітності простору (серверна частина)

**Створено:** 2026-11-13 · **Оновлено:** 2026-11-13

Дрібні технічні рішення виконавця PR «ACC-06: reporting currency of the space — server side» (рядок 8 плану
`docs/plans/poc-wave-2.md`), модулі `household` і `fx-rates`. Питання власнику — у тілі PR.

- Рішення ведучого (2026-11-13; власник не схвалював; цей PR): рядок 8 плану називає «зміну з перерахунком через
  `fx-rates`», але ACC-06@PoC зміни не має — валюта звітності завжди EUR без вибору (FR 1, FR 2). Джерело правди —
  текст вимоги: маршруту зміни валюти немає, `reportingCurrency` у тілі `PATCH /v1/space` ігнорується. Зміна з
  перерахунком — ACC-06@MVP.
- Рішення ведучого (2026-11-13; власник не схвалював; цей PR): валюта звітності — стовпець
  `household.households.reporting_currency` (ISO 4217) зі значенням за замовчуванням `EUR` для наявних просторів і
  перевіркою бази `= 'EUR'` (правило PoC і в базі; реліз із вибором валюти послаблює перевірку власною міграцією).
  Новий простір записує `EUR` явно; запис аудиту створення простору має поле `reportingCurrency`. `GET` і
  `PATCH /v1/space` повертають `reportingCurrency` (розширюваний перелік, зараз лише `EUR`). Нового прапорця немає: поле
  віддають маршрути за наявним прапорцем `household.space-settings`.
- Рішення ведучого (2026-11-13; власник не схвалював; цей PR): довідник конверсій (бізнес-правило, граничний
  випадок 2) — `fx-rates/domain/fixed-conversions.ts`, застосовується в `FxRates.rate` і `FxRates.rates`, тож
  однаково в `convert`, `createFxReporting` і підсумках списків (`officialDatedRates`). Від дати заміни пара валюта ↔
  наступник має фіксований курс датою запиту (курс кожного дня — не «приблизно»), джерело `EU`; валюта → наступник —
  обернений курс із 18 знаками (похибка нижче 10^-18 на одиницю). Зараз у довіднику лише BGN → EUR (1,95583 з
  2026-01-01): HRK domain-kernel не приймає (NFR-06), тож AC5 відкрито питанням власнику. Питання AC5 вирішено рішенням власника 2026-11-14, див. `2026-11-14-owner-answers-queue-retention-hrk.md`. Крос-курс через наступника
  (BGN → USD) не будується — у PoC валюта звітності лише EUR. Прапорця немає, як і в VAL-04: це правило читання
  курсу, а не нова функція.
- Рішення ведучого (2026-11-13; власник не схвалював; цей PR): FR 3, AC2, AC3, AC4 і граничний випадок 1 у цьому PR
  перевірено з боку сервера (валюта простору з API і дані підказки «≈»: оригінальна сума, курс, дата курсу, джерело,
  «найближчий доступний курс»); саму підказку (наведення, фокус із клавіатури) і показ сум перевіряє UI — рядок 111.
