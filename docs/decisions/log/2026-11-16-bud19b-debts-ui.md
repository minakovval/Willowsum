# Рішення 2026-11-16: BUD-19@PoC b) — «Борги», частина 1 (S-143, S-146)

**Створено:** 2026-11-16

Дрібні рішення виконавця PR «BUD-19: «Борги» — page, tabs, list and progress (UI part b1)» (план
`docs/plans/poc-wave-2.md`, частина F, рядок 131). Екрани S-144 «План погашення» і S-145 «Стратегія» — наступні PR
того самого рядка.

- Рішення власника (2026-11-16), передане ведучим: у PoC мінімальний платіж кредитної картки вводиться в сценарії;
  збереженого поля немає до PoC v2. Стосується S-144 і S-145 (наступні PR); цей PR його не змінює.
- Рішення ведучого (2026-11-16; власник не схвалював; BUD-19 b): вкладки «Борги · План погашення · Стратегія ·
  Прогрес» — окремі адреси (`/planning/debts`, `/planning/debts/plan`, `…/strategy`, `…/progress`, як у
  `docs/ux/screen-map.md`); вкладка — посилання з `role="tab"` (CMP-11 «Вкладки сторінки», компонент `PageTabs` у
  `packages/ui`), ← → відкривають сусідню вкладку. Без боргів вкладок немає — лише порожній стан (дошка
  PocPlanDebtsEmpty).
- Рішення ведучого (2026-11-16; власник не схвалював; BUD-19 b): «Додати рахунок» порожнього стану веде на «Новий
  рахунок» з `?type=loan`; форма S-052 (рядок 112) читає тип з адреси. «›» рядка боргу веде на
  `/money/accounts/:id/settings` (S-054, рядок 113); до того екрана сторінка показує заголовок «Налаштування рахунку» з
  порожнім станом, як інші ще не збудовані сторінки.
- Рішення ведучого (2026-11-16; власник не схвалював; BUD-19 b): підсумки «Загальний борг» і «Платежі на місяць» —
  точна сума `Money` окремо за кожною валютою; підсумок у валюті звітності — разом із п. 9 вимоги. Картки «Погашено N %
  усіх боргів» на S-143 і S-146 немає, доки API не віддає базу «Погашено» (див. питання в PR).
- Рішення ведучого (2026-11-16; власник не схвалював; BUD-19 b): позначка рядка боргу, що не зменшується, — «Борг не
  зменшується» (текст вимоги), а не «Борг зростає» з дошки; рядок без ставки чи платежу — «Немає ставки або платежу».
- Рішення ведучого (2026-11-16; власник не схвалював; BUD-19 b): функцію вимкнено для простору (прапорець
  `debts.payoff`, 404) — сторінка «Борги» лишається в меню і показує звичайний порожній стан сторінки.
