# Рішення ведучого 2026-11-20: рішення партії й готовність до застосування (IMP-05@PoC частина 2)

**Створено:** 2026-11-20 · **Оновлено:** 2026-11-20

Рішення ведучого (2026-11-20; власник не схвалював): деталі, які IMP-05@PoC не називає, у PR частини 2 (хвиля 2, рядок 42,
модуль `import-sessions`).

1. «Остання застосована виписка» рахунку (п. 3) — файл застосованої партії того самого рахунку в просторі з найпізнішим
   кінцем періоду; за рівності — партія з пізнішою останньою дією. Партія, що ще не застосована, і виписка іншого рахунку
   не враховуються. Розрив обчислюється, коли перевірки файлу записуються.
2. Рішення лежать у слотах; нове рішення в тому самому слоті замінює попереднє (п. 10 «можна повторювати»). Рішення рядка
   переважає рішення групи для файлу, а те — рішення групи для партії. Серед рішень груп «виключити» переважає «перевернути
   знак», а те — «прийняти».
3. «Розбіжність контрольних сум» (п. 2) підтверджується лише вибором «Застосувати й оновити залишок до виписки» або
   «Застосувати без оновлення залишку»; «Чужий рахунок» (п. 4) — лише «Так, це правильний рахунок». Загальне підтвердження
   позначки для них не приймається. «Знак картки» (п. 6) підтверджується або знак перевертається для файлу.
4. «Прийняти» групу «потребує уточнення» — прийняти рядки, як їх прочитав рушій; «виключити» — виключити їх. Відповідь
   «застосувати до файлу» поширюється на ті неоднозначні суми файлу, що не мають власної відповіді.
5. Прочитання перевіряється за валютою виписки, а якщо її немає — за валютою рахунку файлу (п. 7, AC7). Прочитання, якого
   немає серед двох прочитань рядка, теж відхиляється (422 `IMPORT_DECISION_INVALID`).
6. Рішення приймаються лише в станах «розібрано» і «потребує перегляду»; новий розбір файлу (запис перевірок) скидає рішення
   цього файлу й рішення для всієї партії. Готовність партії, у якій прийнятий файл ще не має перевірок, — 409.
7. Відмови йдуть у порядку п. 11; кожна називає файли й до 100 номерів рядків (`count` — усі).
8. Запропонований рахунок для «чужого рахунку» записує крок розбору разом з перевірками; пошук такого рахунку серед рахунків
   простору — окремий зріз.
