# Рішення 2026-11-13: GitHub issues створює лише ведучий

**Створено:** 2026-11-13 · **Оновлено:** 2026-11-13

- 2026-11-13, власник (чат ведучому, за повідомленням ведучого): GitHub issues створює лише ведучий, не виконавці й
  рецензенти. Причина: автоматичний класифікатор дозволів у сесіях агентів блокує записи у зовнішні системи, спроба
  агента зазнає невдачі, і ведучий мусить вирішувати, чи повтор є обходом відмови. Агенти не створюють issues:
  наступні кроки вони перелічують у розділі «Follow-ups» тіла PR або у звіті, ведучий відкриває issues і додає
  посилання. Оновлено skills `pr-pipeline`, `implement-requirement`, `review-pr`, `security-review`,
  `change-requirement`, `fix-review-findings`.
- Рішення ведучого (2026-11-13; власник не схвалював; PRC-02): якщо агент повідомляє, що дію відхилив класифікатор
  дозволів, ведучий не повторює її за агента, коли сама дія чутлива, а повідомляє власнику; буденні дії ведучого
  (відкрити issue з follow-up, злити PR за чек-листом) лишаються за ним; правило записано в `pr-pipeline`.
