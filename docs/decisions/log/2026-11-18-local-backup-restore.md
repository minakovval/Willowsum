# Копія і відновлення локальної бази (CICD-04, рядок 173)

**Створено:** 2026-11-18

Рішення ведучого (2026-11-16; власник не схвалював): за розділом 1 зовнішнього рев'ю команди `pnpm local:backup` і `pnpm local:restore` потрібні, тексту вимоги не потрібно ([план](../../plans/poc-wave-2.md), рядок 173).

Дрібні деталі (вирішено в PR):

- Лише база `ws_dev` на локальному сервері (той самий вибір сервера, що в `pnpm local:dev`); тестові бази і чужі хости не чіпаються.
- Формат: `pg_dump -Fc` (контейнер `local:up` або локальні клієнти з `WS_TEST_PG_ADMIN_URL`); поряд файл `<файл>.roles.sql` з ролями без паролів (`pg_dumpall --roles-only --no-role-passwords`), щоб відновити базу і в новому томі.
- Копія за замовчуванням у `~/Willowsum-backups/`, права 0600; наявний файл не перезаписується.
- Відновлення питає «yes» або потребує `--yes`; файл перевіряється (`pg_restore --list`) до видалення бази; `DROP DATABASE` без `FORCE`: працюючий `pnpm local:dev` зупиняє відновлення.
