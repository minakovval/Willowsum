# Рішення 2026-11-19: BUD-06@PoC b) — екран «Порівняння» (S-132, S-290) і вибір періоду CMP-72

**Створено:** 2026-11-19

Рішення ведучого (2026-11-19; власник не схвалював; BUD-06, CMP-72; рядок 132 хвилі 2, `docs/plans/poc-wave-2.md`):

1. Адреса екрана — `#/planning/budget/compare?type=…&period=…&base=…&full=true&view=year`: вибір живе в адресі, тож
   перезавантаження і «назад» його зберігають; без адреси береться останній вибір цього глядача (`localStorage`, лише
   зручність, сторінка працює без нього) — CMP-72 «Стани»: «Вибір зберігається для користувача і сторінки».
2. Типовий стан — тип «Місяць», місяць, що триває (CMP-72 «Стани»: «або поточний, якщо сторінка показує поточний період»; BUD-06 AC1: 12-те число, та сама дата, «Повний попередній період»). Зміна типу тримає найближчий період нового
   типу, що містить старий (жовтень → IV квартал → 2026; «З початку року» — рік).
3. Назва «З початку року» — «Січень — <місяць сьогодні> <рік>»: вікно API закінчується сьогодні (для минулого року — тією
   ж датою), тож і назва за місяцем сьогодні (власник, 2026-11-19: «Січень — листопад 2025»).
4. «‹» неактивна, коли попередній період закінчується раніше за перший місяць історії; його екран виводить з
   `finishedPeriods` (завершені місяці від початку історії, лічені назад від сьогодні) — окремого поля API не потрібно.
   Для «З початку року» діє так само (рішення власника 2026-11-19, `2026-11-19-owner-bud06-ytd-past-years.md`).
5. «Повний попередній період» показано для баз «Попередній період» і «Той самий період минулого року», коли
   `inProgress` або тип «З початку року» (у минулому року `inProgress` = false, а вікно обрізане: #623).
6. Перемикач бази — `Select` (CMP-03): неактивні бази залишаються в списку з поясненням («немає даних за …»), посилання
   «Імпортувати старі виписки» — поруч. Підпис «Порівняти з:» стоїть над полем, а не в одному рядку з ним — розбіжність з
   дошкою, у тілі PR.
7. Порядок рядків — як у відповіді API (сортування за абсолютною різницею робить сервер, BUD-06 FR 6); суми не
   складаються і не порівнюються на екрані. Пояснення «найбільших змін» — «<категорія>: ▲ N € до середнього, на K
   транзакцій більше»; різниця кількості транзакцій — цілі числа, не гроші; рівна кількість — без частини про транзакції.
8. Вкладки сторінки «Бюджет» (`BudgetTabs`) у `main` ще немає: його створює відкритий #629. Щоб не мати двох файлів
   на одному шляху, цей PR не додає вкладку; щойно #629 злито, «Порівняння» додається одним рядком у `TABS`
   (`{ id: "compare", label: …, path: () => childPath("budgetCompare") }`) — follow-up.
9. Режим «Бюджетний період» CMP-72 (стрілки на сторінці «Бюджет») — не цей екран і не цей PR: його покриває BUD-02
   (S-121); CMP-72 AC7 і AC9 лишаються без тесту тут.
