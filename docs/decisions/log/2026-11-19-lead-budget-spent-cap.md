# Рішення ведучого 2026-11-19: «Витрачено» бюджету — суми поза межами грошового типу (#586)

**Створено:** 2026-11-19

Власник тут нічого не вирішував; опора — те саме правило для «Очікуваних платежів» і «Розподілу» (#567, #573): «жодної цифри краще за хибну», ніколи не 500.

- Рішення ведучого (2026-11-19; власник не схвалював; #586): у «Витрачено», «Поза планом», фактичному доході та історії майстра (BUD-02@PoC FR 12) сума транзакції або частини з понад 15 цифрами цілої частини (як ліміт, `parseBudgetAmount`) не перераховується і не додається — її пропущено й пораховано в `approximate.unavailableCount` разом із сумами без курсу; так само сума, що після перерахунку має понад 15 цифр. Якщо модуль курсів не може скласти суми в межах типу або сума їхніх абсолютних значень перевищує 10^18, пропущено всі суми періоду, ніколи не HTTP 500: «Витрачено», «Поза планом» і фактичний дохід тоді 0 (не null, на відміну від `null` у #573) з «Курс недоступний · N» на всі N сум, а місяць майстра — без категоризованих транзакцій; бо так у цілому робить #573 у `adapters/obligations.ts`, а окремий лічильник «поза межами» змінив би контракт API заради синтетично неможливих сум.
