- **rpo / rto**: Canonical RPO ≤ 15 min and RTO ≤ 4 h (NFR-03 FR 3, NFR-16, NFR-18; profile «Старт»). arc/README.md (deployment profiles table) also states RPO ≤ 5 min and RTO ≤ 1 h for the future profile «Комерційний», which no requirement file carries. Reported as fact-mismatch and baselined; the owner decides whether NFR-03 should state per-profile targets.
- **transfer-window**: Not a conflict: own-account transfers pair within 3 days, 5 days when the description names the other account (IMP-03, stated as an assumption); crypto wallet/exchange transfers use a separate 72-hour window (CRY-02). Only the 3-day base value is registered.
- **past-due-grace**: Not a conflict: the 90-day grace period in ACC-12 belongs to emergency household access, not to unpaid subscriptions (14 days). It is not matched by the registry.
- **ceiling-rows / ceiling-file-size**: Not a conflict: the asset/table import (DAT-04, FLW-10) has its own limits (10 000 rows, 500 MB of attachments); the registry checks only the bank-statement import ceilings (IMP-01, IMP-19).
