# IMP-14 · Файл помилок і повторний імпорт виправлених рядків

**Реліз:** PoC (без колонки сторінки для PDF і сканів і без вбудованого профілю «Файл помилок»); PoC v2 (вбудований профіль «Файл помилок» з підстановкою рахунку і позначкою «виправлення партії …»); MVP (ролі й учасники простору; колонка «сторінка» для PDF і сканів) · **Пріоритет:** M

**Зв'язки**
- Зрізи: IMP-14@PoC, IMP-14@PoC v2, IMP-14@MVP
- Модуль: file-storage, import-sessions

**Мета.** Як учасник, що імпортує виписку, я хочу отримати рядки, які не вдалося імпортувати, виправити їх і додати, щоб не втратити жодної операції.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| PoC | [IMP-14.poc.md](IMP-14.poc.md) | Файл помилок CSV для кожного файлу партії; виправлені рядки — звичайним імпортом, без профілю «Файл помилок» |
| PoC v2 | [IMP-14.poc-v2.md](IMP-14.poc-v2.md) | Вбудований профіль «Файл помилок»: розпізнавання за шапкою, підстановка рахунку початкової партії, позначка «виправлення партії …», без звірки залишку |
| MVP | [IMP-14.mvp.md](IMP-14.mvp.md) | Колонка «сторінка» у файлі помилок для PDF і сканів; ролі й учасники простору |

**Рішення власника (2026-11-12):** вбудований профіль «Файл помилок» перенесено з PoC у PoC v2; файл помилок CSV лишається в PoC (відповіді власника у формі питань у чаті ведучого, 2026-11-12).
