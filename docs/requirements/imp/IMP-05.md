# IMP-05 · Контрольні суми, розриви історії та захист від чужого рахунку

**Реліз:** PoC (без інвестиційних рахунків); MVP (ролі й учасники простору; позначка «лише рух коштів» для інвестиційного рахунку) · **Пріоритет:** M

**Зв'язки**
- Зрізи: IMP-05@PoC, IMP-05@MVP
- Модуль: file-parsers, import-sessions

**Мета.** Як користувач, я хочу, щоб система перевіряла виписку її власними підсумками, помічала пропущені періоди і не давала імпортувати файл іншого рахунку, щоб помилки розпізнавання не потрапили в облік непомітно.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| PoC | [IMP-05.poc.md](IMP-05.poc.md) | Контрольні суми, розриви історії, захист від чужого рахунку, знак суми і знак картки, неоднозначні суми й дати, рішення і блокування застосування |
| MVP | [IMP-05.mvp.md](IMP-05.mvp.md) | Позначка партії «лише рух коштів» для інвестиційного рахунку; ролі й учасники простору |
