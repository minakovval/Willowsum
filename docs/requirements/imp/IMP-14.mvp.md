# IMP-14@MVP · Файл помилок і повторний імпорт виправлених рядків

**Реліз:** MVP · **Пріоритет:** M

**Зв'язки**
- Розширює: IMP-14@PoC
- Залежить від: IMP-01@MVP, IMP-04@MVP
- Дизайн: S-163, S-174
- Спільні правила: П-8
- Сценарії: UC-IMP-22
- Модуль: import-sessions, file-storage
- Перевіряється: —

**Мета.** Як учасник, що імпортує виписку, я хочу отримати рядки, які не вдалося імпортувати, виправити їх і додати, щоб не втратити жодної операції.

**Функціональні вимоги**
1. Система повинна формувати файл помилок CSV для кожного файлу партії, у якому хоча б один рядок не став транзакцією через помилку. Службові рядки (підсумки, шапки, перенесення залишку) і дублі до нього не потрапляють: вони є в звіті імпорту з причиною.
2. Колонки файлу помилок: номер рядка в оригіналі, сторінка (для PDF і сканів), поле з помилкою, код і текст причини мовою інтерфейсу, а далі — колонки дата, сума, валюта, опис, залишок із значеннями як у оригіналі та службовий ідентифікатор партії. Кодування UTF-8 із BOM, роздільник — кома.
3. Файл помилок доступний з екрана результату імпорту і з історії імпортів тим, хто бачить партію, через підписане посилання зі строком дії 15 хв. Він зберігається зашифрованим і живе стільки ж, скільки оригінал файлу.
4. Виправлений файл помилок завантажується звичайним імпортом. Рушій розпізнає його за шапкою, застосовує вбудований профіль «Файл помилок», пропонує рахунок початкової партії і позначає нову партію як «виправлення партії …».
5. Рядки виправленого файлу проходять ті самі перевірки, що й будь-який імпорт, включно з пошуком дублів. Звірка залишку для нього не виконується; партія позначається «залишок не перевірявся».

**Критерії приймання**
1. **Given** файл із 120 рядків, з яких 3 мають нечислову суму і 2 є підсумками **When** імпорт застосовано **Then** файл помилок містить рівно 3 рядки з номерами в оригіналі і причиною «сума не є числом», а підсумки є лише в звіті.
2. **Given** виправлений файл помилок із 3 рядками **When** його завантажено **Then** рахунок початкової партії запропоновано, імпортовано 3 транзакції, нова партія зв'язана з початковою.
3. **Given** той самий виправлений файл завантажено вдруге **When** рушій його обробляє **Then** усі 3 рядки позначено дублями, нових транзакцій немає.
4. **Given** обмежена партія **When** Editor без доступу до неї запитує файл помилок **Then** він отримує «не знайдено».
