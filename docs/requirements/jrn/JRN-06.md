# JRN-06 · Перехід з іншого бюджетного застосунку: перші 90 днів

**Реліз:** PoC (імпорт із файлів, правила, підключення банків PoC; без методу «Кожній копійці — завдання», без простого вигляду і без міграції з іншого застосунку); PoC v2 (метод «Кожній копійці — завдання»); MVP (міграція, простий вигляд для другого учасника, активи з іпотекою); v1 (компенсація акціями)

**Зв'язки**
- Зрізи: JRN-06@PoC, JRN-06@PoC v2, JRN-06@MVP, JRN-06@v1
- Модуль: budget, categorization, holdings, import-recipes, import-sessions, liabilities

**Мета.** Зберегти звичний метод і історію, бачити весь капітал в одному місці і залучити дружину через простіший вигляд.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| PoC | [JRN-06.poc.md](JRN-06.poc.md) | Перенесення історії імпортом і підключенням банку, правила категорій, бюджет методом «Ліміти», паралельний місяць |

| MVP | [JRN-06.mvp.md](JRN-06.mvp.md) | Майстер міграції з іншого застосунку, демо-простір, простий вигляд для дружини, квартира з іпотекою, рішення про план Family |
