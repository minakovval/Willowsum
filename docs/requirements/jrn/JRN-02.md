# JRN-02 · Колекціонер: купівля, облік, страхування, продаж

**Реліз:** MVP (облік, лоти, документи, поліси, страховий розклад як звіт розділу «Звіти», без фото); v1 (автооцінки, аналіз покриття, фото в страховому розкладі).

**Персона і контекст.** Давид, 50–65 років. 400 пляшок вина, 30 годинників, 15 робіт сучасного мистецтва. Частина вдома, частина у винному сховищі та на складі зберігання. Купує на аукціонах, страхує колекцію окремим полісом, іноді продає.

**Мета.** Знати, що є, де воно і скільки коштує зараз; мати документи на випадок страхової події чи продажу.

| Етап | Мета користувача | Що повинен забезпечити продукт |
| --- | --- | --- |
| 1. Купівля | Не забути внести покупку | Додавання з PDF інвойсу з розпізнаванням полів (v2); до того — швидка форма з прикріпленням інвойсу |
| 2. Облік | Зберегти все в одному місці | Форми під тип активу, лоти для вина, мінімум обов'язкових полів |
| 3. Організація | Бачити структуру колекції | Локації, групи, масові дії над сотнями предметів |
| 4. Оцінка | Знати вартість зараз | Нагадування про застарілі оцінки; прикріплення звіту оцінювача; з v1 — автооцінки |
| 5. Страхування | Не бути недострахованим | Попередження про недострахування; страховий розклад за хвилину (MVP, як звіт розділу «Звіти»; фото — v1) |
| 6. Подія | Мати докази на момент події | Чек-лист повноти: фото, серійні номери, оцінки — заздалегідь |
| 7. Продаж | Знати результат продажу | Частковий продаж лоту з реалізованим результатом і комісіями |
| 8. Звичка | Отримувати лише корисні сигнали | Налаштовувані тригери і зведені сповіщення |

**Моменти, що повинні спрацювати**

- Нова оцінка предмета одразу змінює статус покриття без ручного перерахунку.
- Страховий розклад містить лише застраховані предмети і не розкриває інших активів.
- Продаж частини лоту не ламає собівартість решти.

**Цільові показники**

- Частка колекційних активів із фото і документом — не менше 70 % через 60 днів.
- Частка колекційних активів з оцінкою, не старшою за нормативний строк, — не менше 60 %.
- Час формування страхового розкладу — не більше 1 хв.
- Незастрахована вартість колекції зменшується щонайменше на 20 % за 3 місяці користування розділом.

**Гіпотези для перевірки**

- Страхування — сильніший мотив для обліку, ніж знання вартості.
- Колекціонери готові платити більше за автооцінки свого класу активів.
- Внесення з інвойсу критичне для колекцій понад 100 предметів.
- Місце зберігання — обов'язкова частина обліку.
