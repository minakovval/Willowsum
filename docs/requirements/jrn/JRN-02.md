**Моменти, що повинні спрацювати**

- [MVP] Нова оцінка предмета одразу змінює статус покриття без ручного перерахунку.
- [MVP] Страховий розклад містить лише застраховані предмети і не розкриває інших активів.
- [MVP] Продаж частини лоту не ламає собівартість решти.

**Цільові показники**

- [лише MVP] Частка колекційних активів із документом — не менше 70 % через 60 днів.
- [v1] Частка колекційних активів із фото і документом — не менше 70 % через 60 днів.
- [MVP] Частка колекційних активів з оцінкою, не старшою за нормативний строк, — не менше 60 %.
- [MVP] Час формування страхового розкладу — не більше 1 хв.
- [MVP] Незастрахована вартість колекції зменшується щонайменше на 20 % за 3 місяці користування розділом.

**Гіпотези для перевірки**

- [MVP] Страхування — сильніший мотив для обліку, ніж знання вартості.
- [MVP] Колекціонери готові платити більше за автооцінки свого класу активів.
- [MVP] Внесення з інвойсу критичне для колекцій понад 100 предметів.
- [MVP] Місце зберігання — обов'язкова частина обліку.
