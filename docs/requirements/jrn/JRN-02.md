# JRN-02 · Колекціонер: купівля, облік, страхування, продаж

**Реліз:** MVP (облік, лоти, документи, поліси, страховий розклад як звіт розділу «Звіти», без фото); v1 (автооцінки, групи, аналіз покриття, фото в страховому розкладі, налаштовувані тригери); v2 (додавання з PDF інвойсу з розпізнаванням)

**Зв'язки**
- Зрізи: JRN-02@MVP, JRN-02@v1, JRN-02@v2
- Модуль: asset-registry, auto-valuation, insurance, ocr, reports, valuation

**Мета.** Знати, що є, де воно і скільки коштує зараз; мати документи на випадок страхової події чи продажу.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
