# JRN-06@PoC v2 · Перехід з іншого бюджетного застосунку: перші 90 днів

**Реліз:** PoC v2

**Зв'язки**
- Розширює: JRN-06@PoC
- Залежить від: FLW-10@PoC v2, FLW-17@PoC v2, FLW-34@PoC v2, FLW-38@PoC v2, FLW-41@PoC v2, FLW-43@PoC v2
- Дизайн: S-121, S-125, S-129, S-132, S-134, S-163, S-170, S-171, S-174, S-197, S-198
- Спільні правила: П-17, П-24, П-25, П-26, SCR-02
- Сценарії: —
- Модуль: import-sessions, budget, categorization
- Перевіряється: —

**Персона і контекст.** Михайло, 38 років, інженер у технологічній компанії, Варшава. Шість років веде бюджет в іншому застосунку за методом «кожній копійці — завдання», а інвестиції, акції роботодавця і вартість квартири — у таблиці. Дружина Ірина вважає його застосунок складним і не користується ним.

**Мета.** Перенести історію транзакцій в один інструмент і перевірити, що цифри бюджету сходяться з попереднім застосунком, зберігши звичний метод бюджетування.

| Етап | Мета користувача | Що повинен забезпечити продукт |
| --- | --- | --- |
| 1. Тригер | Позбутися двох інструментів | Чесна сторінка порівняння з іншими застосунками |
| 2. Оцінка | Не втратити 6 років даних | Перелік того, що переноситься: виписки CSV і Excel, підключення monobank, Revolut і BBVA; демо-простору і майстра міграції немає |
| 3. Перенесення | Перенести історію і категорії | Імпорт виписок CSV і Excel за минулі місяці або підключення банку; правила категорій; бюджет тим самим методом «Кожній копійці — завдання» за середніми витратами |
| 4. Паралельний місяць | Переконатися, що цифри сходяться | Повторний імпорт без дублів; перекази між власними рахунками розпізнаються парами |
| 5. Рішення | Обрати один продукт | Підсумок першого місяця: порівняння і тренд |

**Моменти, що повинні спрацювати**

- Імпорт тієї самої виписки не створює дублів.
- Правило категорії, збережене один раз, категоризує нові транзакції мерчанта.

**Цільові показники**

- Не менше 70 % тестувальників імпортують історію транзакцій за одну сесію.

**Гіпотези для перевірки**

- Люди переходять, лише якщо метод і цільові суми зберігаються без змін.
- Паралельний місяць — норма; повторний імпорт без дублів зменшує відтік.
