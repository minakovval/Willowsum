# ADV-01 · Організація радника

**Реліз:** v2 · **Пріоритет:** C

**Зв'язки**
- Зрізи: ADV-01@v2
- Модуль: advisor

**Мета.** Як керівник консалтингової фірми, я хочу створити організацію, додати співробітників з ролями та закріпити за ними клієнтів, щоб кожен бачив лише свою частину книги клієнтів.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
