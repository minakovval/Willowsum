# CMP-58 · ViewSwitch — Перемикач вигляду

**Реліз:** PoC v2 (кнопка вигляду графіка з меню виглядів і перемикач «Картки / Таблиця» у списках; десктоп від 1280 px, світла тема); MVP (повний обсяг: віджети Головної, сенсорні екрани, вузькі ширини, темна тема, режим «Приховати суми») · **Пріоритет:** M

**Зв'язки**
- Зрізи: CMP-58@PoC v2, CMP-58@MVP
- Модуль: —

**Мета.** Як користувач, я хочу перемикати підсумок між діаграмою, стовпчиками, трендом і таблицею тихим перемикачем у куті, щоб обирати зручний вигляд, не відволікаючись від даних.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

[лише PoC v2] **Призначення.** Тихий перемикач вигляду в заголовку картки з графіком або в панелі інструментів списку. Не для вибору значення у формі — для цього сегментований перемикач у рамці. Не для вибору вигляду сторінки — для цього текстовий випадний список («Вигляд: Повний ˅»). Не показується, якщо варіантів менше двох. Перемикання вигляду ніколи не змінює розміру картки: змінюється лише вміст зони даних. Компонент має два варіанти:
- [лише PoC v2] «Меню» — для кожного графіка на сторінці. Тиха кнопка-іконка в заголовку картки графіка, завжди з тією самою іконкою «chart-no-axes-column» на кожному графіку і в кожному стані, з підказкою і доступним ім'ям «Вигляд: <назва поточного вигляду>». Натискання відкриває меню під кнопкою, де біля кожної назви стоїть власна іконка вигляду, а поточний пункт позначено галочкою. Іконки окремих виглядів є лише в меню. Приклади наборів: «Смуга / Кільце / Водоспад» для складу, «Накопичено / По днях / По тижнях» для темпу.
- [лише PoC v2] «Група кнопок» — для списків. Група кнопок лише з іконками в панелі інструментів списку, наприклад «Картки / Таблиця».

[MVP] **Призначення.** Тихий перемикач вигляду в заголовку віджета, картки чи списку (наприклад, «Діаграма / Стовпчики / Тренд / Таблиця» або «Картки / Таблиця»). Для графіка в картці на сторінці таблиця тих самих чисел не є варіантом вигляду: вона завжди доступна під графіком як текстова альтернатива, і в меню виглядів такого графіка пункту «Таблиця» немає. Віджет Головної може мати вигляд «Таблиця». Не для вибору значення у формі — для цього сегментований перемикач у рамці. Не показується, якщо варіантів менше двох. Варіант «меню» — єдиний варіант у заголовку віджета Головної: тиха кнопка безпосередньо перед «›», завжди з тією самою іконкою «chart-no-axes-column» у кожному віджеті і в кожному стані, з підказкою і доступним ім'ям «Вигляд: <назва поточного вигляду>»; натискання відкриває меню, де біля кожної назви стоїть власна іконка вигляду, а поточний пункт позначено галочкою. Іконки окремих виглядів є лише в меню. Група кнопок-іконок нижче — для карток і списків поза віджетами Головної. Перемикання вигляду ніколи не змінює розміру віджета: змінюється лише вміст зони даних.

[MVP] **Режим «Приховати суми».** Не впливає на перемикач; новий вигляд підкоряється режиму.
