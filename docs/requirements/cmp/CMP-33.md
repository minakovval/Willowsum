# CMP-33 · Icon — Іконка

**Реліз:** PoC (десктоп від 1280 px, світла тема); PoC v2 (іконки типів активів, страхування й інвестицій); MVP (темна тема) · **Пріоритет:** M

**Зв'язки**
- Зрізи: CMP-33@PoC, CMP-33@PoC v2, CMP-33@MVP
- Модуль: —

**Мета.** Як користувач, я хочу бачити впізнавані однакові іконки розділів, типів активів, продуктів і дій поруч зі словами, щоб швидше орієнтуватися, не вгадуючи їхнє значення.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
