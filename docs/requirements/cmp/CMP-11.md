# CMP-11 · Tabs — Вкладки

**Реліз:** PoC (десктоп від 1280 px, світла тема); PoC v2 (варіант «Вкладки картки» з підкресленням); MVP (вузькі й середні ширини) · **Пріоритет:** M

**Зв'язки**
- Зрізи: CMP-11@PoC, CMP-11@PoC v2, CMP-11@MVP
- Модуль: —

**Мета.** Як користувач, я хочу перемикатися між видами одного об'єкта (наприклад, вкладками картки активу), щоб бачити різні сторони без переходу на іншу сторінку.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
