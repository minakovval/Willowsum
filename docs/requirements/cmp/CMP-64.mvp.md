# CMP-64@MVP · Chip — Чип

**Реліз:** MVP · **Пріоритет:** M

- Розширює: CMP-64@PoC
- Залежить від: —
- Дизайн: —
- Спільні правила: П-13, П-16, DS-06, DS-10, DS-11, DS-14, DS-18
- Сценарії: —
- Модуль: —
- Перевіряється: —

**Мета.** Як користувач, я хочу бачити застосовані фільтри як компактні чипи і знімати кожен одним натисканням, щоб розуміти, що саме зараз відфільтровано.

**Призначення.** Компактний елемент для застосованого фільтра (з кнопкою «×»), для перемикача-фільтра (наприклад, типи на мапі) або для тегу. Не для навігації між розділами (для цього — вкладки) і не для стану (для цього — бейдж).

**Варіанти і розміри**
- Фільтр зі зняттям: висота 32 px, відступи 0 4 px 0 12 px, радіус 999 px, текст 14/20 px вага 500; кнопка «×» 28 × 28 px (гліф 16 px) із зоною натискання 44 px; фон `surface-300` F1F1EF / 1B3F6E, текст `ink` 1B2230 / F6F1E8, без рамки.
- Перемикач (чип мапи і швидких фільтрів): висота 36 px, відступи 0 × 14 px, радіус 999 px, іконка 16 px ліворуч; вимкнений стан перемикача — фон `surface-200` FFFFFF / 12305A, рамка 1,5 px `border-control` 7B8494 / 6F8CB0, текст `ink`; увімкнений — фон `ink` 1B2230 / F6F1E8, текст `surface-100` FBFBFA / 0B2545, галочка 16 px перед назвою.
- Тег (лише читання): висота 24 px, відступи 0 × 8 px, радіус 999 px, текст 12/16 px вага 500, фон `surface-300`.

**Стани.** Наведення — фон темнішає (суміш 8 % `ink`), для «×» — фон `surface-200` під кнопкою; фокус — фокус-кільце 3 px `focus` 1D4E89 / E3A33B з відступом 2 px; натиснутий — суміш 12 % `ink`; вимкнений — `disabled-bg` E7E1D3 / 1B3F6E, `disabled-ink` 8A8F99 / 6F86A6.

**Вміст.** Текст чипа-фільтра — «Поле: значення» або лише значення, якщо поле очевидне («Їжа», «Березень 2026»); не більше 24 символів, далі трикрапка з підказкою лише при обрізанні. Після трьох і більше чипів-фільтрів з'являється тиха дія «Скинути все».

**Клавіатура і екранний читач.** Чип-фільтр: текст — не фокусний; «×» — `button` з іменем «Прибрати фільтр: Їжа»; після зняття фокус переходить на наступний чип або, якщо чипів немає, на кнопку фільтрів. Чип-перемикач — `button` з `aria-pressed`. Набір чипів — список з доступною назвою («Застосовані фільтри»).

**Адаптивність.** Чипи переносяться в кілька рядків, проміжок 8 px; горизонтального прокручування немає. На Compact на мапі чипи переносяться, а не прокручуються.

**Режим «Приховати суми».** Чип із сумою («Сума: від € 100») показує «Сума: •••».

**Критерії приймання**
1. **Given** застосовано фільтр «Їжа» **When** показано чип **Then** його висота 32 px, кнопка «×» 28 px має зону натискання 44 px.
2. **Given** фокус на «×» чипа «Їжа» **When** користувач натискає Enter **Then** фільтр знято, фокус на наступному чипі, читач оголошує оновлену кількість результатів.
3. **Given** чип типу на мапі увімкнено **When** його показано у світлій темі **Then** висота 36 px, фон 1B2230, текст F6F1E8, галочка видима, `aria-pressed="true"`.
4. **Given** 6 чипів на ширині 360 px **When** їх показано **Then** вони переносяться в кілька рядків без горизонтального прокручування.
5. **Given** три застосовані фільтри **When** показано чипи **Then** поруч видно дію «Скинути все».
