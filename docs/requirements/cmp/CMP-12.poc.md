# CMP-12@PoC · Segmented — Сегментований перемикач

**Реліз:** PoC · **Пріоритет:** M

**Мета.** Як користувач, я хочу одним натисканням змінювати спосіб показу тих самих даних (період графіка, черга за мерчантами чи по одній), щоб обирати зручний вигляд.

**Призначення.** Перемикання вигляду того самого вмісту, або вибір значення з 2–4 видимих варіантів у формі. Вибір діє одразу. Понад чотири варіанти — список вибору. У панелі інструментів або заголовку віджета замість нього використовується тихий перемикач вигляду (без рамки).

**Будова.** Рамка 1,5 px `border-control` 7B8494 / 6F8CB0, радіус 4 px, фон `surface-200` FFFFFF / 12305A; сегменти розділені лінією 1 px `border-control`.

**Розміри.** Сегмент: мінімальна висота 40 px (зона натискання доповнена до 44 px), відступи 16 px, Inter 14/20 px, вага 500, без переносу. Перемикач завширшки як його варіанти і ніколи не розтягується на весь контейнер.

**Стани**
- Активний сегмент: заливка `brand` 0B2545 / EBDFC6, текст `on-brand` F6F1E8 / 0B2545, вага 600.
- Неактивний: текст `ink` 1B2230 / F6F1E8.
- Наведення: фон `surface-300` F1F1EF / 1B3F6E.
- Фокус: фокус-кільце 3 px `focus` 1D4E89 / E3A33B всередині сегмента.
- Вимкнений сегмент: фон `disabled-bg` E7E1D3 / 1B3F6E, текст `disabled-ink` 8A8F99 / 6F86A6.

**Вміст.** Короткі підписи (одне слово). Перемикач періоду будь-якого графіка — цей компонент з одним набором варіантів «1М · 3М · 1Р · Усе» (вибраний підсвічено); інших наборів періодів для графіків немає. Аналітичні таблиці (порівняння періодів, річна таблиця «план і факт», грошовий потік, підсумок періоду) вибирають період не цим перемикачем, а компонентом «Вибір періоду аналітичної таблиці».

**Клавіатура і екранний читач.** `role="radiogroup"` з доступним ім'ям групи; сегменти — `role="radio"` з `aria-checked`. Tab заходить на вибраний сегмент; ← → змінюють вибір.

**Адаптивність.** Однаковий на всіх класах.

**Критерії приймання**
1. **Given** перемикач «Мерчанти / По одній» над чергою «До розбору» **When** користувач обирає «По одній» **Then** черга одразу показує транзакції по одній.
2. **Given** фокус на вибраному сегменті **When** натиснути → **Then** вибір переходить на наступний сегмент, читач оголошує «вибрано».
3. **Given** контейнер шириною 800 px **When** показано перемикач із трьох варіантів **Then** його ширина дорівнює сумі сегментів, а не 800 px.
4. **Given** графік балансу на картці рахунку **When** показано перемикач періоду **Then** це цей компонент з варіантами «1М», «3М», «1Р», «Усе».
