# CMP-26 · Table — Таблиця

**Реліз:** PoC (десктоп від 1280 px, світла тема; один вигляд — таблиця); PoC v2 (вигляд карток поруч із таблицею, вибір вигляду для кожного списку); MVP (вузькі й середні ширини, режим «Приховати суми») · **Пріоритет:** M

**Зв'язки**
- Зрізи: CMP-26@PoC, CMP-26@PoC v2, CMP-26@MVP
- Модуль: —

**Мета.** Як користувач із багатьма записами, я хочу бачити їх щільною таблицею з сортуванням і підсумком, а на вузькому екрані — картками, щоб швидко порівнювати і ніколи не прокручувати вбік.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
