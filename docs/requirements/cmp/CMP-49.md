**Мета.** Як користувач, я хочу бачити прогрес до однієї цілі компактним кільцем на дашборді, щоб швидко оцінити, скільки лишилося.

**Призначення.** Прогрес до однієї мети в компактній круглій формі, для цілей на дашбордах.

**Будова і розміри.** Квадрат заданого розміру (типово 96 px); доріжка завтовшки 8 px кольору `surface-300` F1F1EF / 1B3F6E без рамки; дуга тієї самої товщини з округленими кінцями — тон `brand` 0B2545 / EBDFC6, а для цілі — колір шкали прогресу цілі (жовто-зелений градієнт `goal-0` … `goal-100`, інтерполяція oklch) у точці відсотка заповнення; досягнута ціль — `goal-100` (бурштин `accent` дугу не заповнює); відсоток у центрі Inter Tight 600 22/28 px табличні цифри; підпис під кільцем 14/20 px вага 500, по центру. Проміжок 8 px.

**Стани.** 0 % — лише доріжка; 100 % — у центрі слово «Готово»; понад 100 % — повна дуга і «Готово»; завантаження — скелетон-коло; фокус (якщо кільце — посилання) — фокус-кільце 3 px `focus` 1D4E89 / E3A33B.

**Вміст.** Підпис — один рядок із трикрапкою і підказкою лише при обрізанні.

**Клавіатура і екранний читач.** `role="progressbar"` з `aria-valuenow`, мінімумом 0, максимумом 100 і текстом «Відпустка, 62 %».

[лише PoC v2] **Адаптивність.** Розмір задається.
[MVP] **Адаптивність.** Розмір задається; на Compact у сітці дашборда кільця стають по два в ряд.

[MVP] **Режим «Приховати суми».** Кільце показує лише відсоток, тому не змінюється.
[MVP]
**Критерії приймання**
#. [PoC v2] **Given** ціль виконана на 62 % **When** показано кільце **Then** дуга займає 62 % і має колір шкали прогресу цілі в точці 62 % (між `goal-55` 9ACD32 і `goal-80` 4CAF50), у центрі «62 %»; досягнута ціль — повна дуга `goal-100` 2E7D32.
#. [PoC v2] **Given** ціль досягнута **When** показано кільце **Then** у центрі слово «Готово».
#. [PoC v2] **Given** кільце не для цілі **When** обирається тон **Then** використано `brand`, а не шкалу цілі і не бурштин.
#. [PoC v2] **Given** екранний читач **When** фокус на кільці **Then** озвучено назву і відсоток.
#. [PoC v2] **Given** кільце 96 px для цілі на 53 % у світлій темі **When** виміряти його **Then** доріжка 8 px кольору F1F1EF без рамки, дуга 8 px з округленими кінцями кольору шкали цілі в точці 53 %, у центрі «53 %» Inter Tight 600 22 px.

Припущення: типовий розмір 96 px визначено, бо джерела задають лише параметр розміру.
