# CMP-23 · EmptyState — Порожній стан

**Реліз:** PoC (десктоп від 1280 px; без різновиду з прикладом); MVP (різновид із прикладом для сторінки «Активи», вузькі ширини); v1 (дія, недоступна за лімітом плану) · **Пріоритет:** M

**Зв'язки**
- Зрізи: CMP-23@PoC, CMP-23@MVP, CMP-23@v1
- Модуль: —

**Мета.** Як користувач, я хочу, щоб порожній список чи віджет пояснював, чого бракує, і пропонував один наступний крок, щоб я знав, що робити далі.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
