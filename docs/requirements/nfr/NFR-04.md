# NFR-04 · Продуктивність

**Реліз:** PoC (базові ліміти швидкодії списків та імпорту); MVP (Головна, запити API, пошук, Core Web Vitals, конкурентне редагування, перерахунок net worth, повільні віджети); v1-mobile (холодний старт і плавність мобільного застосунку) · **Пріоритет:** M

**Зв'язки**
- Зрізи: NFR-04@PoC, NFR-04@MVP, NFR-04@v1-mobile
- Модуль: —

**Мета.** Як користувач із великою історією, я хочу, щоб Головна і списки відкривалися швидко навіть на великому просторі, щоб продуктом було зручно користуватися щодня.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| PoC | [NFR-04.poc.md](NFR-04.poc.md) | Серверна пагінація; сторінка 50 транзакцій із фільтрами ≤ 500 мс (p95) на синтетичному просторі; звіт вимірювань |
| MVP | [NFR-04.mvp.md](NFR-04.mvp.md) | Головна ≤ 2 с, API, пошук, Core Web Vitals, оптимістичне блокування, перерахунок net worth ≤ 5 хв, повільні віджети окремо |
