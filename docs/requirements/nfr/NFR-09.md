**Мета.** Як користувач з ЄС чи України, я хочу користуватися Willowsum своєю мовою, з датами, числами і валютами у звичному форматі, щоб інтерфейс був зрозумілим.

**Функціональні вимоги**
#. [PoC] Усі тексти інтерфейсу, листів і повідомлень проходять через ключі перекладу; жорстко зашитих рядків немає.
#. [MVP] Інтерфейс повністю перекладено українською (uk) і англійською (en).
#. [MVP] Мови zh, hi, es, fr, ar, bn, pt, ru, ur, id, de, ja мають статус «машинний переклад»; інтерфейс показує позначку «машинний переклад» для цих мов.
#. [MVP] Підтримується письмо справа наліво (RTL) для арабської та урду: розкладка дзеркалиться, числа і суми читаються правильно.
#. [MVP] Юридичні тексти (Умови, Політика приватності) доступні українською і англійською. Інтерфейс адмін-панелі персоналу — англійською і українською.
#. [PoC] Додавання нової мови не вимагає змін коду: мова реєструється в конфігурації і отримує переклади.
#. [PoC] Дати, числа, валюти і часові пояси форматуються за локаллю і часовим поясом користувача.
#. [MVP] Валюта звітності нового простору — EUR; для локалі uk-UA — UAH.

**Критерії приймання**

| Критерій | Поріг | Спосіб перевірки |
| --- | --- | --- |
| i18n | 0 жорстко зашитих рядків в інтерфейсі | Lint-правило в CI |
| [лише PoC] Додавання мови | Без зміни коду | Тест псевдолокалізації (подовжені рядки, напрям зліва направо); RTL-псевдомова — з PoC v2 (рішення ведучого 2026-11-12) |
| [лише PoC] Формати | Дати, числа, валюти, часові пояси за локаллю | Юніт-тести форматування для uk і en |
| [MVP] Мови | uk і en — 100 % ключів перекладено; інші мови позначені «машинний переклад» | Перевірка повноти каталогів у CI |
| [PoC v2] Додавання мови | Без зміни коду | Тест псевдолокалізації (подовжені рядки і RTL-псевдомова) |
| [PoC v2] Формати | Дати, числа, валюти, часові пояси за локаллю | Юніт-тести форматування для uk, en і однієї RTL-мови |
| [MVP] RTL | Дзеркальна розкладка без перекриття елементів | Візуальні регресійні тести RTL |

#. [MVP] **Given** обрано мову зі статусом «машинний переклад» **When** користувач відкриває застосунок **Then** інтерфейс показує позначку «машинний переклад».
#. [MVP] **Given** новий простір створює користувач із локаллю uk-UA **When** простір створено **Then** валюта звітності — UAH; для інших локалей — EUR.
#. [MVP] **Given** ключ перекладу відсутній у вибраній мові **When** сторінка рендериться **Then** показується англійський текст, а відсутній ключ фіксується в CI як помилка повноти для uk і en.
