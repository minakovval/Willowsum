# NFR — module requirements

Scope: Non-functional requirements: security, compliance, availability, performance, DoD. Source: tab 9 of the Willowsum product specification.

## Text from the specification tab (outside individual requirements)

<!-- spec-text:begin -->
## 9. Нефункціональні вимоги

Розділ описує нефункціональні вимоги Willowsum: безпеку, відповідність GDPR, доступність і відновлення сервісу, продуктивність, архітектуру, цілісність даних, платформи, доступність інтерфейсу, локалізацію, спостережуваність, поставку, строки зберігання, захисні заголовки, обов'язкові засоби захисту, процедуру резервного копіювання, обробників даних, критерії готовності до запуску і критерії готовності вимоги. Кожен критерій має вимірюваний поріг і спосіб перевірки. Критерій вважається виконаним, коли перевірка проходить у staging перед релізом і далі моніториться в production.

Вимоги розділу: NFR-01, NFR-02, NFR-03, NFR-04, NFR-05, NFR-06, NFR-07, NFR-08, NFR-09, NFR-10, NFR-11, NFR-12, NFR-13, NFR-14, NFR-15, NFR-16, NFR-17, NFR-18, NFR-19.
