**Функціональні вимоги**
#. [лише PoC] PoC — лише вебзастосунок для десктопного браузера з шириною вікна від 1280 px. Підтримуються останні 2 версії Chrome, Safari і Edge; наскрізні тести виконуються лише в рушіях Chromium і WebKit, Firefox — з PoC v2 (рішення власника 2026-11-12).
#. [лише PoC v2] PoC — лише вебзастосунок для десктопного браузера з шириною вікна від 1280 px. Підтримуються останні 2 версії Chrome, Safari, Edge і Firefox.
#. [PoC–PoC v2] Навігація — бічна панель із підписами шириною 212 px.
#. [PoC–PoC v2] Відступи сітки — 24 px; ширина вмісту — не більше 1200 px.
#. [MVP] MVP — лише вебзастосунок для настільного і мобільного браузера. Підтримуються останні 2 версії Chrome, Safari, Edge і Firefox.
#. [MVP] Інтерфейс адаптивний від 360 px ширини вікна. Горизонтальної прокрутки сторінки немає ніде; широкі таблиці перетворюються на картки, якщо контейнер вужчий за 520 px.
#. [MVP] Навігація залежить від ширини вікна: менше 600 px — нижня панель з 4 або 5 пунктами; 600–1279 px — рейка з іконками шириною 64 px; від 1280 px — бічна панель із підписами шириною 212 px.
#. [MVP] Відступи сітки: 16 px на вузьких екранах (менше 600 px) і 24 px від 600 px; ширина вмісту — не більше 1200 px.
#. [MVP] Кожна функція перевіряється у трьох діапазонах ширини: менше 600 px, 600–1279 px і від 1280 px.
#. [v1-mobile] Мобільні застосунки iOS 16+ і Android 10+ (API 29+) виходять окремим релізом.
#. [v1-mobile] Функції MVP доступні у мобільному застосунку, якщо для функції не сказано інше; паритет фіксується матрицею в релізному чек-листі.
#. [v1-mobile] Мобільний застосунок показує останні дані без мережі; редагування без мережі ставиться в чергу синхронізації.

**Критерії приймання**

| Критерій | Поріг | Спосіб перевірки |
| --- | --- | --- |
| [лише PoC] Веб | Останні 2 версії Chrome, Safari, Edge; від 1280 px | E2E-тести в Chromium і WebKit на ширині 1280 px |
| [лише PoC v2] Веб | Останні 2 версії Chrome, Safari, Edge, Firefox; від 1280 px | Крос-браузерні E2E-тести на ширині 1280 px |
| [лише PoC v2] Навігація | Бічна панель 212 px від 1280 px | Візуальні регресійні тести |
| [MVP] Веб | Останні 2 версії Chrome, Safari, Edge, Firefox; від 360 px; 0 горизонтальної прокрутки сторінки | Крос-браузерні E2E-тести на трьох ширинах; автоматична перевірка ширини документа |
| [MVP] Навігація | Нижня панель < 600 px; рейка 64 px 600–1279 px; бічна панель 212 px від 1280 px | Візуальні регресійні тести |
| [v1-mobile] Мобільні | iOS 16+; Android 10+ (API 29+) | Тести на фермі пристроїв |
| [v1-mobile] Паритет | Функції MVP доступні в застосунку, якщо не сказано інше | Матриця паритету в релізному чек-листі |
| [v1-mobile] Офлайн | Перегляд останніх даних без мережі; редагування з чергою синхронізації | E2E-тест у режимі «у літаку» |

#. [MVP] **Given** вікно шириною 360 px **When** користувач відкриває будь-яку сторінку **Then** ширина документа не перевищує ширину вікна, а таблиці показано картками.
#. [PoC] **Given** вікно шириною 1280 px **When** користувач відкриває застосунок **Then** ліворуч показано бічну панель навігації 212 px із підписами.
#. [v1-mobile] **Given** мобільний застосунок без мережі **When** користувач відкриває Головну і додає витрату **Then** показано останні збережені дані з часом оновлення, а витрата чекає в черзі і синхронізується після появи мережі.

**Граничні випадки**
- [PoC] Непідтримуваний браузер: показується повідомлення з переліком підтримуваних браузерів; вхід не блокується.

[PoC–PoC v2] Припущення: поведінка для непідтримуваного браузера додана як розумне значення.
[MVP] Припущення: для автоматичних тестів використовуються ширини 390 px, 768 px і 1280 px як представники трьох діапазонів; поведінка для непідтримуваного браузера додана як розумне значення.
