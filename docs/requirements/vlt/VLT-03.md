# VLT-03 · Додавання документа: ручне введення, імпорт файлу і розпізнавання на пристрої

**Реліз:** MVP (веб: ручне введення та імпорт файлу); v1-mobile (камера і розпізнавання на пристрої); v1 (зображення платіжної картки із закритим кодом безпеки) · **Пріоритет:** S

**Зв'язки**
- Зрізи: VLT-03@MVP, VLT-03@v1-mobile, VLT-03@v1
- Модуль: file-storage, vault-items

**Мета.** Як член родини, я хочу швидко додати документ із файлу або фото й отримати заповнені поля, щоб не вводити номери й дати вручну і не передавати зображення паспорта на сервер для розпізнавання.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| MVP | [VLT-03.mvp.md](VLT-03.mvp.md) | Ручне введення та імпорт файлу у вебі; шифрування в браузері для «Особливо чутливих»; серверне розпізнавання лише для «Чутливих»; без файлів платіжної картки |
| v1-mobile | [VLT-03.v1-mobile.md](VLT-03.v1-mobile.md) | Сканування камерою, розпізнавання на пристрої (OCR, MRZ, PDF417), перевірка полів; зображення картки не зберігається |
