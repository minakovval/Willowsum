# DAT — module requirements

Scope: Universal list, global search, bulk actions, shared data rules. Source: tab 5 of the Willowsum product specification.

## Module intro (from the specification tab)

Модуль охоплює сховище документів і їх типи, страхові поліси й аналіз покриття, сповіщення і тригери, універсальний список, глобальний пошук, масові дії, єдиний імпорт даних, стани екранів, підтримку, стандартні й заплановані звіти, а також імпорт банківських виписок: рушій розпізнавання, рецепти й шаблони, мультивалютність, парування, контрольні суми, PDF і OCR.

Shared text of this tab (title, intro, common sections) is kept in [../doc/README.md](../doc/README.md).

## Requirements

| ID | Title | Release | Priority |
| --- | --- | --- | --- |
| [DAT-01](DAT-01.md) | Універсальний список | PoC (один вигляд — таблиця; фільтри, сортування і колонки без збереження; без збережених і спільних виглядів; кнопка панелі фільтрів — «Застосувати»); PoC v2 (вигляди «Картки / Таблиця»; збережені вигляди, без спільних; кнопка «Показати N»); MVP (ролі й учасники простору; спільні вигляди, списки активів і інших сутностей, картки на вузьких екранах); v1-mobile (безперервна прокрутка в мобільному застосунку) | M |
| [DAT-02](DAT-02.md) | Глобальний пошук | MVP; v1-mobile (пошук у мобільному застосунку); v1 (вимкнена за планом функція повертає 402) | S |
| [DAT-03](DAT-03.md) | Масові дії | PoC (лише для транзакцій: зміна категорії чи мітки, позначка «переглянуто»; механізм спільний для всіх сутностей); MVP (ролі й учасники простору; масові дії з активами: поле, локація, власник, експорт, видалення в кошик); v1 (групи й теги, вимкнена за планом функція повертає 402) | S |
| [DAT-04](DAT-04.md) | Єдиний імпорт і майстер міграції | PoC (імпорт транзакцій із файлів CSV і XLSX в один рахунок, зокрема рахунок типу «Кредит»; без майстра міграції з інших застосунків); MVP (ролі й учасники простору; активи, зобов'язання, контакти і позиції портфеля, ZIP із вкладеннями, режим «Оновити існуючі», майстер міграції, сповіщення «Імпорт завершено», двофакторна автентифікація); v1 (перевірка лімітів плану на кроці перевірки) | M |
| [DAT-05](DAT-05.md) | Стани екранів і віджетів | PoC (без пропозиції звернутися в підтримку після трьох невдалих повторів); PoC v2 (пропозиція звернутися в підтримку з кодом помилки); MVP (ролі й учасники простору; віджети Головної, екран «Розділ вимкнено» для рівня складності, дві мови інтерфейсу); v1-mobile (офлайн-стан у мобільних застосунках); v1 (екран пропозиції апгрейду для функції, недоступної за планом) | M |
