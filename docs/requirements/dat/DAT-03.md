# DAT-03 · Масові дії

**Реліз:** PoC (лише для транзакцій: зміна категорії чи мітки, позначка «переглянуто»; механізм спільний для всіх сутностей); MVP (ролі й учасники простору; масові дії з активами: поле, локація, власник, експорт, видалення в кошик); v1 (групи й теги, вимкнена за планом функція повертає 402) · **Пріоритет:** S

**Зв'язки**
- Зрізи: DAT-03@PoC, DAT-03@MVP, DAT-03@v1
- Модуль: asset-registry, bulk-actions, plan-catalog, transactions

**Мета.** Як власник великої колекції, я хочу змінювати локацію, власника, групу, теги чи інші поля для багатьох записів одночасно, щоб не редагувати їх по одному.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
