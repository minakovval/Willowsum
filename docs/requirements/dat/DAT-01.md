# DAT-01 · Універсальний список

**Реліз:** PoC (фільтри, сортування і колонки без збереження; без збережених і спільних представлень; кнопка панелі фільтрів — «Застосувати»); PoC v2 (збережені представлення, без спільних; кнопка «Показати N»); MVP (спільні представлення, списки активів і інших сутностей, картки на вузьких екранах); v1-mobile (безперервна прокрутка в мобільному застосунку) · **Пріоритет:** M

**Зв'язки**
- Зрізи: DAT-01@PoC, DAT-01@PoC v2, DAT-01@MVP, DAT-01@v1-mobile
- Модуль: asset-registry, saved-views, transactions

**Мета.** Як користувач з великою кількістю активів, транзакцій і документів, я хочу працювати з будь-яким списком однаково — сортувати, фільтрувати, обирати колонки і зберігати свої представлення, щоб швидко знаходити потрібне без окремого інтерфейсу для кожного типу.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| PoC | [DAT-01.poc.md](DAT-01.poc.md) | Один компонент списку, сортування в заголовках, фільтри з кнопкою «Застосувати», колонки, серверна пагінація, відновлення стану; без збережених представлень |
| PoC v2 | [DAT-01.poc-v2.md](DAT-01.poc-v2.md) | Збережені представлення користувача (типове, перейменувати, видалити), без спільних; кнопка «Показати N» з живою кількістю |
| MVP | [DAT-01.mvp.md](DAT-01.mvp.md) | Спільні представлення і область «збережені представлення списків» для обмеженого scope; списки активів та інших сутностей з атрибутами типу; картки на вузьких екранах |
| v1-mobile | [DAT-01.v1-mobile.md](DAT-01.v1-mobile.md) | Безперервна прокрутка замість сторінок у мобільному застосунку |
