# WGT-01 · Реєстр віджетів

**Реліз:** MVP; v1 (стан «Вимкнено планом» для віджетів реєстру) · **Пріоритет:** M

**Зв'язки**
- Зрізи: WGT-01@MVP, WGT-01@v1
- Модуль: dashboard

**Мета.** Як команда продукту, я хочу мати один перелік усіх віджетів Головної з розміром, висотою, джерелом даних, порожнім станом і доступом, щоб кожен новий віджет одразу вписувався в сітку і правила каркаса.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| MVP | [WGT-01.mvp.md](WGT-01.mvp.md) | Реєстр віджетів: ідентифікатор, назва, розмір, висота, джерело, порожній стан, доступ, ключ функції без застосування ліміту |
| v1 | [WGT-01.v1.md](WGT-01.v1.md) | Віджети реєстру мають стан «Вимкнено планом» каркаса |
