# WGT-25 · Віджет «Інвестиції»

**Реліз:** MVP; v1 (стан «Вимкнено планом») · **Пріоритет:** M

**Зв'язки**
- Зрізи: WGT-25@MVP, WGT-25@v1
- Модуль: dashboard

**Мета.** Як інвестор, я хочу бачити на Головній вартість портфелів і результат, щоб стежити за інвестиціями без переходу на сторінку портфеля.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
