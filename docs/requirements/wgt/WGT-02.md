# WGT-02 · Режим редагування Головної

**Реліз:** MVP; v1 (віджет поза планом у каталозі) · **Пріоритет:** S

**Зв'язки**
- Зрізи: WGT-02@MVP, WGT-02@v1
- Модуль: dashboard

**Мета.** Як користувач, я хочу змінювати порядок і набір віджетів прямо на Головній, мишею, дотиком чи клавіатурою, і завжди бачити, куди ляже віджет, щоб налаштувати Головну під себе без несподіваних перестановок.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
