# SUB-05 · Back office

**Реліз:** MVP (доступ підтримки до даних простору, п. 4–6); v1 (решта back office: пошук користувачів, дії над підпискою, довідники) · **Пріоритет:** S

**Зв'язки**
- Зрізи: SUB-05@MVP, SUB-05@v1
- Модуль: billing, staff-admin

**Мета.** Як оператор підтримки, я хочу керувати підписками, пробними періодами, купонами та довідниками, не бачачи фінансових даних клієнтів, щоб допомагати без ризику для приватності.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
