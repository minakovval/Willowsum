# PRC-02 · Процес змін: вплив змін вимог і дизайну на інші артефакти

**Реліз:** PoC · **Пріоритет:** M

**Зв'язки**
- Зрізи: PRC-02@PoC
- Модуль: —

**Мета.** Як власник продукту, я хочу, щоб кожна зміна вимоги, дизайну чи спільного правила доходила до всіх залежних артефактів в одному PR або явно фіксувалася як подальша робота, щоб вимоги, дизайн, тести й код не розходилися.

**Релізні зрізи.** Кожен зріз повний для свого релізу. Зріз діє до релізу наступного зрізу.
