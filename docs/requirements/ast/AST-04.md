# AST-04 · Дії життєвого циклу

**Реліз:** MVP; v1 (капітальні витрати в базі вартості при продажу) · **Пріоритет:** M

**Зв'язки**
- Зрізи: AST-04@MVP, AST-04@v1
- Модуль: asset-registry

**Мета.** Як власник, я хочу фіксувати все, що відбувається з активом (оцінка, пропозиція, продаж, позика музею, подарунок), щоб історія і net worth були правдивими.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| MVP | [AST-04.mvp.md](AST-04.mvp.md) | Події без вибуття, продаж, подарунок, втрата, відновлення, кошик; реалізований прибуток від бази «ціна придбання плюс комісії» |
| v1 | [AST-04.v1.md](AST-04.v1.md) | Капітальні витрати входять у базу вартості для реалізованого прибутку |
