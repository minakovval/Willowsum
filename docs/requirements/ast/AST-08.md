# AST-08 · Одиничні активи та лоти

**Реліз:** MVP; v1 (ліміт активів під час розділення лота) · **Пріоритет:** M

**Зв'язки**
- Зрізи: AST-08@MVP, AST-08@v1
- Модуль: asset-registry

**Мета.** Як власник винного льоху, монет чи серії гравюр, я хочу вести їх як один лот з кількістю, але діяти з частиною, щоб не створювати сотні однакових записів.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
