## 8. AI, API, планування, радник

Модуль охоплює AI-функції (асистент, пояснення, розбір документів, захист даних в AI), відкритий доступ до даних через персональний API і MCP-конектор, довгострокове, пенсійне і спадкове планування, а також роботу фінансового радника з клієнтами (організація радника, список клієнтів, передача простору, контроль доступу клієнтом, фіди, походження даних, брендовані звіти й аналітика). Усі AI- і планувальні функції працюють як облік, факти і розрахунки на припущеннях користувача, без персональних інвестиційних, податкових чи юридичних порад. У MVP жодної з цих функцій немає.

Вимоги модуля: AI-01, AI-02, AI-03, AI-04, INT-01, PLN-01, PLN-02, PLN-03, ADV-01, ADV-02, ADV-03, ADV-04, ADV-05, ADV-06, ADV-07.

**Спільні для модуля поняття.**
- Обмежений учасник — учасник з роллю Editor, Viewer або Advisor, якому Owner чи Admin обмежив доступ за класами активів, власниками (прямі частки), групами або окремими активами, з прапорцями «Без вартості» і «Без документів». Виміру «рахунки» в обмеженні немає. Обмежений учасник лише читає. Масові дії й експорт для нього закриті завжди; фінанси (рахунки, транзакції), бюджет, журнал аудиту, збережені представлення, AI-функції, API-токени і планування закриті за замовчуванням, і політика видимості простору може відкрити їх лише для перегляду.
- Приватний рахунок — рахунок, який його єдиний власник позначив як приватний. Він прихований від інших учасників у списку рахунків, транзакціях, черзі перегляду, бюджеті, сповіщеннях і net worth. У net worth власник обирає режим: «рядок» (один рядок «Приватний рахунок» без деталей, сума входить у підсумок) або «приховано» (рахунок не входить у підсумок для інших).
- Ніхто не дізнається про записи поза своїми правами: ні про самі записи, ні про їх кількість, ні про суми. Екран «Немає доступу» показується лише для цілого модуля або віджета, а обмеження плану — екраном пропозиції апгрейду.
- Ліміти і доступність функцій за планом задаються матрицею планів і змінюються без релізу. Ліміт блокує лише створення нового і нічого не видаляє та не ховає. Під час перевищення API повертає 402 PLAN_LIMIT_REACHED, а інтерфейс показує екран порівняння планів.
