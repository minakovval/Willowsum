## 5. Імпорт, дані, документи, сповіщення, звіти

Модуль охоплює сховище документів і їх типи, страхові поліси й аналіз покриття, сповіщення і тригери, універсальний список, глобальний пошук, масові дії, єдиний імпорт даних, стани екранів, підтримку, стандартні й заплановані звіти, а також імпорт банківських виписок: рушій розпізнавання, рецепти й шаблони, мультивалютність, парування, контрольні суми, PDF і OCR.

Вимоги модуля: DOC-01, DOC-02, DOC-03, INS-01, INS-02, NOT-01, NOT-02, DAT-01, DAT-02, DAT-03, DAT-04, DAT-05, SUP-01, RPT-01, RPT-02, IMP-01, IMP-02, IMP-03, IMP-04, IMP-05, IMP-06, IMP-07, IMP-08, IMP-09, IMP-10, IMP-11, IMP-12, IMP-13, IMP-14, IMP-15, IMP-16, IMP-17, IMP-18, IMP-19.

Терміни модуля: «простір» — спільний облік родини або особи (межа ізоляції даних, ключів шифрування і білінгу); «учасник» — користувач простору з роллю Owner, Admin, Editor або Viewer; «обмежений scope» — учасник Editor або Viewer, якому Owner чи Admin обмежив доступ класами активів, власниками (прямі частки), групами або окремими активами, з прапорцями «Без вартості» і «Без документів». Учасник з обмеженим scope лише читає. Масові дії, експорт, імпорт і парування для нього закриті завжди; фінанси (рахунки, транзакції), портфелі, бюджет, страхування, зобов'язання, локації, журнал аудиту і збережені представлення закриті за замовчуванням, і політика видимості простору може відкрити їх лише для перегляду. Ніхто не дізнається про записи поза своїм scope: ні про самі записи, ні про їх кількість, ні про суми.
