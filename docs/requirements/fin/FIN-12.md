# FIN-12 · Керування рахунками

**Реліз:** PoC (без приховування рахунків; кредити — рахунки типу «Кредит» у групі «Кредитні»); PoC v2 (приховування рахунків); MVP (кредити — зобов'язання поза «Грошима», обране у віджеті «Рахунки» на Головній, двофакторна автентифікація для змін); v1 (завершена звірка робить тимчасове коригування постійним) · **Пріоритет:** M

**Зв'язки**
- Зрізи: FIN-12@PoC, FIN-12@PoC v2, FIN-12@MVP, FIN-12@v1
- Модуль: accounts, ledger

**Мета.** Як власник простору, я хочу впорядковувати, групувати, приховувати й закривати рахунки без втрати історії, щоб список рахунків відповідав моїй реальній фінансовій картині.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
