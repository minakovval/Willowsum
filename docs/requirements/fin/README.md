# FIN — module requirements

Scope: Accounts, bank aggregation, transactions, journal, recurring payments. Source: tab 3 of the Willowsum product specification.

## Text from the specification tab (outside individual requirements)

<!-- spec-text:begin -->
## 3. Фінанси, інвестиції та інтеграції

Модуль «Фінанси, інвестиції та інтеграції» охоплює грошові рахунки й транзакції, внутрішній журнал подвійного запису, інвестиційні портфелі та інструменти, криптоактиви, приватні інвестиції, пенсійні накопичення, кредитні картки, підключення банків і інших провайдерів даних та єдиний стандарт інтеграцій. Усі суми в прикладах наведено в EUR або UAH.

Вимоги модуля: FIN-01, FIN-02, FIN-03, FIN-04, FIN-05, FIN-06, FIN-07, FIN-08, FIN-09, FIN-10, FIN-11, FIN-12, FIN-13, FIN-14, FIN-15, FIN-16, FIN-17, FIN-18, FIN-19, INV-01, INV-02, INV-03, CRY-01, CRY-02.

<!-- spec-text:end -->
