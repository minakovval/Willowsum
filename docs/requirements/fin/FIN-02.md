# FIN-02 · Агрегація банків

**Реліз:** PoC (ручні рахунки; автоматичні підключення: monobank — персональний токен; Revolut і BBVA — через Enable Banking у режимі лише власних рахунків тестувальників; Raiffeisen Україна — імпорт файлів); MVP (підключення для всіх користувачів через договір з ліцензованим агрегатором); v1 (застосування лімітів плану) · **Пріоритет:** M

**Зв'язки**
- Зрізи: FIN-02@PoC, FIN-02@MVP, FIN-02@v1
- Модуль: accounts, bank-consents, bank-enablebanking, bank-monobank, bank-saltedge, bank-sync, notification-delivery, usage-limits

**Мета.** Як користувач, я хочу підключити банк за хвилину і більше не вводити залишки вручну, щоб дані були актуальними без зусиль.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
