# VAL-05 · Фіди курсів і цін

**Реліз:** PoC (лише щоденні курси валют з НБУ, інші пари — крос-курсом через гривню); PoC v2 (ECB для основних валют, НБУ для гривні); MVP (раз на добу для всіх планів, ціни інструментів); v1 (щогодини для Plus і Family) · **Пріоритет:** M

**Зв'язки**
- Зрізи: VAL-05@PoC, VAL-05@PoC v2, VAL-05@MVP, VAL-05@v1
- Модуль: fx-rates, market-data

**Мета.** Як власник акцій, криптовалюти та активів у валюті, я хочу, щоб ціни та курси оновлювалися автоматично, щоб не вводити їх вручну.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| PoC | [VAL-05.poc.md](VAL-05.poc.md) | Щоденні курси валют лише з НБУ (один адаптер; EUR та інші пари — крос-курсом через гривню) через абстракцію провайдера, повтори і подія рівня «помилка» в журналі сервера після 24 год без оновлення |

| v1 | [VAL-05.v1.md](VAL-05.v1.md) | Щогодинне оновлення для Plus, Family і Trial |
