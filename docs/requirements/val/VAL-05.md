# VAL-05 · Фіди курсів і цін

**Реліз:** PoC (лише щоденні курси валют: ECB для основних валют, НБУ для гривні); MVP (раз на добу для всіх планів, ціни інструментів); v1 (щогодини для Plus і Family) · **Пріоритет:** M

**Зв'язки**
- Зрізи: VAL-05@PoC, VAL-05@MVP, VAL-05@v1
- Модуль: fx-rates, market-data

**Мета.** Як власник акцій, криптовалюти та активів у валюті, я хочу, щоб ціни та курси оновлювалися автоматично, щоб не вводити їх вручну.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
