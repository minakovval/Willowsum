# VAL-03 · Свіжість оцінки

**Реліз:** MVP (нормативи за замовчуванням за типом активу, позначка «застаріла», пункт у списку дій і в щотижневому підсумку); v1 (налаштування нормативу для окремого активу, автоматичний фід) · **Пріоритет:** S

**Зв'язки**
- Зрізи: VAL-03@MVP, VAL-03@v1
- Модуль: auto-valuation, valuation

**Мета.** Як власник, я хочу знати, які вартості застаріли, і отримувати нагадування, щоб net worth не втрачав достовірності з часом.
