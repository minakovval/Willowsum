# BUD-11 · Ручний режим без підключення банку

**Реліз:** PoC (без сповіщень, без Головної і онбордингу); MVP (ролі й учасники простору; крок «Вести вручну» в онбордингу, нагадування «Внести витрати», двофакторна автентифікація для змін); v1-mobile (швидке додавання в мобільному застосунку, зокрема офлайн) · **Пріоритет:** M

**Зв'язки**
- Зрізи: BUD-11@PoC, BUD-11@MVP, BUD-11@v1-mobile
- Модуль: duplicate-matching, transactions

**Мета.** Як користувач, що не хоче або не може підключити банк, я хочу швидко вносити витрати вручну та мати той самий бюджет і цілі.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
