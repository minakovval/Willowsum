# BUD-01 · Категорії витрат і доходів

**Реліз:** PoC (без методу Flex: правило групи «Фіксовані» не діє); PoC v2 (обов'язкова категорія входить у групу «Фіксовані» методу Flex); MVP (ролі й учасники простору; двофакторна автентифікація для змін; особисті бюджети інших учасників закриті для обмеженого scope) · **Пріоритет:** M

**Зв'язки**
- Зрізи: BUD-01@PoC, BUD-01@PoC v2, BUD-01@MVP
- Модуль: categories, categorization

**Мета.** Як власник бюджету, я хочу, щоб транзакції автоматично потрапляли в зрозумілі категорії, а помилку я міг виправити один раз для всіх подібних, щоб бюджет і порівняння витрат були точними без ручної роботи.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| PoC | [BUD-01.poc.md](BUD-01.poc.md) | Дерево категорій, автокатегоризація, правило з деталі транзакції, розділення, об'єднання, кольори й іконки, атрибут «обов'язкова»; бюджет лише за методом «Ліміти» |
| PoC v2 | [BUD-01.poc-v2.md](BUD-01.poc-v2.md) | Обов'язкова категорія входить у групу «Фіксовані» методу Flex |
