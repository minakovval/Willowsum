## 4. Бюджет, цілі накопичення та витрати

Модуль «Бюджет, цілі накопичення та витрати» охоплює категорії й розбір транзакцій, бюджет періоду і суму «Можна витратити», цілі накопичення, регулярні платежі, грошовий потік, спільний бюджет родини, сповіщення, ручний режим, атрибути транзакцій, правила, чеки, методи бюджетування, керування планом, цільові суми категорій, калькулятор погашення боргів і конструктор звітів. Усі вимоги модуля входять у реліз MVP (веб: десктоп і мобільний браузер від 360 px); критерії для мобільних застосунків позначено «(v1-mobile)». Приклади сум наведено в EUR; базова валюта простору — EUR (для локалі uk-UA — UAH).

Вимоги модуля: BUD-01, BUD-02, BUD-03, BUD-04, BUD-05, BUD-06, BUD-07, BUD-08, BUD-09, BUD-10, BUD-11, BUD-12, BUD-13, BUD-14, BUD-15, BUD-16, BUD-17, BUD-18, BUD-19, BUD-20.
