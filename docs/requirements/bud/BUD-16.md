# BUD-16 · Методи бюджетування

**Реліз:** PoC (лише метод «Ліміти», без перенесення залишку); PoC v2 (методи Flex і «Кожній копійці — завдання», зміна методу, вкладка «Метод», перенесення залишку); MVP (метод особистого бюджету, сповіщення учасників про зміну методу, двофакторна автентифікація для змін); v1 (застосування ліміту плану до методів Flex і «Кожній копійці — завдання») · **Пріоритет:** S

**Зв'язки**
- Зрізи: BUD-16@PoC, BUD-16@PoC v2, BUD-16@MVP, BUD-16@v1
- Модуль: budget

**Мета.** Як власник бюджету, я хочу обрати метод бюджетування — ліміти, Flex або «Кожній копійці — завдання» — і змінювати його без втрати даних, щоб планувати так, як мені зручно.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
