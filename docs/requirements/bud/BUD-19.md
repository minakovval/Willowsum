# BUD-19 · Погашення боргів

**Реліз:** PoC (борги — кредитні картки і кредити з розділу «Гроші»; без розділу «Активи › Зобов'язання»); MVP (ролі й учасники простору; зобов'язання з розділу «Активи › Зобов'язання», двофакторна автентифікація для змін); v1 (застосування ліміту плану до планів погашення); v2 (поширення прогресу картинкою) · **Пріоритет:** S

**Зв'язки**
- Зрізи: BUD-19@PoC, BUD-19@MVP, BUD-19@v1, BUD-19@v2
- Модуль: debt-payoff

**Мета.** Як власник боргів, я хочу бачити дату погашення і суму відсотків за різних сценаріїв платежів і стратегій, щоб самостійно вирішити, як швидше вийти з боргів.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
