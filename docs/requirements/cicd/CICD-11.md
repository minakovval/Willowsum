# CICD-11 · Метрики поставки

**Реліз:** MVP · **Пріоритет:** S

| Метрика | Ціль |
| --- | --- |
| Час від злиття PR до staging | ≤ 30 хв |
| Частота релізів у production | Щонайменше раз на тиждень у період активної розробки |
| Частка релізів, що потребували відкату або термінового виправлення | ≤ 15 % |
| Час відновлення після інциденту у робочий час | ≤ 1 год |
| Частка нестабільних тестів | ≤ 1 %; нестабільний тест виправляється протягом 5 робочих днів |
