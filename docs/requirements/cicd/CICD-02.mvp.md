*Перевірки і пороги*

3. Типи (TypeScript strict), лінтер, форматування — поріг: 0 помилок.
4. Межі модулів і заборонені імпорти (числа з рухомою комою для сум, SDK провайдерів поза адаптерами) — поріг: 0 порушень.
5. Unit-тести — поріг: усі зелені; покриття доменного шару ≥ 90 %, бізнес-логіки ≥ 80 %; покриття не зменшується.
6. Тести властивостей для грошей, журналу проводок і часток власності — поріг: усі зелені.
7. Інтеграційні тести на справжній PostgreSQL 17 (включно з тестами ізоляції просторів і прав для кожної ролі) — поріг: усі зелені.
8. Контрактні тести API і порівняння контракту з main — поріг: 0 несумісних змін.
9. Міграції: застосування на порожній БД і на синтетичній копії, сумісність зі старим кодом — поріг: успішно.
10. E2E-тести вебу і адмін-панелі на ширинах 390, 768 і 1280 px — поріг: усі зелені.
11. Доступність (axe) на тих самих ширинах — поріг: 0 critical і serious.
12. Ключі перекладів (жодного рядка, зашитого в код) — поріг: 0 порушень.
13. Статичний аналіз безпеки коду — поріг: 0 знахідок High і Critical.
14. Сканування секретів — поріг: 0 знахідок.
15. Вразливості залежностей — поріг: 0 High і Critical у production-залежностях; винятки — лише з власником і датою перегляду.
16. Ліцензії залежностей — поріг: лише зі списку дозволених (MIT, Apache-2.0, BSD, ISC тощо).
17. Тривалість повного конвеєра PR — поріг: ≤ 15 хв.
