# CICD-02 · Обов'язкові перевірки PR

**Реліз:** PoC (E2E-тести лише на ширині 1280 px, без перевірки доступності axe); PoC v2 (E2E-тести адмін-панелі); MVP (ширини 390 і 768 px, перевірка доступності axe) · **Пріоритет:** M

**Зв'язки**
- Зрізи: CICD-02@PoC, CICD-02@PoC v2, CICD-02@MVP
- Модуль: —

Кожен PR проходить усі перевірки; червона перевірка блокує злиття. Вимикати, пропускати чи послаблювати тести, щоб отримати зелений статус, заборонено.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| PoC | [CICD-02.poc.md](CICD-02.poc.md) | Усі перевірки PR; E2E-тести вебу лише на ширині 1280 px (без адмін-панелі); без перевірки доступності axe; без перевірки ліцензій залежностей |
| PoC v2 | [CICD-02.poc-v2.md](CICD-02.poc-v2.md) | E2E-тести адмін-панелі на ширині 1280 px; перевірка ліцензій залежностей за списком дозволених |
| MVP | [CICD-02.mvp.md](CICD-02.mvp.md) | E2E-тести на ширинах 390, 768 і 1280 px; перевірка доступності axe на тих самих ширинах |
