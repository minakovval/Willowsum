# CICD-10@v1-mobile · Мобільні застосунки

**Реліз:** v1-mobile · **Пріоритет:** M

**Зв'язки**
- Розширює: —
- Залежить від: CICD-02@MVP, CICD-05@MVP
- Дизайн: —
- Спільні правила: NFR-13
- Сценарії: —
- Модуль: —
- Перевіряється: —

1. Збірки iOS і Android створюються хмарним сервісом збірки React Native з того самого репозиторію; те саме набір перевірок PR діє для мобільного коду.
2. Подання в стори — лише за схваленням власника, з поступовим випуском (1 % → 10 % → 100 % за відсутності збоїв).
3. Оновлення без стору (OTA) — лише для змін без нативного коду, за тим самим схваленням; застосунок відкочується на попереднє оновлення, якщо нове не запускається.
4. Сервер підтримує дві останні мажорні версії застосунку; старіша версія отримує екран «Оновіть застосунок».
