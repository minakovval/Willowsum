## Джерело зрізів

**Реліз:** PoC · **Пріоритет:** M

**Зв'язки**
- Розширює: —
- Залежить від: CICD-02@PoC
- Дизайн: —
- Спільні правила: NFR-15
- Сценарії: —
- Модуль: —
- Перевіряється: —

#. [PoC] З кожного коміту в main збирається один образ з тегом, що дорівнює хешу коміту. Той самий образ без перезбирання проходить усі розгорнуті середовища, зокрема production.
#. [PoC] До образу додається перелік компонентів (SBOM), образ сканується на вразливості та підписується; середовище запускає лише підписані образи.
#. [PoC] Дії конвеєра закріплені за повним хешем; конвеєр має мінімальні права; для доступу до хмари використовуються короткоживучі токени (OIDC), де хмара це підтримує.
#. [PoC] Оновлення залежностей пропонує бот щотижня окремими PR; версії, випущені менше ніж 7 днів тому, не приймаються (крім виправлень безпеки).

| Критерій | Поріг | Перевірка |
| --- | --- | --- |
| Образ без підпису або SBOM у середовищі | 0 | Перевірка перед розгортанням |
| Вразливості High і Critical у образі | 0 на момент релізу | Сканер образів |
| Дії конвеєра без закріпленого хешу | 0 | Перевірка у CI |
