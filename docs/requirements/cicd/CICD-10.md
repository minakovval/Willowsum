## Джерело зрізів

**Реліз:** v1-mobile · **Пріоритет:** M

**Зв'язки**
- Розширює: —
- Залежить від: CICD-02@MVP, CICD-05@MVP
- Дизайн: —
- Спільні правила: NFR-13
- Сценарії: —
- Модуль: —
- Перевіряється: —

#. [v1-mobile] Збірки iOS і Android створюються хмарним сервісом збірки React Native з того самого репозиторію; те саме набір перевірок PR діє для мобільного коду.
#. [v1-mobile] Подання в стори — лише за схваленням власника, з поступовим випуском (1 % → 10 % → 100 % за відсутності збоїв).
#. [v1-mobile] Оновлення без стору (OTA) — лише для змін без нативного коду, за тим самим схваленням; застосунок відкочується на попереднє оновлення, якщо нове не запускається.
#. [v1-mobile] Сервер підтримує дві останні мажорні версії застосунку; старіша версія отримує екран «Оновіть застосунок».
