# GRID-06 · Сітки сторінок входу і онбордингу

**Реліз:** PoC (вхід і реєстрація, без онбордингу); решта — MVP · **Пріоритет:** M

**Зв'язки**
- Зрізи: GRID-06@PoC, GRID-06@MVP
- Модуль: —

**Мета.** Як новий або повторний користувач, я хочу, щоб вхід і онбординг були зосередженими екранами без зайвої навігації, щоб спокійно увійти, налаштувати продукт і не відволікатися.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
