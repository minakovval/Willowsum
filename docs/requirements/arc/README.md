## 13. Архітектура і CI/CD

### 13.0 Контекст і вихідні умови

Архітектура має давати змогу безпечно змінювати одну частину продукту, не зачіпаючи решти. Вона працює на мінімальній інфраструктурі зараз і переходить на комерційну інфраструктуру зміною конфігурації, а не переписуванням коду.

| Умова | Значення |
| --- | --- |
| Команда | Код пишуть AI-агенти; власник продукту схвалює релізи і дії в production |
| Бюджет на старті | Мінімальний: безкоштовні або найдешевші ресурси |
| Масштаб на 2 роки | До 10 000 просторів (родин); одна база даних і один регіон |
| Регіони даних | Розгортається лише ЄС; модель даних і ключі дозволяють додати інший регіон без переписування |
| Репозиторій і CI | GitHub на безкоштовному плані, GitHub Actions; технічного захисту гілки немає, тому захист забезпечують права доступу і конвеєр поставки |
| Релізи в production | За схваленням власника, у будь-який момент |
| Спостережуваність | Безкоштовні тарифи сервісів із даними в ЄС, через відкритий стандарт OpenTelemetry |
| Реагування на збої | Власник у робочий час; алерти в Telegram, критичні — також на email; перший розбір інциденту робить AI-агент |
| Доступ агентів | Код і staging; у production — читання дашбордів і логів без персональних даних та заздалегідь описані дії за схваленням власника |
| Мобільні застосунки | React Native (Expo) у тому ж монорепозиторії |

#### Профілі розгортання

Код однаковий для обох профілів; відрізняються лише конфігурація та опис інфраструктури.

| Складова | Профіль «Старт» (зараз) | Профіль «Комерційний» (після перших платних клієнтів) |
| --- | --- | --- |
| Обчислення | Одна віртуальна машина в ЄС із безкоштовного тарифу хмари; контейнери під Docker Compose | Керований сервіс контейнерів або дві ВМ у різних зонах доступності ЄС |
| База даних | PostgreSQL у контейнері; безперервне архівування журналу записів (WAL) і шифрована копія в іншому регіоні ЄС | Керована PostgreSQL із відновленням на будь-який момент за 35 днів і резервною реплікою |
| Файли | S3-сумісне сховище хмари | Те саме або інше S3-сумісне сховище в ЄС |
| Ключі і секрети | Головний ключ — у керованому KMS хмари хостингу (OCI Vault); інші секрети — у секретах хоста з обмеженим доступом | Керований KMS і сховище секретів хмари |
| Черга задач | Таблиці PostgreSQL | Те саме (до 10 000 просторів окремий брокер не потрібен) |
| Вхідний трафік | Зворотний проксі на ВМ + CDN із захистом від DDoS | Те саме + балансувальник хмари |
| Доступність | Ціль 99,9 % без SLA; RPO ≤ 15 хв, RTO ≤ 4 год | 99,9 % із SLA; RPO ≤ 5 хв, RTO ≤ 1 год |
| Перехід між профілями | — | За ранбуком, з простоєм ≤ 1 год; без змін коду застосунку |

| [ARC-09](ARC-09.md) | Спостережуваність | PoC (структуровані логи на сервері без експорту телеметрії, щотижневе сканування логів на персональні дані; без зовнішньої перевірки доступності, SLO, алертів і чергового); MVP (експорт телеметрії в сервіс із даними в ЄС, SLO і алерти, зовнішній монітор доступності) | M |
| [ARC-10](ARC-10.md) | Масштаб і продуктивність | PoC v2 (основа в архітектурі й моделі даних: горизонтальне масштабування API і воркерів, знімки підсумків); MVP (навантажувальний тест) | M |
