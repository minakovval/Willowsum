# ARC-06 · Ключі, секрети, файли

**Реліз:** PoC (без токенів банківських провайдерів); PoC v2 (токени банківських провайдерів під ключем підключення; перша репетиція ротації головного ключа з хмарним KMS на тимчасовому середовищі форми production) · **Пріоритет:** M

**Зв'язки**
- Зрізи: ARC-06@PoC, ARC-06@PoC v2
- Модуль: —

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
