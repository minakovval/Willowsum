#. [PoC] Один образ контейнера запускається в трьох ролях: API, воркер фонових задач, планувальник задач за розкладом. Роль задає команда запуску.
#. [PoC] Процеси не зберігають стану в пам'яті чи на диску між запитами; будь-який екземпляр можна зупинити або додати без втрати даних.
#. [PoC] Конфігурація — лише змінні середовища та секрети, перевірені схемою під час старту. З некоректною конфігурацією процес не стартує.
#. [PoC] Кожен процес має перевірки «живий» і «готовий»; «готовий» перевіряє з'єднання з БД і версію схеми.
#. [PoC] Зупинка процесу — коректна: API довершує запити до 30 с, воркер повертає незавершені задачі в чергу.

| Критерій | Поріг | Перевірка |
| --- | --- | --- |
| [лише PoC] Запити, втрачені під час коректної зупинки | 0 | Інтеграційний тест коректної зупинки в CI |
| [PoC v2] Запити, втрачені під час перезапуску | 0 | Навантажувальний тест під час розгортання на тимчасовому середовищі форми production |
| Час старту екземпляра до «готовий» | ≤ 20 с | Вимір у CI |
| Старт із пропущеним обов'язковим секретом | Відмова з назвою змінної (без значення) | Тест |
