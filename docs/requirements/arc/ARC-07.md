#. [PoC] Усі клієнти (веб, адмін-панель, мобільний застосунок, зовнішній API) працюють через один задокументований HTTP API. Прямого доступу клієнтів до БД немає.
#. [PoC] Контракт API описаний у форматі OpenAPI 3.1 і генерується з тих самих схем, що перевіряють запити. Клієнтський пакет генерується з контракту.
#. [PoC] Версія в шляху (/v1). Зміни в межах версії — лише сумісні (додавання полів і маршрутів). Видалення — лише після позначки «застаріле» і щонайменше 6 місяців (для мобільних клієнтів — поки частка старих версій не стане < 1 %).
#. [PoC] Помилки — у єдиному форматі «problem details» із машинним кодом. Запити на створення приймають ключ ідемпотентності. Списки — із серверною пагінацією.
#. [лише PoC] Клієнти: веб-застосунок на React; мобільний — React Native. Адмін-панелі в PoC немає (рішення власника 2026-11-12); її окремий застосунок з'являється разом із нею. Спільні пакети: доменна логіка (гроші, формули), клієнт API, переклади, дизайн-токени.
#. [лише PoC] Адмін-панелі в PoC немає (рішення власника 2026-11-12), тож окремого домену, автентифікації персоналу і списку дозволених IP для неї в цьому релізі немає.
#. [PoC v2] Клієнти: веб-застосунок і адмін-панель — окремі застосунки на React; мобільний — React Native. Спільні пакети: доменна логіка (гроші, формули), клієнт API, переклади, дизайн-токени.
#. [PoC v2] Адмін-панель розгортається на окремому домені з окремою автентифікацією персоналу та списком дозволених IP.
