# ARC-08@PoC v2 · Переносимість між профілями розгортання

**Реліз:** PoC v2 · **Пріоритет:** M

**Зв'язки**
- Розширює: —
- Залежить від: ARC-05@PoC, ARC-06@PoC v2
- Дизайн: —
- Спільні правила: П-24, CICD-07
- Сценарії: —
- Модуль: —
- Перевіряється: —

1. Застосунок використовує лише стандартні технології, які є в будь-якої хмари ЄС: образи OCI, PostgreSQL, S3-сумісне сховище, SMTP або HTTP-API пошти, OpenTelemetry.
2. Пропрієтарні сервіси конкретної хмари використовуються лише через адаптери.
3. Інфраструктура обох профілів описана кодом (OpenTofu або Terraform) у репозиторії.
4. Перехід між профілями описаний ранбуком: розгортання нового середовища, реплікація або відновлення БД, перенесення файлів і переобгортання ключів під новий KMS, перемикання DNS.

| Критерій | Поріг | Перевірка |
| --- | --- | --- |
| Зміни коду застосунку для переходу між профілями | 0 | Репетиція переходу на тимчасовому середовищі форми production до запуску платних підписок |
| Простій під час переходу | ≤ 1 год | Вимір під час репетиції |
| Середовище з нуля з опису інфраструктури | ≤ 1 год | Щоквартальний прогін |
