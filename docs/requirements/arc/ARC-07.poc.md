1. Усі клієнти (веб, адмін-панель, мобільний застосунок, зовнішній API) працюють через один задокументований HTTP API. Прямого доступу клієнтів до БД немає.
2. Контракт API описаний у форматі OpenAPI 3.1 і генерується з тих самих схем, що перевіряють запити. Клієнтський пакет генерується з контракту.
3. Версія в шляху (/v1). Зміни в межах версії — лише сумісні (додавання полів і маршрутів). Видалення — лише після позначки «застаріле» і щонайменше 6 місяців (для мобільних клієнтів — поки частка старих версій не стане < 1 %).
4. Помилки — у єдиному форматі «problem details» із машинним кодом. Запити на створення приймають ключ ідемпотентності. Списки — із серверною пагінацією.
5. Клієнти: веб-застосунок і адмін-панель — окремі застосунки на React; мобільний — React Native. Спільні пакети: доменна логіка (гроші, формули), клієнт API, переклади, дизайн-токени.
6. Адмін-панель розгортається на окремому домені з окремою автентифікацією персоналу та списком дозволених IP.
