# SCR — module requirements

Scope: Screen inventory and screen rules. Source: tab 12 of the Willowsum product specification.

## Module intro (from the specification tab)

Вкладка описує наскрізні користувацькі потоки Willowsum (від точки входу до результату), карти досвіду ключових персон і повний інвентар екранів вебпродукту та адмін-панелі з правилами, спільними для всіх екранів. Потоки зберігають свої історичні номери; кожен потік самодостатній і описує поведінку поточної версії продукту: MVP — лише веб (десктоп і мобільний браузер від 360 px), ручні рахунки, імпорт виписок і автоматичне підключення банків (monobank — персональний токен, Enable Banking, Salt Edge після юридичних умов), навігація першого рівня «Головна», «Гроші», «Активи», «Планування», «Ще».

Shared text of this tab (title, intro, common sections) is kept in [../flw/README.md](../flw/README.md).
