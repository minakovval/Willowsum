# FCS-01 · Прогноз витрат періоду

**Реліз:** PoC (лише один бюджет простору, кредит — рахунок типу «Кредит» із щомісячним платежем, без страхових премій); PoC v2 (разові витрати з перевірки «Чи можу я собі дозволити?» і непокриті цільові суми категорій у запланованих витратах; стан «Режим без бюджету»); MVP (ролі й учасники простору; прогноз особистих бюджетів, платежі за графіками кредитів, типовий платіж кредиту без графіка, страхові премії полісів) · **Пріоритет:** M

**Зв'язки**
- Зрізи: FCS-01@PoC, FCS-01@PoC v2, FCS-01@MVP
- Модуль: cashflow

**Мета.** Як власник бюджету, я хочу бачити, де опиняться мої витрати на кінець періоду за поточного темпу і з урахуванням запланованих платежів, щоб заздалегідь знати, чи вистачить бюджету і коли гроші закінчаться.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| PoC | [FCS-01.poc.md](FCS-01.poc.md) | Прогноз витрат періоду для спільного бюджету; кредит — рахунок типу «Кредит» із щомісячним платежем; без страхових премій; без цільових сум категорій і «Режиму без бюджету»; разові заплановані витрати — лише з плану погашення боргу |
| PoC v2 | [FCS-01.poc-v2.md](FCS-01.poc-v2.md) | Датовані заплановані витрати включають разові витрати з перевірки «Чи можу я собі дозволити?» і непокриту частину цільових сум категорій; стан «Режим без бюджету» |
| MVP | [FCS-01.mvp.md](FCS-01.mvp.md) | Прогноз особистих бюджетів (особисті бюджети з'являються в MVP); платежі за графіками активних кредитів, типовий платіж кредиту без відомого графіка, страхові премії полісів; двофакторна автентифікація для змін; ролі й учасники простору |
