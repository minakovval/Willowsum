# FCS-01 · Прогноз витрат періоду

**Реліз:** PoC (кредит — рахунок типу «Кредит» із щомісячним платежем, без страхових премій); MVP (платежі за графіками кредитів, типовий платіж кредиту без графіка, страхові премії полісів) · **Пріоритет:** M

**Зв'язки**
- Зрізи: FCS-01@PoC, FCS-01@MVP
- Модуль: cashflow

**Мета.** Як власник бюджету, я хочу бачити, де опиняться мої витрати на кінець періоду за поточного темпу і з урахуванням запланованих платежів, щоб заздалегідь знати, чи вистачить бюджету і коли гроші закінчаться.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| PoC | [FCS-01.poc.md](FCS-01.poc.md) | Прогноз витрат періоду; кредит — рахунок типу «Кредит» із щомісячним платежем; без страхових премій. Діє також у PoC v2 |
| MVP | [FCS-01.mvp.md](FCS-01.mvp.md) | Платежі за графіками активних кредитів, типовий платіж кредиту без відомого графіка, страхові премії полісів; двофакторна автентифікація для змін |
