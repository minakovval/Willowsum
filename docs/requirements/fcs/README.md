## Прогнози

Модуль «Прогнози» описує розрахунок прогнозу витрат періоду бюджету, «розумну» перевірку темпу витрат із трьома станами («У межах плану», «Швидше за план», «Перевитрата») і графік темпу та прогнозу у віджеті «Можна витратити» на Головній. Обов'язкові платежі (оренда, садочок чи школа, інші регулярні платежі) входять у план на свої дати, а з планом порівнюються лише дискреційні витрати. Попередження вмикається лише тоді, коли дискреційні витрати перевищують очікувані щонайменше на 20 % і прогноз показує недобір до кінця періоду. Усі суми — десяткові значення в мінімальних одиницях валюти, без чисел з рухомою комою. Усі вимоги модуля входять у реліз MVP. Приклади сум наведено в EUR.

Вимоги модуля: FCS-01, FCS-02, FCS-03.
