# UX-01 · Онбординг

**Реліз:** MVP; v1 (ліміти функцій, які відкриває чек-лист) · **Пріоритет:** M

**Зв'язки**
- Зрізи: UX-01@MVP, UX-01@v1
- Модуль: dashboard, demo-space, onboarding, usage-limits

**Мета.** Як новий користувач, я хочу пройти коротке інтро і налаштувати продукт у власному темпі та порядку, щоб швидко отримати першу корисну картину фінансів без перевантаження розширеними модулями.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.

| Реліз | Зріз | Що змінюється порівняно з попереднім зрізом |
| --- | --- | --- |
| MVP | [UX-01.mvp.md](UX-01.mvp.md) | Інтро, питання про мету, чек-лист налаштування, демо-простір, рівні складності; ліміти не застосовуються |
| v1 | [UX-01.v1.md](UX-01.v1.md) | Застосування лімітів плану: функції, які відкриває чек-лист, показують порівняння планів при досягненні ліміту |
