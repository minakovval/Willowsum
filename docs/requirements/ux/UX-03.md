# UX-03 · Налаштовуваний головний екран

**Реліз:** MVP; v1-mobile (окрема розкладка мобільного застосунку); v1 (пропозиція апгрейду для віджета поза планом) · **Пріоритет:** S

**Зв'язки**
- Зрізи: UX-03@MVP, UX-03@v1-mobile, UX-03@v1
- Модуль: dashboard, usage-limits

**Мета.** Як користувач, я хочу сам обирати, які віджети і в якому порядку бачу на головному екрані окремо на вебі й на телефоні, щоб одразу бачити найважливіше для мене.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
