# UX-02 · Приховування сум

**Реліз:** MVP; v1-mobile (push, заблокований екран, віджети і знімки екрана в мобільному застосунку) · **Пріоритет:** S

**Зв'язки**
- Зрізи: UX-02@MVP, UX-02@v1-mobile
- Модуль: dashboard, identity

**Мета.** Як користувач, який відкриває застосунок на людях або показує екран іншим, я хочу одним перемикачем приховати всі суми, щоб ніхто поруч не бачив моїх фінансових даних.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
