# UX-04 · Командний рядок і скорочення

**Реліз:** MVP; v1 (пункт «Запитати AI») · **Пріоритет:** S

**Зв'язки**
- Зрізи: UX-04@MVP, UX-04@v1
- Модуль: ai-assistant, search

**Мета.** Як досвідчений користувач вебверсії, я хочу викликати командний рядок і користуватися клавіатурними скороченнями, щоб переходити між розділами, виконувати дії, шукати і ставити питання без миші.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
