## Джерело зрізів

**Реліз:** v2 · **Пріоритет:** C

**Зв'язки**
- Розширює: —
- Залежить від: INT-01@v2
- Дизайн: S-214, S-215
- Спільні правила: П-5, П-8, П-23, SCR-02
- Сценарії: UC-INT-01, UC-INT-02, UC-INT-03, UC-INT-04, UC-INT-05, UC-INT-06, UC-INT-07, UC-INT-08, UC-INT-09
- Модуль: integrations
- Перевіряється: —

**Мета.** Як учасник простору, я хочу дати зовнішньому інструменту (AI-асистенту через MCP, таблиці, автоматизації) контрольований доступ до своїх даних.

**Актор і точка входу.** Будь-який учасник без обмеженого scope — для себе: «Налаштування → Інтеграції → API-токени» або «MCP-конектор».

**Основний шлях**

#. [v2] Екран «API-токени» показує токени користувача: назва, права, дата створення, строк дії, останнє використання.
#. [v2] «Створити токен»: назва, права читання і окремо запису за розділами даних, строк дії від 1 дня до 1 року (30, 90, 365 днів за замовчуванням).
#. [v2] Токен показується один раз із кнопкою «Скопіювати» і попередженням, що повторно його не побачити.
#. [v2] «MCP-конектор» показує інструкцію підключення і перемикачі прав (за замовчуванням лише читання).
#. [v2] Журнал доступу показує кожне звернення: час, токен, точку доступу, результат.
#. [v2] Кнопка «Відкликати» біля кожного токена і підключення; токен перестає діяти протягом 60 с.

**Гілки та помилки**

- [v2] Права запису доступні лише ролям із правом редагування з увімкненою 2FA.
- [v2] Обмежений учасник не може створювати токени.
- [v2] Понад 60 запитів на хвилину — відповідь 429 із часом повтору.
- [v2] За 7 днів до закінчення строку — нагадування.
- [v2] Зміни через API чи MCP позначаються в журналі аудиту назвою токена.

**Екрани і стани:** API-токени (порожній, список) · Створення токена · Токен створено (показ один раз) · MCP-конектор · Журнал доступу.

**Метрика успіху.** Підключення інтеграції займає не більше 2 хв; 0 випадків доступу поза визначеними правами.

**Критерії приймання**

#. [v2] **Given** Editor без 2FA **When** він створює токен **Then** права запису недоступні з підказкою увімкнути 2FA.
#. [v2] **Given** Viewer **When** він створює токен **Then** доступні лише права читання.
#. [v2] **Given** строк 400 днів **When** користувач зберігає токен **Then** збереження заблоковано з підказкою про максимум 1 рік.
#. [v2] **Given** токен створено **When** користувач закриває вікно **Then** значення токена більше ніде не показується.
#. [v2] **Given** 61 запит за хвилину **When** надходить 61-й **Then** відповідь 429 із часом повтору.
#. [v2] **Given** токен відкликано **When** минає 60 с **Then** запити з ним відхиляються.
#. [v2] **Given** зміна даних через токен «Таблиця» **When** відкривається журнал аудиту **Then** зміна позначена як зроблена через інтеграцію «Таблиця».

**Граничні випадки**

- [v2] Токен діє лише в межах прав свого власника на момент запиту.
