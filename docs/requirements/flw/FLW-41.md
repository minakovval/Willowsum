# FLW-41 · Правила і мерчанти

**Реліз:** PoC (без сторінки мерчанта і логотипів з довідника, без прив'язки до активу чи зобов'язання); PoC v2 (сторінка мерчанта і логотипи з довідника; кількісна метрика успіху); MVP (дія «Прив'язати до активу або зобов'язання»); v1 (інші дії й оператори правил, попередній перегляд «було → стане», дія «приховати») · **Пріоритет:** S

**Зв'язки**
- Зрізи: FLW-41@PoC, FLW-41@PoC v2, FLW-41@MVP, FLW-41@v1
- Модуль: categorization, merchants

**Мета.** Як Owner, Admin або Editor, я хочу один раз налаштувати правила, щоб нові транзакції одразу мали правильні назви, категорії й теги.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
