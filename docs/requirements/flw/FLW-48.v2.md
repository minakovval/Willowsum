# FLW-48@v2 · Підключення зовнішнього AI-асистента або сервісу через API
> Згенеровано з [FLW-48.md](FLW-48.md) командою `node tools/req-check/index.mjs --views`. Не редагувати: змінюйте джерело.

**Реліз:** v2 · **Пріоритет:** C

**Зв'язки**
- Розширює: —
- Залежить від: INT-01@v2
- Дизайн: S-214, S-215
- Спільні правила: П-5, П-8, П-23, SCR-02
- Сценарії: UC-INT-01, UC-INT-02, UC-INT-03, UC-INT-04, UC-INT-05, UC-INT-06, UC-INT-07, UC-INT-08, UC-INT-09
- Модуль: integrations
- Перевіряється: —

**Мета.** Як учасник простору, я хочу дати зовнішньому інструменту (AI-асистенту через MCP, таблиці, автоматизації) контрольований доступ до своїх даних.

**Актор і точка входу.** Будь-який учасник без обмеженого scope — для себе: «Налаштування → Інтеграції → API-токени» або «MCP-конектор».

**Основний шлях**

1. Екран «API-токени» показує токени користувача: назва, права, дата створення, строк дії, останнє використання.
2. «Створити токен»: назва, права читання і окремо запису за розділами даних, строк дії від 1 дня до 1 року (30, 90, 365 днів за замовчуванням).
3. Токен показується один раз із кнопкою «Скопіювати» і попередженням, що повторно його не побачити.
4. «MCP-конектор» показує інструкцію підключення і перемикачі прав (за замовчуванням лише читання).
5. Журнал доступу показує кожне звернення: час, токен, точку доступу, результат.
6. Кнопка «Відкликати» біля кожного токена і підключення; токен перестає діяти протягом 60 с.

**Гілки та помилки**

- Права запису доступні лише ролям із правом редагування з увімкненою 2FA.
- Обмежений учасник не може створювати токени.
- Понад 60 запитів на хвилину — відповідь 429 із часом повтору.
- За 7 днів до закінчення строку — нагадування.
- Зміни через API чи MCP позначаються в журналі аудиту назвою токена.

**Екрани і стани:** API-токени (порожній, список) · Створення токена · Токен створено (показ один раз) · MCP-конектор · Журнал доступу.

**Метрика успіху.** Підключення інтеграції займає не більше 2 хв; 0 випадків доступу поза визначеними правами.

**Критерії приймання**

1. **Given** Editor без 2FA **When** він створює токен **Then** права запису недоступні з підказкою увімкнути 2FA.
2. **Given** Viewer **When** він створює токен **Then** доступні лише права читання.
3. **Given** строк 400 днів **When** користувач зберігає токен **Then** збереження заблоковано з підказкою про максимум 1 рік.
4. **Given** токен створено **When** користувач закриває вікно **Then** значення токена більше ніде не показується.
5. **Given** 61 запит за хвилину **When** надходить 61-й **Then** відповідь 429 із часом повтору.
6. **Given** токен відкликано **When** минає 60 с **Then** запити з ним відхиляються.
7. **Given** зміна даних через токен «Таблиця» **When** відкривається журнал аудиту **Then** зміна позначена як зроблена через інтеграцію «Таблиця».

**Граничні випадки**

- Токен діє лише в межах прав свого власника на момент запиту.
