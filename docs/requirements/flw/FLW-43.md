# FLW-43 · Місячний розподіл «Кожній копійці — завдання»

**Реліз:** PoC v2; MVP (особисті бюджети, ролі Admin і Editor, сповіщення про дохід) · **Пріоритет:** S

**Зв'язки**
- Зрізи: FLW-43@PoC v2, FLW-43@MVP
- Модуль: budget

**Мета.** Як Owner або Admin (для спільного бюджету) чи власник особистого бюджету, я хочу розподілити отриманий дохід між категоріями до нуля, щоб тримати бюджет збалансованим.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
