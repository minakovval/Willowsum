# FLW-08 · Швидке додавання активу

**Реліз:** MVP; v1-mobile (швидка інвентаризація камерою); v1 (медіа й фото, ліміт активів плану) · **Пріоритет:** M (критичний для запуску)

**Зв'язки**
- Зрізи: FLW-08@MVP, FLW-08@v1-mobile, FLW-08@v1
- Модуль: asset-media, asset-registry, usage-limits, valuation

**Мета.** Як Owner, Admin або Editor, я хочу додати будь-який актив за мінімум полів (назва, тип, вартість, валюта) і дозаповнити решту пізніше, щоб актив одразу з'явився в net worth.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
