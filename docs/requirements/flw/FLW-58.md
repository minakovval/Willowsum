## Джерело зрізів

**Реліз:** v2 · **Пріоритет:** C

**Зв'язки**
- Розширює: —
- Залежить від: VLT-20@v2, VLT-21@v2
- Дизайн: S-246
- Спільні правила: П-5, П-6, П-8, П-10, П-23, SCR-02
- Сценарії: UC-VLT-26, UC-VLT-28, UC-VLT-68, UC-VLT-69
- Модуль: vault-items
- Перевіряється: —

**Мета.** Як користувач або довірена особа, я хочу підтвердити особу через офіційний цифровий документ без зберігання самого credential у продукті.

**Актор і точка входу.** Користувач або довірена особа на кроці «Підтвердіть особу»: відновлення доступу до Сейфу, запит екстреного доступу; кнопка «Заповнити з гаманця» у формі посвідчення.

**Основний шлях**

#. [v2] Продукт показує доступні способи за країною: EUDI Wallet для країн ЄС, Дія.Шеринг для України, цифрові посвідчення водія через Digital Credentials API.
#. [v2] Екран показує атрибути, які буде запитано (ім'я, прізвище, дата народження), і мету запиту.
#. [v2] У вебі перевірка йде через Digital Credentials API браузера або через QR-код, який користувач сканує гаманцем на телефоні.
#. [v2] Продукт перевіряє підпис і статус атестації і зіставляє атрибути з профілем.
#. [v2] Зберігаються лише квитанція перевірки (джерело, дата, результат) і потрібні атрибути; credential не зберігається.
#. [v2] «Заповнити з гаманця» заповнює поля «Ім'я», «Дата народження», «Номер», «Строк дії» з позначкою «Перевірено · <дата>».

**Гілки та помилки**

- [v2] Дані не збігаються — «Дані гаманця не збігаються з профілем» і кнопка «Інший спосіб».
- [v2] Гаманець недоступний у країні — альтернатива: ключ відновлення, довірений пристрій або скидання Сейфу; ручної перевірки підтримкою немає.
- [v2] Гаманець передав не всі атрибути — повідомлення, наприклад «Гаманець не передав номер документа».
- [v2] Ручна зміна поля знімає позначку «Перевірено» лише з цього поля.
- [v2] Продукт не стає гаманцем і не зберігає ідентифікаційні дані особи понад потрібні атрибути.

**Екрани і стани:** Вибір гаманця · Запит атрибутів · QR-код · Результат перевірки (успіх, не збігається, недоступно) · Поля з позначкою «Перевірено».

**Метрика успіху.** Не менше 90 % перевірок успішні з першої спроби; 0 збережених credential.

**Критерії приймання**

#. [v2] **Given** користувач в Україні **When** відкривається «Підтвердіть особу» **Then** серед способів є Дія.Шеринг.
#. [v2] **Given** атрибути збігаються з профілем **When** перевірка завершена **Then** збережено квитанцію з джерелом, датою і результатом, без credential.
#. [v2] **Given** дата народження в гаманці відрізняється від профілю **When** перевірка завершена **Then** показано «Дані гаманця не збігаються з профілем» і «Інший спосіб».
#. [v2] **Given** форма посвідчення **When** користувач натискає «Заповнити з гаманця» і підтверджує **Then** поля заповнено з позначкою «Перевірено · <дата>».
#. [v2] **Given** поле «Номер» з позначкою «Перевірено» **When** користувач змінює його вручну **Then** позначка знята лише з цього поля.
#. [v2] **Given** браузер без підтримки Digital Credentials API **When** користувач починає перевірку **Then** показано QR-код для гаманця на телефоні.

**Граничні випадки**

- [v2] Поля не оновлюються автоматично — лише новою перевіркою.
