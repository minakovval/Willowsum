# FLW-44 · План погашення боргів

**Реліз:** PoC (борги — кредитні картки і кредити з розділу «Гроші»; без розділу «Активи › Зобов'язання»); PoC v2 (кількісна метрика успіху); MVP (зобов'язання з розділу «Активи», «План погашення» на картці зобов'язання, ролі учасників); v2 (поширення прогресу картинкою) · **Пріоритет:** S

**Зв'язки**
- Зрізи: FLW-44@PoC, FLW-44@PoC v2, FLW-44@MVP, FLW-44@v2
- Модуль: accounts, debt-payoff, liabilities

**Мета.** Як Owner, Admin або власник зобов'язання, я хочу побачити, коли закінчаться борги і скільки відсотків можна заощадити додатковими платежами.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
