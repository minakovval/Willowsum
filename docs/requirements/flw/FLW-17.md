# FLW-17 · Додавання рахунків: ручний рахунок, імпорт виписки, підключення банку

**Реліз:** PoC (ручний рахунок, зокрема «Кредит», імпорт виписок CSV і Excel; рахунки всіх банків — імпортом файлів, без автоматичних підключень); PoC v2 (автоматичне підключення банків для тестувальників, кількісна метрика успіху); MVP (ролі й учасники простору; PDF і скани, підключення для всіх користувачів, вхід з онбордингу і Головної); v1 (ліміти плану на підключення) · **Пріоритет:** M (критичний для запуску)

**Зв'язки**
- Зрізи: FLW-17@PoC, FLW-17@PoC v2, FLW-17@MVP, FLW-17@v1
- Модуль: accounts, bank-enablebanking, bank-monobank, bank-saltedge, bank-sync, duplicate-matching, import-sessions, ocr, usage-limits

**Мета.** Як Owner, Admin або Editor, я хочу швидко отримати в продукті свої рахунки, залишки і транзакції — через підключення банку, з файлу виписки або вручну — щоб не вводити кожну операцію руками і бачити реальну картину грошей.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
