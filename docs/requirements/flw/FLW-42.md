# FLW-42 · Чек: від фото до розділеної транзакції

**Реліз:** PoC v2 (файл або пересланий лист, локальне розпізнавання, імпорт замовлень з файлу); MVP (вхід з «Ще → Імпорт», ролі Admin і Editor); v1-mobile (фото камерою) · **Пріоритет:** S

**Зв'язки**
- Зрізи: FLW-42@PoC v2, FLW-42@MVP, FLW-42@v1-mobile
- Модуль: ocr, receipts, transactions

**Мета.** Як учасник із правом редагування, я хочу розкласти покупку на категорії за позиціями чека без ручного розподілу.

**Релізні зрізи.** Кожен зріз повний для свого релізу: функціональні вимоги, правила, права, стани і критерії приймання, що діють у ньому, без посилань на інші зрізи. Зріз діє до релізу наступного зрізу.
