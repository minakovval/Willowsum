## Етапи

### 1. Налаштування — Токени

*Реліз етапу:* v2.

**Що робить користувач і навіщо.** Андрій переглядає список токенів, створює токен лише для читання і токен із правом запису.

**Точки дотику.** S-029 Немає доступу, S-030 Пропозиція апгрейду, S-186 Налаштування, S-214 Інтеграції і API, S-215 Створити токен → «Токен показано один раз»

**Сценарії (по порядку).**

1. UC-INT-01 · Переглянути список API-токенів (v2)
1. UC-INT-02 · Створити токен лише для читання (v2)
1. UC-INT-03 · Створити токен із правом запису (v2)

**Що робить система.** Токен із правом запису — для Owner, Admin і Editor з увімкненою 2FA; токен не дає більше, ніж права власника.

**Емоції й болі, які знімають вимоги.** Страх «дати ключ від усього».

**Гілки відмов і винятків.**

- UC-INT-01: 2а — Токенів ще немає: порожній стан «Токенів ще немає» і кнопка «Створити токен»; 2б — Завантаження і помилка: скелетон, після 3 с — індикатор; помилка без технічних деталей, з «Повторити» і кодом (П-13).
- UC-INT-02: 2а — Viewer: доступні лише права читання; перемикач запису неактивний з поясненням «Запис доступний лише ролям з правом…; 3а — Строк поза межами 1 день – 1 рік: створення неможливе (валідація форми).
- UC-INT-03: 2а — 2FA не увімкнена: створення блокується з повідомленням «Щоб надати право запису, увімкніть двофакторну автентифікацію»; 2б — Viewer: перемикач запису неактивний — «Запис доступний лише ролям з правом редагування».

### 2. Налаштування — MCP-конектор

*Реліз етапу:* v2.

**Що робить користувач і навіщо.** Андрій підключає зовнішнього AI-асистента через MCP-конектор.

**Точки дотику.** S-030 Пропозиція апгрейду, S-214 Інтеграції і API

**Сценарії (по порядку).**

1. UC-INT-04 · Підключити зовнішнього AI-асистента через MCP-конектор (v2)

**Що робить система.** Viewer може підключити MCP лише на читання; доступ контрольований.

**Емоції й болі, які знімають вимоги.** Користуватися улюбленим асистентом без копіювання даних вручну.

**Гілки відмов і винятків.**

- UC-INT-04: 3а — Користувач з правом редагування вмикає право запису: підключення отримує запис; зміни зовнішнього асистента виконуються…; 3б — Viewer: доступне лише читання; перемикач запису неактивний.

### 3. Щоденне використання — Запити і журнал

*Реліз етапу:* v2.

**Що робить користувач і навіщо.** Скрипт читає і змінює категорії; Андрій переглядає журнал доступу.

**Точки дотику.** S-214 Інтеграції і API

**Сценарії (по порядку).**

1. UC-INT-05 · Обробити запит інтеграції до даних (v2)
1. UC-INT-06 · Переглянути журнал доступу (v2)

**Що робить система.** Кожен запит перевіряє і токен, і поточні права користувача; журнал показує, що і коли запитано.

**Емоції й болі, які знімають вимоги.** Прозорість дій інтеграцій.

**Гілки відмов і винятків.**

- UC-INT-05: 2а — Токен прострочено: 401 з кодом token_expired; 2б — Токен відкликано (понад 60 с тому): 401.
- UC-INT-06: 2а — Звернень не було: «Звернень ще не було»; 2б — Помилка завантаження: стан помилки з «Повторити» і кодом.

### 4. Винятки і помилки — Строки, відкликання і зміна прав

*Реліз етапу:* v2.

**Що робить користувач і навіщо.** Андрій отримує нагадування про закінчення строку токена; відкликає токен чи MCP-підключення; після зміни його ролі чи плану доступ інтеграцій звужується автоматично.

**Точки дотику.** S-024 Центр сповіщень, S-214 Інтеграції і API

**Сценарії (по порядку).**

1. UC-INT-08 · Нагадати про закінчення строку дії токена (v2)
1. UC-INT-07 · Відкликати токен або MCP-підключення (v2)
1. UC-INT-09 · Звузити або відкликати доступ інтеграцій після зміни прав користувача чи плану (v2)

**Що робить система.** Токени ніколи не дають більше, ніж поточні права учасника; при пониженні плану чи ролі доступ звужується або відкликається.

**Емоції й болі, які знімають вимоги.** Забутий токен не стане дірою в безпеці.

**Гілки відмов і винятків.**

- UC-INT-08: 2а — Строк минув без дій: токен повертає 401 з кодом token_expired (UC-INT-05).
- UC-INT-07: 1а — Те саме для MCP-підключення: кнопка «Відкликати» біля підключення; 1б — Обмежений учасник, Advisor: дія недоступна (його токени відкликає система, UC-INT-09).
- UC-INT-09: 1а — Owner обмежує учасника scope (наприклад, за класами активів): усі його токени і MCP-підключення відкликаються протягом…; 1б — Учасника видалено з простору: усі його токени і підключення відкликаються автоматично.
