# Відкриті питання сценаріїв використання

Зведений перелік розділів «Відкриті питання» всіх каталогів `UC-*.md`. Документ не є вимогою: він фіксує розбіжності й прогалини у вимогах, які виявилися під час написання сценаріїв. Рішення ухвалюють у файлі вимоги; після рішення питання прибирають звідси і з каталогу-джерела.

Вихідних питань у каталогах: 206. Після об'єднання однакових розбіжностей, про які повідомили кілька модулів: 181 (з них 21 зведено з кількох джерел).

Формат пункту: **OQ-NN.** суть розбіжності. *Вимоги:* файл і пункт. *Джерело:* каталог і номер питання в його розділі «Відкриті питання».
