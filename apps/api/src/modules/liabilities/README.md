# Модуль liabilities

**Створено:** 2026-11-13 · **Оновлено:** 2026-11-14 (FIN-01@PoC a: кредити й кредитні картки — модель даних)

Картка модуля (ARC-01). Робота з модулем починається з неї; оновлюйте її в тому ж PR, що й інтерфейс.

## Призначення

Кредити, застава, графіки платежів.

Домен каталогу ARC-01: Активи. Реліз, з якого модуль у каталозі: PoC.

Зараз (FIN-01@PoC): умови зобов'язання рахунку модуля `accounts` — кредиту («Кредит»: іпотека, споживчий, автокредит,
кредитна лінія, позика) зі ставкою і щомісячним платежем і кредитної картки з лімітом і пільговим періодом. Борг — часовий
ряд у журналі (залишок рахунку журналу); власники з частками — рахунку (`accounts.account_owners`). Окремого інтерфейсу
зобов'язань у PoC немає.

## Вимоги

FIN-01@PoC п. 2, 3 (поля кредиту й картки), 5 (обов'язкові ставка і платіж), 16 (ліміт і доступно), AC8, AC13 (доступно =
ліміт − борг), AC18; бізнес-правило «зобов'язання — першокласна сутність». Далі: графік платежів і поділ платежу
(п. 26, AC19–AC21), застава.

## Публічний інтерфейс

`index.ts`:

- `liabilitiesModule` — опис модуля (маршрутів немає: зобов'язання створює `accounts`).
- `createLiabilities(db, audit)` → `Liabilities`, де `db` — `ModuleDatabases.for("liabilities")`; кожен виклик прив'язаний
  до одного простору:
  - `register(householdId, { actorAccountId, accountId, terms })` → `{ kind: "registered", liability }` або
    `{ kind: "invalid", issues }` — одне зобов'язання на рахунок; повтор повертає наявне й нічого не пише. Запис аудиту
    `liabilities.liability`/`create` (ставка, платіж, ліміт, пільговий період) — у транзакції модуля до коміту.
  - `forAccount(householdId, accountId)` → `Liability` або null (рахунок іншого простору — null).
- `createLiabilitiesErasure(db)` → `eraseHousehold(householdId)` — видалення зобов'язань простору (NFR-12@PoC п. 3), лише
  для `data-erasure`.
- `checkTerms(terms)` — перевірка умов без запису (кредит: ставка 0–100 з двома знаками і платіж > 0 обов'язкові,
  пільгового періоду немає; картка: ліміт ≥ 0, пільговий період 0–365 днів, без щомісячного платежу; суми — не більше знаків,
  ніж у валюти); `availableCredit(limit, debt)` — ліміт мінус борг (Decimal); `parseAnnualRate`, `parseTypedAmount`,
  `LIABILITY_KINDS`, `GRACE_PERIOD_MAX_DAYS`; типи `Liability`, `LiabilityKind`, `LiabilityTerms`, `LiabilityTermsInput`,
  `TermsIssue`, `RegisterResult`.
