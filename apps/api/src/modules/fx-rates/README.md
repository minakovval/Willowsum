# Модуль fx-rates

**Створено:** 2026-11-12 · **Оновлено:** 2026-11-13

Картка модуля (ARC-01). Робота з модулем починається з неї; оновлюйте її в тому ж PR, що й інтерфейс.

## Призначення

Курси валют: щоденне оновлення з повторами, історія курсів із джерелом і датою, курс на дату (або найближчий
попередній) і конвертація для відображення. У PoC єдине джерело — НБУ (офіційні курси до гривні); будь-яка інша пара —
крос-курс через гривню на ту саму дату, джерело «НБУ» (рішення власника 2026-11-12). Адаптер ECB — у PoC v2.

## Вимоги

VAL-05@PoC (п. 1–5, AC1–AC5; стан інтерфейсу «оновлено <дата і час>» — у PR екранів із сумами); ARC-05 (адаптер
провайдера й синтетична реалізація); VAL-04@PoC (п. 1–5, AC1–AC4, граничні випадки 1–4; стани інтерфейсу «за курсом на
<дата>» і позначка обмеженої конвертації — у PR екранів із сумами).

## Публічний інтерфейс

`index.ts`:

- `fxRatesModule` — опис модуля (маршрутів і подій немає).
- `createFxRates({ db, now? })` → `FxRates` — читання для відображення, лише з історії модуля (збій провайдера не блокує
  перегляду, AC4):
  - `rate(from, to, date)` → `{ rate: ExchangeRate, updatedAt, stale }` — курс дати або найближчий попередній, крос-курс через
    UAH з курсів однієї дати й одного джерела; немає курсу — `RateUnavailableError`;
  - `convert(money, to, date)` → `{ conversion: Conversion, updatedAt, stale }` — `Conversion` з domain-kernel (сума, курс, дата
    курсу, джерело, `approximate`, якщо курс не цієї дати; курс п'ятниці для суботи й неділі — курс дати, VAL-04 AC4); сума
    лишається в оригінальній валюті;
  - `freshness()` → `{ updatedAt, stale }` — час останнього успішного оновлення (ISO, UTC) і чи минуло 24 год.
- `rates([{ from, to, date }, …])` → `(ExchangeRate | null)[]` — багато курсів одним запитом до історії: для кожного
  курс дати або найближчий попередній (ніколи не пізнішої дати); немає курсу — `null`; помилка бази відхиляє весь виклик.
- `officialDatedRates(fxRates)` → `{ rates(requests) }` — курси для підсумків списку (DAT-01@PoC FR 12,
  `platform/lists/list-total.ts`): усі курси одного підсумку одним запитом; немає курсу — `null` (ніколи не 0).
- `createFxReporting({ db, now? })` → `FxReporting` — суми у валюті звітності простору (VAL-04@PoC), лише читання історії:
  - `toReporting({ amount, date }, currency = REPORTING_CURRENCY)` → `ReportedAmount`: `reporting-currency` (уже у валюті
    звітності), `converted` (`value` без округлення, `conversion` — курс, дата курсу, джерело, запитана дата, `approximate`;
    `restricted` — валюта з обмеженою конвертацією) або `rate-unavailable` (жодного курсу на дату чи раніше: «Курс
    недоступний»). `date` — дата транзакції; `null` — «сьогодні» (київська дата годинника) за останнім денним курсом, без
    позначки «приблизно» (FR 3). `approximate` — курс раніший за дату, крім вихідних із курсом попереднього робочого дня;
  - `total(amounts, currency?)` → `ReportedTotal`: `total` (сума тих, що мають курс; `null`, якщо курсу немає в жодної — ніколи
    0), `approximate` (є найближчий курс або сума без курсу), `nearestRateCount`, `unavailableCount` (число для підказки),
    `restricted`, `items`; усі курси — одним запитом (`rates`). Нічого не зберігає: з появою курсу дати той самий виклик дає
    точне значення.
- Правила валют (`domain/currencies.ts`): `REPORTING_CURRENCY` (EUR — валюта звітності кожного простору в PoC, FR 2; сам
  атрибут простору — `household`, ACC-06), `RESTRICTED_CONVERTIBILITY` і `isRestrictedConvertibility` (довідник валют з
  обмеженою конвертацією), `rateCoversDate(rateDate, date)` (курс тієї ж дати або робочого дня, за яким до дати лише субота
  й неділя; календаря свят у PoC немає — свято дає «приблизно»).
- `startFxRatesRefresh({ db, mode, report, alertMail?, feed?, clock?, firstDelayMs? })` → `{ attempt(), stop() }` — щоденне завдання
  ролі `scheduler`: перша спроба через хвилину після старту, далі раз на добу; після збою — 3 повтори через 15 хв, потім
  1 год, 2 год, 4 год … не більше 24 год. Звіт `report`: `updated`, `failed`, `stale` (24 год без успіху: від останнього успішного оновлення, а до першого — від старту; повтор
  ніколи не призначається за цей момент, тож подія і лист приходять рівно тоді, FR 4, AC2). `main.ts` пише
  `stale` подією рівня «помилка» `fx_rates.stale` у журнал сервера (FR 4, AC2). `alertMail: { mail, to }` — лист власнику
  продукту через адаптер пошти застосунку (рішення власника 2026-11-12: алерти PoC — листи застосунку; адреса —
  `WS_ALERT_EMAIL`): один на період без оновлення (період — після останнього успішного оновлення; заявка в таблиці
  `stale_alerts`, тож перезапуск чи другий планувальник листа не повторюють; невдале надсилання знімає заявку, і лист
  іде з наступною спробою). Текст — `staleAlertMessage`: лише час останнього оновлення і кількість спроб, без сум,
  курсів і валют. Звіти `alert-sent`, `alert-failed`.
- Константи й типи: `NBU_SOURCE`, `PIVOT_CURRENCY`, `REFRESH_INTERVAL_MS`, `STALE_AFTER_MS`, `retryDelayMs`, `PivotRate`,
  `FxRateFeed` (абстракція провайдера, FR 5), `FxClock`, `FxRefreshEvent`.

Провайдери (ARC-05, `adapters/feeds/`): порт `official-fx-rates` (`dailyRates`: поля `date`, `json`); `live` — НБУ
(`https://bank.gov.ua/NBUStatService/v1/statdirectory/exchange?date=YYYYMMDD&json=`, без ключа; курс — JSON-число, читається
з тексту відповіді в Decimal, без float; відповідь відхиляється цілком, якщо валюта повторюється, курс не вміщується в
NUMERIC(38,18) — понад 20 цифр цілої частини чи 18 знаків після коми — або виходить за межу правдоподібності
10^-6 … 10^7 грн за одиницю: у переліку НБУ курси від ≈0,0003 грн до ≈1,7·10^5 грн за унцію золота), `test` —
синтетичний фід (джерело «synthetic»). Вибір — `WS_PROVIDER_MODE`; у staging і production роль `scheduler`, як і `api`,
стартує лише з `live`.

## Власні таблиці

Схема `fx_rates`; міграції — `adapters/db/migrations/NNNN_slug.sql`. Довідкові дані платформи без `household_id`
(`schema-exemptions.json`):

- `rates` — курс валюти до гривні (NUMERIC(38,18)) на дату, джерело, час отримання; один курс на валюту й дату;
- `updates` — кожне успішне оновлення: реалізація фіду, дата, кількість валют, час завершення;
- `stale_alerts` — заявка на єдиний лист періоду без оновлення: ключ періоду і час (без адреси й тексту).
