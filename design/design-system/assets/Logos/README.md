Знак Willowsum — три вкладені листки зі спільним гострим кутом унизу ліворуч (DS-02). Файли скопійовано з `packages/ui/src/brand/assets/`.

- `mark-light.svg` — для світлої теми: великий листок Navy #0B2545, середній Blue #1D4E89, малий Amber #E3A33B.
- `mark-dark.svg` — для темної теми.
- `mark-mono.svg` — одноколірний друк: Navy #0B2545 з вирізом Paper #F6F1E8.
- `app-icon.svg` — іконка застосунку, квадрат 64 × 64 з радіусом `radius-lg` (14 px).

Поле навколо знака — не менше чверті його ширини. Знак не обертають, не дзеркалять і не перефарбовують; у коді кольори беруть токени `mark-large`, `mark-middle`, `mark-small`.
