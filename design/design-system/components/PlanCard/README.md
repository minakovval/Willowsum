PlanCard — картка одного тарифного плану на сторінці порівняння планів.

**Коли використовувати.** Сторінка «Плани і підписка» і пропозиція апгрейду. Не для рекламних банерів у продукті.

**Будова.** Бейджі «Рекомендовано» або «Поточний» над назвою; назва Inter Tight 600 22/28 px; ціна Inter Tight 600 28/36 px табличними цифрами і період «/ міс» 14/20 px `ink-muted`; короткий опис; перелік можливостей з позначками; дія.

**Стани.** Типовий; поточний (обведений `brand`, дія вимкнена); рекомендований; наведення і фокус дії — як у Button; завантаження цін — скелетон рядка ціни.

**Що передає споживач.** `name`, `price`, `period`, `features`, `cta`, `current`, `recommended`.

- Можливості — факти; «Скоро» немає. Ціна не переноситься, дуже велика — скорочується.

**Реліз:** MVP. **Вимога:** CMP-57.
