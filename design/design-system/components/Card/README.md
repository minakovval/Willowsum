Card групує пов'язаний вміст на `surface-200`: рахунок, ціль, підсумок.

**Коли використовувати.** Самостійний блок сторінки. Не для обгортання всієї сторінки; для блоку Головної — Widget.

**Тони.** `flat` (типово, рамка 1 px `line`), `raised` (`shadow-raised`, одна на екран), `sunken` (`surface-300`, тихий вміст усередині іншої картки).

**Будова.** Тло `surface-200`, рамка 1 px `line`, радіус 8 px (`radius-md`), відступи 20 × 24 px. Заголовок картки — 13/16 px 500 великими літерами з розрядкою 0,08 em `ink-muted` («ГРОШІ РАЗОМ»), під ним рядок уточнення 12/16 px `ink-muted`; головне число — Inter Tight 600 32/40 px; праворуч у заголовку — тиха «›» 28 px. Картки стану (порожньо, помилка) і налаштувань мають радіус 12 px.

**Стани.** Типовий; картка-посилання: наведення — рамка `ink`, фокус — кільце `focus` з відступом 2 px; завантаження — скелетон усередині зі збереженням висоти.

**Що передає споживач.** `title`, `tone`, `children`.

- Заголовок: один рядок → 85 % → два рядки → трикрапка; підказка лише при обрізанні.
- Без кольорових смуг на краях. Не вкладайте підняту картку в іншу.

**Реліз:** PoC; MVP — вузькі ширини, сенсорні екрани, темна тема. **Вимога:** CMP-53.
