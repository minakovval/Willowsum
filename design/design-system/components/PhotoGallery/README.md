PhotoGallery — розділ «Медіа» сторінки активу: велике зображення, лічильник, обкладинка, мініатюри і завантаження для редакторів.

**Коли використовувати.** Сторінка активу з фото.

**Будова.** Головне зображення 4:3 (рамка 1 px `line`, `radius-md`, тло `surface-300`); «2 / 6» праворуч угорі і «★ Обкладинка» ліворуч угорі (пігулки `ink`, текст `surface-100`); кнопки «Попереднє» і «Наступне» — кола 44 px `surface-200` з рамкою 1,5 px `border-control`; «Розгорнути» 44 px; мініатюри 56 × 56 px; плитка «Додати» з пунктирною рамкою для редакторів.

**Стани.** Фото — цілим (`contain`), мініатюри обрізані; відео-посилання — плитка з іконкою відтворення; вибрана мініатюра — рамка `ink`; фокус — кільце `focus`; на першому чи останньому фото кнопка прихована; без фото — AssetPlaceholder `large` і «Завантажити фото»; завантаження файлу — смуга прогресу; помилка — «Помилка. Файл не підтримується. Оберіть JPG, PNG або HEIC.»

**Що передає споживач.** `photos` (`src`, `alt`, `video`), `name`, `type`, `cover`, `editable`.

- Кожне фото має `alt`; EXIF-локація видаляється при завантаженні. Стрілки клавіатури працюють, коли зображення у фокусі.

**Реліз:** v1. **Вимога:** CMP-37.
