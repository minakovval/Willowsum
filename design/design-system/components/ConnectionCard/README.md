ConnectionCard — картка одного підключення (банк, брокер, біржа) з його станом і дією.

**Коли використовувати.** Вкладка «Підключення» сторінки «Рахунки». Не для окремих рахунків (ListRow).

**Будова.** Аватар установи 40 px; назва 16/24 px 600; «Оновлено 12 хв тому» 14/20 px `ink-muted`; праворуч Badge стану; нижче — пояснення (для «Потребує дії» і «Помилка») і дії.

**Стани.**
- «✓ Активне» — другорядна дія «Оновити зараз».
- «! Потребує дії» — пояснення («Банк просить підтвердити доступ») і основна дія «Перепідключити».
- «✕ Помилка» — пояснення, «Код: 4012» 13/18 px `ink-muted`, основна дія «Спробувати ще раз».
- «• Відключено» — дані лише для читання, одна дія «Підключити знову».
- Оновлення триває — кнопка в стані завантаження, повторне натискання заблоковане.

**Що передає споживач.** `name`, `status`, `detail`, `action`.

- Банк, від якого надходять лише листи, має картку «<банк> · Листи від банку» зі статусом «Листи».
- Назва — один рядок з трикрапкою.

**Реліз:** PoC; MVP — вузькі ширини і «Приховати суми». **Вимога:** CMP-56.
