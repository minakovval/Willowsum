Skeleton тримає місце вмісту під час завантаження, щоб макет не зсувався.

**Коли використовувати.** Кожен список, віджет і сторінка. Спінер замість скелетона — лише всередині кнопки.

**Варіанти.** `text` — смужки 12 px заввишки (100 %, 80 %, 60 %; для суми 40 % або 64 px), проміжок 12 px; `row` — коло 28–36 px або плитка логотипа 32 px з радіусом 8 px і дві смужки; `block` — прямокутник висотою числа, поля (40 px, радіус 8 px) чи стовпців графіка. Колір `skeleton`, радіус 6 px.

**Стани.** Перелив — світліша смуга проходить зліва направо, один прохід за 1,6 с (`duration-skeleton`), ease-in-out, безкінечно; спінера немає; при зменшеному русі — статичний. Через 3 с під скелетоном — «Ще завантажується…» 14/20 px `ink-muted`. Завершення — вміст, EmptyState або ErrorState без зсуву.

**Що передає споживач.** `variant` і кількість рядків, що повторює майбутній вміст; `slow`.

- Прихований від читача; контейнер один раз оголошує «Завантаження».

**Реліз:** PoC; MVP — вузькі ширини. **Вимога:** CMP-22; DS-13.
