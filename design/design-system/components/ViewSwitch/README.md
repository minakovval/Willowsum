ViewSwitch — тихий перемикач вигляду в заголовку віджета, картки чи списку: «Діаграма / Стовпчики / Тренд / Таблиця» або «Картки / Таблиця».

**Коли використовувати.** Коли ті самі дані мають щонайменше два вигляди. Не для вибору значення у формі (Segmented). З одним варіантом перемикача немає.

**Варіанти.**
- Група кнопок-іконок «Картки / Таблиця» для списків: гліф 16 px у полі **28 × 28 px** (зона 44 px), проміжок 2 px, радіус 4 px, без рамки; назва групи «Показати як».
- «Меню» в заголовку картки графіка (PoC v2): кнопка 28 × 28 з іконкою поточного вигляду і меню виглядів графіка («Стовпчики», «Накопичено», «По днях»…). **«Таблиця» — не вигляд графіка**: таблиця тих самих чисел доступна під графіком у кожному вигляді.
- PoC: кожен графік має рівно один вигляд; кнопка вигляду — неактивна кнопка-іконка 28 × 28 з підказкою «Вигляд: Стовпчики».
- Вигляд усієї сторінки — не іконка, а Select «Вигляд: Повний ˅».

**Стани.** Типовий — `ink-muted`, тло прозоре; наведення — `ink` на `surface-300`; поточний — `surface-300`, `ink` і підкреслення 2 px `brand`; фокус — кільце `focus`; вимкнений — `disabled-ink`. Після перемикання тіло показує скелетон; розмір віджета не змінюється.

**Що передає споживач.** Варіанти з назвою (одне слово) й іконкою, поточний вигляд, обробник зміни. Вибір запам'ятовується для кожного віджета чи списку.

- Клавіатура: `role="radiogroup"`, Tab на поточний, ← → по колу, Home / End; живий регіон: «Показано: Таблиця».
- **PoC:** перемикача немає — кожен графік має один типовий вигляд, кнопка вигляду неактивна (DS-01 п. 27). Вигляди — з PoC v2, повний компонент — MVP.

**Реліз:** MVP (вигляди графіків — з PoC v2). **Вимога:** CMP-58.
