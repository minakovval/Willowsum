Dropzone приймає файли: виписки, документи для розпізнавання, власний логотип.

**Коли використовувати.** Будь-яке завантаження файлу. Кнопка «Обрати файл» є завжди; перетягування — зручність.

**Будова.** Рамка-зона; «Перетягніть файл сюди»; «Обрати файл»; підказка про формати і розмір; під час завантаження — назва, смуга і відсоток.

**Стани.** Очікування — пунктирна рамка; файл над зоною — суцільна рамка `brand`, тло `surface-300`; фокус на кнопці — кільце `focus`; завантаження — «Завантажено 45 %» і «Скасувати»; помилка — рамка `loss`, «Помилка. Файл більший за 1 МБ. Оберіть менший файл.» і «Обрати інший файл»; успіх — «✓ Завантажено»; з v1 — недоступно за планом.

**Що передає споживач.** `state`, `filename`, `pct`, `hint`, `error`.

- Назви файлів — один рядок з трикрапкою.

**Реліз:** MVP; v1 — стан недоступності за планом. **Вимога:** CMP-06.
