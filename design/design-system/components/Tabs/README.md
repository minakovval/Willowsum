Tabs перемикають види однієї сутності або підсторінки одного розділу.

**Варіанти.**
- «Вкладки сторінки» — пігулки під заголовком сторінки: 36 px, відступи 0 × 14 px, `radius-pill`, текст 14/20 px 500 `ink-muted`; поточна — тло `surface-300`, текст `brand` 600. Лічильник — у назві: «До розбору · 7», «Пари · 3». Ряд зсунутий ліворуч на 14 px, щоб текст стояв під заголовком.
- «Вкладки картки» — підкреслення: 44 px, активна — `ink` 600 і підкреслення 3 px `brand` над лінією 1 px `line`.

**Коли використовувати.** Не для розділів продукту (AppNavigation) і не для швидких фільтрів списку (PillTabs).

**Стани.** Наведення — лише колір тексту `ink`; фокус — кільце `focus` всередині вкладки; вимкнена — `disabled-ink`; вміст вантажиться — скелетон під вкладками, вкладки доступні. Лічильник зникає, коли черга порожня.

**Що передає споживач.** `items` (`id`, `label`, `count`), `active`, `variant`.

- Вкладки не переносяться; коли не вміщуються — прокручуються вбік, активна лишається видимою. Це єдина навмисна горизонтальна смуга.
- Підпис — одне-два слова; кожна вкладка від 44 px заввишки.

**Реліз:** PoC; MVP — вузькі ширини. **Вимога:** CMP-11.
