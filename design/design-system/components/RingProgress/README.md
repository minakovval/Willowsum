RingProgress показує прогрес до однієї мети в компактній круглій формі.

**Коли використовувати.** Цілі на дашбордах і в картках. Для повного вигляду цілі — GoalProgress.

**Будова.** Квадрат заданого розміру (типово 96 px); доріжка 8 px `surface-300`; дуга з округленими кінцями кольором шкали цілі `goal-0` … `goal-100` у точці відсотка (інтерполяція OKLCH; на паузі — `goal-paused`), для не-цілі — `brand`; відсоток у центрі Inter Tight 600 22 px табличними цифрами («53 %»), досягнута — «Готово»; підпис під кільцем 14/20 px 500.

**Стани.** 0 % — лише доріжка; 100 % і більше — «Готово» в центрі; завантаження — скелетон-коло; якщо кільце — посилання, кільце `focus`.

**Що передає споживач.** `pct`, `label`, `tone`, `size`.


- Підпис — один рядок з трикрапкою і підказкою лише при обрізанні.

**Реліз:** PoC; MVP — вузькі ширини і «Приховати суми». **Вимога:** CMP-49.
