PillTabs — вкладки-пігулки для швидких фільтрів над списком чи галереєю, де обирається рівно один варіант.

**Коли використовувати.** «Усі» і типи активів над галереєю. Не для видів однієї сутності (Tabs з підкресленням), не для підсторінок розділу («Вкладки сторінки» в Tabs: схожі на вигляд, але перемикають сторінку) і не для кількох фільтрів одночасно (Chip).

**Будова.** Ряд пігулок без рамки: назва 14/20 px 500 `ink-muted` і кількість 12/16 px табличними цифрами; перша — «Усі». Висота 36 px (зона 44 px), відступи 0 × 14 px, `radius-pill`, проміжок 8 px. Такий самий вигляд, як «Вкладки сторінки» на полотні P0.

**Стани.** Типова — тло прозоре, текст `ink-muted`; наведення — `ink` на `surface-100`; обрана — тло `surface-300`, текст `brand` 600; фокус — кільце `focus`; вимкнена — `disabled-ink`. Під час завантаження обрана вже позначена, список у скелетоні.

**Що передає споживач.** Варіанти (іменники в множині до 20 символів) з кількістю записів, видимих учаснику; обраний варіант. Пігулки — лише для типів, що є у списку.

**Реліз:** MVP. **Вимога:** CMP-65.
