AssetGalleryWidget — віджет Головної з галереєю активів у спільній рамці Widget.

**Коли використовувати.** Головна й оглядові сторінки. Варіант — за місцем: `carousel` для вузького чи однорядного віджета, `grid` для широкого, `featured`, коли один актив очевидно найважливіший.

**Будова.** Заголовок 18/24 px в один рядок; під ним рядок уточнення 12/16 px `ink-muted` — «1–3 з 12» (`carousel`) або «12 активів» (`grid`); праворуч кнопка вигляду і тиха іконка «›» з підказкою «Відкрити «Активи»». Текстової дії немає. Тіло — AssetGallery з усіма її правилами.

**Стани.** Готово, завантаження (скелетон трьох плиток), порожньо («Ще немає активів» і «Додати актив»), помилка з повтором; з v1 — «недоступно за планом». Активи поза областю доступу учасника не показуються і не рахуються.

**Що передає споживач.** Усі властивості AssetGallery, плюс `title`, `badge`, `state`.

**Реліз:** MVP; v1 — стан недоступності за планом. **Вимога:** CMP-39.
