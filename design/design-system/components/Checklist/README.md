Checklist — тонка смуга кроків налаштування вгорі Головної, над заголовком сторінки.

**Коли використовувати.** Онбординг, до якого людина може повертатися. Не для потоку з обов'язковим порядком (Stepper).

**Будова.** Смуга на всю ширину вмісту, тло `surface-200`, нижня лінія 1 px `line`. Ліворуч — «Чек-лист налаштування» і «3 з 5»; далі кроки компактними чипами в один рядок (спершу невиконані); якщо не вміщуються — пігулка «+N ˅»; праворуч — IconButton «×», що ховає смугу.

**Стани.** Не виконано — «○» `ink-muted`; виконано — «✓» `gain` 700, назва `ink-muted` закреслена; наведення — `surface-300`; фокус — кільце `focus`; усе виконано — «Усе налаштовано» і пропозиція приховати; приховано — у заголовку Головної кнопка «Чек-лист налаштування · 3 з 5».

**Що передає споживач.** `items` — `{label, state}`; кожен крок — посилання прямо на задачу.

**Реліз:** MVP. **Вимога:** CMP-15.
