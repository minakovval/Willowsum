GroupHeader — заголовок групи в списку чи галереї активів: назва, кількість, підсумок і кнопка згортання.

**Коли використовувати.** Групи за локацією, папкою або типом. Не для заголовків сторінок (PageHeader) і віджетів.

**Будова.** Ліворуч — шеврон згортання 16 px у полі 28 × 28 px (зона 44 px); MiniMap 56 × 56 px (лише для групи з локацією); назва Inter Tight 600 18/24 px; під нею «8 активів» 14/20 px `ink-muted`; праворуч — підсумок 18/24 px табличними цифрами і IconButton «Параметри групи».

**Стани.** Розгорнута; згорнута; наведення на шеврон — `surface-300`, шеврон `ink`; фокус — кільце `focus`; завантаження підсумку — скелетон 96 × 24 px; порожня — «Немає активів у цій групі»; кілька валют — сума в основній валюті з «≈».

**Що передає споживач.** `title`, `type`, `net`, `assets`, `liabilities`, `actions`, `map`.

**Реліз:** MVP. **Вимога:** CMP-66.
