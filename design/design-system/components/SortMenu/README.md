SortMenu — меню варіантів сортування універсального списку, що відкривається IconButton «Сортувати» в Toolbar.

**Коли використовувати.** Лише у вигляді «Картки» (зокрема на Compact, де таблиця стає картками). У вигляді «Таблиця» сортують заголовками колонок, кнопки «Сортувати» немає; меню і заголовки показують той самий стан.

**Будова.** Кнопка 36 × 36 px (зона 44 px, гліф 20 px). Menu з двома групами пунктів-варіантів: поле («Дата», «Сума», «Назва», «Тип» — залежно від списку) і напрям («Спочатку нові / старі», «Від більшої / меншої», «А–Я / Я–А»). Поточний варіант кожної групи — галочка 16 px.

**Стани.** Типове сортування — «Дата, спочатку нові» для списків з датою, інакше «Назва, А–Я»; змінене — крапка `brand-2` на кнопці і назва «Сортувати: за датою, спочатку нові»; вимкнений пункт для поля, якого немає у видимих даних; оновлення — меню закрите, список у скелетоні.

**Що передає споживач.** Поля сортування списку, поточні поле і напрям, обробник.

**Реліз:** PoC; MVP — вузькі ширини і «Приховати суми». **Вимога:** CMP-62.
