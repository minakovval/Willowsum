FolderCard — картка папки чи групи активів у сітці («Дача», «Колекція вин»), що відкриває її вміст.

**Коли використовувати.** Сітка груп на сторінці «Активи». Для окремого активу — плитка AssetGallery.

**Будова.** Обкладинка 4:3 (фото папки або AssetPlaceholder; для змішаних типів — іконка папки); назва 16/24 px 600; «12 активів» 14/20 px `ink-muted`; підсумок вартості Inter Tight 600 18/24 px табличними цифрами.

**Стани.** Наведення — рамка `ink`; фокус — кільце `focus` з відступом 2 px; натиснута — `surface-300` під текстом; завантаження — скелетон обкладинки і двох рядків; порожня — заглушка, «0 активів», «–»; помилка фото — заглушка.

**Що передає споживач.** `name`, `counts`, `total`, `state`.

- Уся картка — одна кнопка. Лічильники мають підпис для читача («1 актив»).
- Назва за драбиною: рядок → 85 % → два рядки → трикрапка.

**Реліз:** MVP. **Вимога:** CMP-67.
