Tree показує вкладені локації (країна, будинок, кімната, сейф) і групи активів.

**Будова.** Рядок від 40 px: стрілка розкриття 16 px `ink-muted`, назва, лічильник праворуч 13 px табличними цифрами `ink-muted`. Кожен рівень зсунутий на 16 px.

**Стани.** Наведення — `surface-300`; активний — `surface-300`, ліва смуга 3 px `brand`, 600; фокус — кільце `focus` всередині; розгорнуто «▾» / згорнуто «▸»; завантаження гілки — два рядки-скелетони; порожньо — «Ще немає локацій» і «Додати локацію».

**Що передає споживач.** `nodes` — `{name, count, open, active, children}`.

- Стрілки переміщують, → відкриває, ← закриває гілку. Масове переміщення активів показує підсумок і прогрес.

**Реліз:** MVP. **Вимога:** CMP-17.
