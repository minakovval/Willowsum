ColumnPicker — спливна панель зі списком колонок таблиці з прапорцями.

**Коли використовувати.** Лише у вигляді «Таблиця»; у вигляді карток кнопки «Колонки» немає.

**Будова.** IconButton «Колонки» 36 × 36 px (зона 44 px). Popover: заголовок «Колонки» 14/20 px 600; рядки по 40 px з прапорцем 20 px (рамка 1,5 px `border-control`; вибраний — заливка `brand`, галочка `on-brand`); обов'язкові колонки («Назва») — вимкнені прапорці з позначкою «завжди»; внизу тиха дія «Скинути до типових».

**Що передає споживач.** Колонки списку з ознакою «обов'язкова», видимі колонки, обробник. Прихована колонка отримує в Table `hidden: true`; порядок і ширини решти лишаються. Вибір запам'ятовується для кожного списку.

**Реліз:** PoC; MVP — вузькі ширини і темна тема. **Вимога:** CMP-63.
