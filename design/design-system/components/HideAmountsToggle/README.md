HideAmountsToggle — кнопка з оком, що вмикає режим «Приховати суми».

**Коли використовувати.** Верхня панель застосунку (дія L0 з MVP). У налаштуваннях те саме — `HideAmountsSwitch` у вигляді Switch.

**Будова.** IconButton з іконкою ока, `aria-pressed`, підказка і доступна назва «Приховати суми».

**Поведінка.** Увімкнено — кожна сума стає «•••» тим самим стилем; відсотки, частки і стрілки лишаються; на графіках ховаються осі й підписи із сумами; на мапі маркери одного розміру. Прихована сума показується утриманням 350 мс або Enter / пробілом на 3 с. Справжнього значення немає в DOM. Змінюється лише показ: експорт і звіти — справжні суми.

**Що передає споживач.** Нічого: стан дає `HideAmountsProvider` / `useHideAmounts`. Зараз налаштування зберігається лише на цьому пристрої; синхронізація між пристроями (до 5 с) — після появи API профілю.

**У коді:** `HideAmountsToggle`, `HideAmountsSwitch`, `HideAmountsProvider`, `Amount`, `Percent`, `HIDDEN_AMOUNT`. **Реліз:** MVP. **Вимога:** DS-18.
