BudgetRow — рядок категорії бюджету: назва, витрачено з ліміту, смуга і стан.

**Коли використовувати.** Таблиця категорій «Бюджету» і картки бюджету. Для цілей заощаджень — GoalProgress.

**Будова.** Верхній ряд: назва 16/24 px 600 і праворуч «витрачено з ліміту» 14/20 px `ink-muted` табличними цифрами. Смуга прогресу на власному рядку. Нижній ряд: маркер і слово стану. Сума залишку чи перевитрати — лише в колонці «Залишок» або праворуч угорі, під нею другим рядком `ink-muted` «N % ліміту» або «N % понад ліміт».

**Стани (DS-23, родина А).** «• не почато» (смуга порожня), «• є залишок», «! майже вичерпано · 86 %», «✓ ліміт вичерпано» (обов'язкова), «! вичерпано» (необов'язкова), «✕ перевищено» (вісім рівнів і хвіст за смугою); категорія без ліміту в групі «Поза планом» — без смуги; рядок-посилання: наведення `surface-300`, кільце `focus`; завантаження — скелетон 72 px.

**Кольори смуги (DS-06, DS-07).** Смуга-пігулка 6 px на доріжці `surface-300` кольором шкали використання в точці відсотка (`usage-0` 0 % → `usage-30` → `usage-55` → `usage-75` → `usage-95` 95–100 %, інтерполяція OKLCH). «Вичерпано» необов'язкової — `over-1`. Перевищення — хвіст за межею одним з `over-1` … `over-8` за часткою перевитрати від суми необов'язкових лімітів (< 5 %, 5–10, 10–20, 20–50, 50–100, 100–200, 200–500, ≥ 500 %). Слово стану — `ink-muted`, `on-warning` («! майже вичерпано») або `loss` («✕ перевищено»): текст шкали не фарбують кольором заливки. Бурштину немає.

**Що передає споживач.** `name`, `spent`, `limit` і тексти сум.

**Реліз:** PoC; MVP — вузькі ширини, темна тема, «Приховати суми». **Вимога:** CMP-55; DS-01 п. 25, DS-23.
