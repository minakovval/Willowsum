Treemap показує частки площею прямокутників, найбільші першими.

**Коли використовувати.** Склад портфеля чи витрат, коли частин забагато для DonutChart.

**Будова.** Один рівень: кожен елемент має групу, що задає заливку; легенда перелічує групи з часткою. Прямі кути, клітинки розділені 2 px `surface-200`, кожна група обведена білою рамкою 2 px. Плитка категорії — відтінок тону групи; не більше 4 відтінків на групу, решта категорій усіх груп — одна сіра плитка «Інші · N» `chart-other`, остання в легенді. Текст на плитці білий, якщо білий дає 4,5 : 1, інакше `ink`.

**Стани.** Мала клітинка — лише назва; крихітна — без тексту, але фокусується, назва і частка в підказці; наведення і фокус — курсор «довідка», кільце `focus`; завантаження, порожньо, помилка — як у віджета.

**Кольори (DS-07 п. 15).** Серія-категорія (категорія бюджету, клас активу) має колір своєї категорії: тон групи `chart-cat-1` … `chart-cat-8` (доходи — `chart-group-income-1` / `-2`) і відтінок OKLCH L 0,40–0,80, тон ±8°; не більше 4 відтінків однієї групи, решта — «Інші · N» `chart-other` #9AA3AF, завжди останнім. Некатегоріальні серії (джерела, рахунки, валюти) — `chart-cat-1`, `chart-cat-2`, … у сталому порядку. Між частинами — проміжок 2 px `surface-200`. План і цільова лінія — `chart-reference` штрих 4/4, бюджет — 12/4. Сітка — 1 px `chart-grid`, нульова лінія — 1,5 px `ink-muted`, підписи осей 11 px `ink-muted`. `series-1` … `series-4` — лише лінії тренду P0 з полотна. Повна таблиця — розділ «Палітра графіків» у README системи.

**Що передає споживач.** `items` (`label`, `value`, `group`), `summary`.

- Площа завжди пропорційна значенню; валюти не змішуються; від'ємних значень немає.
