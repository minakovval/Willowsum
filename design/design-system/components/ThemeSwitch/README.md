ThemeSwitch — перемикач теми з трьома варіантами: «Світла», «Темна», «Як у системі».

**Коли використовувати.** Особисті налаштування, розділ вигляду. Вибір застосовується одразу, без перезавантаження.

**Будова.** Сегментований перемикач (Segmented) у `fieldset` з легендою «Тема»; варіанти — радіокнопки.

**Поведінка.** Тема — атрибут `data-theme="light" | "dark"` на кореневому елементі; «Як у системі» — без атрибута, системна схема застосовується одразу на відкритій сторінці. Вибір зберігається на пристрої (з запасним варіантом для приватного режиму). Перша відмальовка — уже в правильній темі. Друк — завжди світлий.

**Що передає споживач.** Нічого: компонент читає і змінює тему через `ThemeProvider` / `useTheme`; підписи — з `@willowsum/i18n`.

**У коді:** `ThemeSwitch`, `ThemeProvider`, `useTheme`, `THEME_STORAGE_KEY`. **Реліз:** MVP (у PoC — одна світла тема). **Вимога:** DS-11.
