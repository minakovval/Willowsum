Pagination — перехід довгим списком, що сторінкується на сервері.

**Коли використовувати.** Таблиці й списки понад одну сторінку.

**Будова.** Один блок праворуч під списком: «Рядків на сторінці [25 ˅] · 1–25 з 1 240 ‹ ›». Розмір сторінки — 10, 25, 50 або 100. Розмір сторінки — малий Select 32 px; «‹» і «›» — IconButton 36 px з назвами «Попередня сторінка» і «Наступна сторінка».

**Стани.** Перша сторінка — «‹» вимкнена (не прихована); остання — «›» вимкнена; завантаження — кнопки вимкнені, список у скелетоні, діапазон не змінюється до даних; порожній список — пагінації немає.

**Що передає споживач.** `page`, `total`, `pageSize`.

- Стан (сторінка, прокручування, фільтри, сортування) відновлюється при поверненні до списку.

**Реліз:** PoC; MVP — вузькі ширини. **Вимога:** CMP-13.
