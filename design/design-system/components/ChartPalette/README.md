Палітра графіків: тони груп, відтінки категорій, доходи, службові кольори, шкали usage/over/goal, лінії плану і бюджету.

**Коли використовувати.** Як довідку кольорів для будь-якого графіка, чипа категорії чи смуги. Правила — розділ «Палітра графіків» у README системи (DS-06, DS-07 п. 15).

**Будова.** Чотири картки зразків у світлій і темній темі:
- тони 8 груп витрат (`chart-cat-1` … `chart-cat-8`) і 2 груп доходів (`chart-group-income-1`, `-2`), кожен з чотирма відтінками категорій від найбільших витрат до найменших;
- службові кольори: «Переказ» `chart-transfer`, «Інші · N» `chart-other`, штрихування «Інші · N» у заливках складу цілого, опорні лінії `chart-reference` — план і ціль штрихом 4/4, бюджет 12/4;
- шкали `usage-*`, `over-1` … `over-8`, `goal-*`;
- лінії тренду P0 `series-1` … `series-4`, які не є категоріальною палітрою.

**Що передає споживач.** Нічого: це довідкова картка, а не компонент коду.

**Реліз:** PoC. **Вимога:** DS-06, DS-07.
