BrandMark — знак продукту (три вкладені листки зі спільним гострим кутом) і словесна частина «Willowsum».

**Коли використовувати.** Навігація, екрани входу, завантажувальний екран, листи. Не як декоративний візерунок чи ілюстрація.

**Варіанти.**
- Знак для світлої теми, темної і одноколірний (`assets/Logos/`). У коді знак один: заливки беруть токени `mark-large`, `mark-middle`, `mark-small`, тож тема змінює кольори сама. Малий листок — `accent` у кольорових варіантах.
- Словесна частина — живий текст Inter Tight 600, трекінг −2 %, «Willowsum», колір `ink`.
- Поєднання: знак ліворуч, назва праворуч, проміжок — третина ширини знака.

**Стани.** Знак-посилання в навігації веде на «Планування → Бюджет»: наведення не змінює кольору, курсор-вказівник; фокус — кільце `focus` з відступом 2 px. Завантажувальний екран — знак 48 px по центру, без анімації при зменшеному русі.

**Що передає споживач.** Розмір знака (від 16 px) і чи він декоративний (тоді `aria-hidden`; інакше `role="img"` з назвою «Willowsum»).

- Розбіжність: CMP-71 називає колір назви `brand`, а код і DS-02 п. 7 — `ink`. Діє код.
- Знак не дзеркалиться для письма справа наліво.

**У коді:** `WillowsumMark`, `Wordmark`. **Реліз:** PoC; MVP — вузькі ширини і темна тема. **Вимога:** CMP-71; DS-02.
