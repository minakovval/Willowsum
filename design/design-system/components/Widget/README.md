Widget — спільна рамка кожного віджета Головної та оглядових сторінок: заголовок, бейдж, тиха «›» і тіло.

**Коли використовувати.** Самостійний блок огляду. Для форм і вмісту, що не є блоком огляду, — Card. На Widget побудовані AssetMapWidget, AssetGalleryWidget, SummaryWidget, AssetTypeWidget і KpiTile.

**Будова.** Рамка Card (`surface-200`, 1 px `line`, радіус 8 px, відступи 20 × 24 px). Заголовок Inter Tight 600 18/24 px в один рядок; необов'язкова плашка праворуч від заголовка; рядок уточнення 12/16 px `ink-muted` під ним; праворуч компактні кнопки-іконки 28 px — вигляд і «›»; тіло; у віджета з частиною списку — тихе посилання внизу 13 px 500.

**Стани.** Готово, завантаження, помилка, порожньо, немає доступу — у тій самій висоті; з v1 — «вимкнено планом» (збережені дані лишаються для читання).

**Що передає споживач.** `title`, `state`, `badge`, `children`, тексти порожнього стану.

- Помилка одного віджета не блокує інші. Суми підкоряються «Приховати суми».
- Перемикання вигляду не змінює розміру віджета.

**Реліз:** MVP; v1 — стан «вимкнено планом». **Вимога:** CMP-54.
