PageHeader відкриває кожну сторінку: один заголовок першого рівня, підзаголовок і дії.

**Коли використовувати.** Кожна сторінка. Вкладки сторінки (Tabs, варіант «Вкладки сторінки») стоять під заголовком.

**Будова.** Ліворуч — заголовок h1 (`heading-1`) і підзаголовок `ink-muted`. Праворуч — дії: одна `primary`, решта — тихі кнопки-іконки з підказками. Налаштування сутності — IconButton «шестерня» («Налаштування рахунку»). Для L3 — хлібні крихти над заголовком.

**Стани.** Типовий; завантаження — скелетон заголовка 28 px заввишки і 40 % ширини, дії вимкнені.

**Що передає споживач.** `title`, `subtitle`, `actions`.

- Одна головна дія на сторінку. Приклад «Гроші → Транзакції»: основна «Імпортувати виписку», тиха «Історія імпорту», вторинна «Нова транзакція» і «…».
- Заголовок — один рядок, трохи зменшується; підказка лише при обрізанні. Дії не перекривають заголовок.

**Реліз:** PoC; MVP — вузькі ширини. **Вимога:** CMP-10.
