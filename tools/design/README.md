# Допоміжні скрипти дизайн-сесій (знімок)

**Створено:** 2026-11-05 · **Оновлено:** 2026-11-05

Це **знімок** скриптів, якими агенти 2026-11-02…2026-11-05 збирали канву «Willowsum · P0 оболонка і
системні екрани» і артефакт «Willowsum — дизайн-система (компоненти)». Це **не підтримуваний інструмент**:
його не запускає CI, на нього не поширюються правила коду з AGENTS.md (eslint і prettier цю теку
ігнорують), а шляхи всередині вказують на тимчасову теку сесії (`/tmp/claude-0/.../scratchpad`,
`/root/.claude/projects/...`). Щоб використати скрипт повторно, спершу замініть ці шляхи на свої.
Знімки самих артефактів — у `design/canvas/` і `design/design-system/`, покажчик — у
`docs/design/ARTIFACTS.md`.

Скріншоти, `node_modules`, вихідні теки (`out/`, `shots/`) і згенерований `icons.json` (≈ 450 КБ) до
знімка не ввійшли.

## `build/` — збирання дизайн-системи (картки компонентів)

| Файл | Що робить |
| --- | --- |
| `build.py` | Збирає `preview.html` усіх компонентів із модулів `comps1…7.py` у `out/project/components/`. |
| `common.py` | Спільні helpers: іконки (`icons.json`), форматування сум (нерозривний пробіл, «−»), базовий CSS картки. |
| `comps1.py` … `comps7.py` | Розмітка карток компонентів за групами: основи, контроли, графіки, продуктові, палітра графіків DS-07, правила DS-01 (стани, суми, статуси, фільтри, меню), кольори категорій. |
| `oklch.py` | Перетворення HEX ↔ OKLCH для відтінків категорій. |
| `tokcss.py` | Робить `tokens.css` (світла і темна теми) з `tokens.json` артефакту. |
| `tokens.css` | Згенеровані CSS-змінні токенів для локального перегляду карток. |
| `readmes.py`, `readmes12.py` | Масово оновлюють розділи `README.md` компонентів (доступність, кольори тощо). |
| `sheet.py` | Склеює скріншоти карток у контактний аркуш (Pillow). |
| `shot.js` | Знімає скріншоти карток у світлій і темній темах (Playwright). |
| `icons.js` | Генерує `icons.json` з пакета `lucide` у `node_modules`. |
