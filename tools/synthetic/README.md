# tools/synthetic — синтетичні дані

**Створено:** 2026-11-06 · **Оновлено:** 2026-11-06

Детермінований генератор синтетичних просторів і їхніх даних для тестів і staging (ARC-03 п. 6, П-9).
Лише вигадані дані: агенти й тести ніколи не використовують реальні.

## Як працює

- Простори: «Synthetic household N», регіон «eu», власне посилання на ключ `synthetic-key-NNNN`
  (заглушка, не ключ). Таблиці просторів поки немає (ACC-08).
- Кожен модуль реєструє генератор своїх таблиць у `apps/api/src/modules/<module>/synthetic.ts`:
  `export const synthetic = [defineSyntheticTable({ table: "<схема>.<таблиця>", perHousehold, rows })]`.
  `perHousehold` — обсяг для тестів і staging; вимога — 10 000 активів і 100 000 транзакцій на простір
  (генератори додадуть модулі `asset-registry` і `transactions`).
- Псевдовипадкові числа — sfc32 із зерном-рядком (не криптографія); зерно окреме для кожної пари
  «простір + таблиця», тож нова таблиця не змінює дані інших. Суми будуються цифрами як рядки, без float.
- Рядки йдуть потоком, у пам'яті — один рядок.

## Команда

```
node tools/synthetic/index.ts --out <dir> [--seed willowsum] [--households 1] [--format csv|sql] \
  [--count <схема.таблиця>=<рядків на простір>]
```

`csv` — файл `<схема.таблиця>.csv` на таблицю; `sql` — `synthetic.sql` з блоками `COPY … FROM stdin` для
завантаження власником схем через psql у тестову базу.

Тести: `pnpm --filter @willowsum/synthetic test` (детермінізм, обсяг 10 000 + 100 000, формати);
тест ізоляції `apps/api/test/isolation.it.test.ts` заповнює кожну таблицю клієнтів цими генераторами.
