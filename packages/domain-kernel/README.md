# @willowsum/domain-kernel

**Створено:** 2026-11-06 · **Оновлено:** 2026-11-13 (NFR-06)

Спільний чистий код без бізнес-правил (ARC-01, AGENTS.md): гроші, ідентифікатори, помилки. Без
введення-виведення; працює і в браузері, і на сервері.

| Що | Файл | Правило |
| --- | --- | --- |
| `Money`, `Decimal`, `sumMoney` | `src/money.ts` | Сума — лише з десяткового рядка або `Decimal`, ніколи з JS `number`; точна арифметика; різні валюти не додаються без явного курсу на дату; межа NUMERIC(38,18) |
| `currencyInfo`, `currencyCode`, `knownCurrencies` | `src/currency.ts` | Довідник одиниць (NFR-06): ISO 4217 з точністю валюти, метали XAU, XAG, XPT, XPD (4 знаки показу), крипта до 18 знаків; невідомий код — помилка |
| `Money#toDisplayDecimal` | `src/money.ts` | Округлення лише для показу: банківське, до точності валюти (NFR-06 п. 2, DS-04) |
| `exchangeRate`, `convert`, `Conversion` | `src/conversion.ts` | Конвертація лише з явним курсом на дату; запис зберігає курс, дату курсу, джерело і позначку «приблизно», якщо курс не тієї дати (NFR-06 п. 4); результат у межах NUMERIC(38,18) |
| `isCalendarDate` | `src/rate-date.ts` | Справжня календарна дата `YYYY-MM-DD` (не «today», не 2026-02-30; роки 0000–0099 відхиляються); правило, який курс покриває дату, — у fx-rates, не тут |
| `newId`, `parseId`, `Id<K>` | `src/ids.ts` | Випадковий UUID (Web Crypto) |
| `DomainError` | `src/errors.ts` | Машинний код і повідомлення без персональних даних |

Статичний аналіз (ESLint, `eslint.config.js`): заборонено `parseFloat`, `Decimal` і `Money.of` з JS-числа,
поля й параметри сум типу `number`, назви планів у коді (NFR-06); тест правил — `src/lint-rules.test.ts`.
