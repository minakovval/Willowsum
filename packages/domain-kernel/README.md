# @willowsum/domain-kernel

**Створено:** 2026-11-06 · **Оновлено:** 2026-11-06

Спільний чистий код без бізнес-правил (ARC-01, AGENTS.md): гроші, ідентифікатори, помилки. Без
введення-виведення; працює і в браузері, і на сервері.

| Що | Файл | Правило |
| --- | --- | --- |
| `Money`, `Decimal`, `sumMoney` | `src/money.ts` | Сума — лише з десяткового рядка або `Decimal`, ніколи з JS `number`; точна арифметика; різні валюти не додаються без явного курсу на дату; межа NUMERIC(38,18) |
| `currencyCode` | `src/money.ts` | Три літери A–Z (довідник валют додає NFR-06) |
| `newId`, `parseId`, `Id<K>` | `src/ids.ts` | Випадковий UUID (Web Crypto) |
| `DomainError` | `src/errors.ts` | Машинний код і повідомлення без персональних даних |

Повний набір правил грошей (ISO 4217, XAU/XAG, крипта, запис конвертації) — NFR-06, наступний PR.
